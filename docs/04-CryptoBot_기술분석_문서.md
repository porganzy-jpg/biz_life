## 2. 4가지 매매 전략 상세 설명

### 전략 1: RSI + 볼린저밴드 (평균회귀 전략)

**핵심 개념**: "가격은 결국 평균으로 돌아온다"

```
가격 차트 예시:
                                    ┌─ 볼린저밴드 상단 (비싸다!)
     ╱╲         ╱╲                 │
    ╱  ╲  ╱╲  ╱  ╲    ╱╲         │  ← 이동평균선 (평균)
   ╱    ╲╱  ╲╱    ╲  ╱  ╲        │
  ╱                 ╲╱    ╲       │
 ╱                         ╲     └─ 볼린저밴드 하단 (싸다!)
                            ╲
                    여기서 매수! ↑
```

| 지표 | 역할 | 설정값 |
|------|------|--------|
| **RSI(7)** | 과매도/과매수 판단 | 30 이하 = 과매도, 70 이상 = 과매수 |
| **볼린저밴드(20)** | 가격 변동 범위 파악 | 2 표준편차 |

**매수 조건** (3가지 모두 충족):
1. RSI가 30 아래 (과매도 = 너무 많이 떨어짐)
2. 가격이 볼린저밴드 하단 15% 이내
3. RSI가 반등 시작 (이전 RSI < 현재 RSI)

**매도 조건** (3가지 모두 충족):
1. RSI가 70 위 (과매수 = 너무 많이 올랐음)
2. 가격이 볼린저밴드 상단 85% 이상
3. RSI가 하락 시작

**비유**: 고무줄을 너무 늘이면 다시 줄어드는 것처럼, 가격이 평균에서 너무 벗어나면 다시 돌아올 확률이 높다는 원리입니다.

---

### 전략 2: VWAP + 거래량 (돌파 전략)

**핵심 개념**: "거래량이 터지면서 핵심 가격선을 돌파하면 추세가 시작된다"

```
       거래량 급등!
       |||||||
가격   |||||||
  ▲   ___|||||||___________________  ← VWAP (거래량 가중 평균가격)
  │  /    |||||||
  │ /     돌파!
  │/
  └──────────────────────────────▶ 시간
```

| 지표 | 역할 | 설정값 |
|------|------|--------|
| **VWAP(14)** | 거래량 가중 평균 가격 | 14봉 기준 |
| **거래량** | 시장 참여자 관심도 | 평균 대비 1.5배 이상 = 급등 |

**매수 조건** (3가지 모두 충족):
1. 최근 2봉 내 VWAP을 위로 돌파
2. 현재 가격이 VWAP 위에서 유지
3. 거래량이 평균의 1.5배 이상

**비유**: 댐이 터지는 순간을 포착하는 것. 물(거래량)이 몰리면서 장벽(VWAP)을 넘으면, 한동안 그 방향으로 흐른다는 원리입니다.

---

### 전략 3: 스토캐스틱 RSI (모멘텀 전략)

**핵심 개념**: "RSI의 RSI를 보면 더 민감한 매매 시점을 잡을 수 있다"

```
100 ──────────────────── 과매수 구간 (75 이상)
     ╲    ╱╲
      ╲  ╱  ╲  K선
       ╲╱    ╲............  D선
              ╲   ↑ 데드크로스 (매도!)
               ╲
 25 ──────────────────── 과매도 구간 (25 이하)
        ╱╲
   K선 ╱  ╲............  D선
      ╱    ↑ 골든크로스 (매수!)
  0 ──────────────────────────────
```

| 지표 | 역할 | 설정값 |
|------|------|--------|
| **Stochastic RSI(14)** | RSI를 한번 더 정규화 | 0~100 범위 |
| **K선(5)** | 빠른 선 (민감) | 5봉 이동평균 |
| **D선(3)** | 느린 선 (안정적) | 3봉 이동평균 |

**매수 조건**:
- K선이 D선을 위로 교차 (골든크로스) + 둘 다 25 아래

**매도 조건**:
- K선이 D선을 아래로 교차 (데드크로스) + 둘 다 75 위

**비유**: 자동차 속도계의 "가속도"를 보는 것. 속도가 느려지다가 다시 빨라지는 그 변곡점을 포착합니다.

---

### 전략 4: EMA 크로스오버 (추세추종 전략)

**핵심 개념**: "추세를 따라가면 안정적인 수익을 얻을 수 있다"

```
     EMA3 (빠른선)
      ╲╲╲
       ╲╲   EMA8 (느린선)
        ╳ ← 골든크로스 (매수!)
       ╱╱
      ╱╱     ─────── EMA21 (추세선)
     ╱╱       가격이 이 위에 있어야 매수 허용
```

| 지표 | 역할 | 설정값 |
|------|------|--------|
| **EMA 3** | 빠른 이동평균 (초단기) | 3분 |
| **EMA 8** | 느린 이동평균 (단기) | 8분 |
| **EMA 21** | 추세 이동평균 (중기) | 21분 |

**매수 조건**:
- EMA3이 EMA8을 위로 교차 (골든크로스)
- 현재 가격 > EMA21 (상승 추세 확인)

**매도 조건**:
- EMA3이 EMA8을 아래로 교차 (데드크로스)
- 현재 가격 < EMA21 (하락 추세 확인)

**비유**: 강물의 방향을 보는 것. 작은 물결(EMA3)이 큰 물결(EMA8)을 넘어가면, 강 전체(EMA21)의 방향과 같을 때만 거래합니다.

## 3. 앙상블 투표 시스템

**핵심 개념**: "한 명의 전문가보다 여러 전문가의 합의가 더 정확하다"

```
┌──────────────────────────────────────┐
│           앙상블 투표 과정              │
│                                       │
│  전략1 (RSI+BB)    : 매수! (30%)      │
│  전략2 (VWAP)      : 매수! (25%)      │
│  전략3 (StochRSI)  : 관망  (25%)      │
│  전략4 (EMA)       : 매수! (20%)      │
│                                       │
│  결과: 3개 전략 매수 동의              │
│  가중 신뢰도 = 0.30×0.7 + 0.25×0.6    │
│              + 0.20×0.5 = 0.46        │
│                                       │
│  ✓ 최소 2개 동의 조건 충족             │
│  ✓ 신뢰도 0.30 이상 조건 충족          │
│  ──▶ 매수 신호 발생!                  │
└──────────────────────────────────────┘
```

### 가중치 배분

| 전략 | 기본 가중치 | 역할 |
|------|-----------|------|
| RSI + 볼린저밴드 | 30% | 평균회귀 감지 (가장 높은 비중) |
| VWAP + 거래량 | 25% | 돌파 모멘텀 감지 |
| 스토캐스틱 RSI | 25% | 과매도/과매수 모멘텀 |
| EMA 크로스오버 | 20% | 추세 방향 확인 |

### 투표 규칙

1. **최소 2개 전략** 이상 같은 방향에 동의해야 함
2. **가중 신뢰도 합계 0.30 이상** 이어야 함
3. **추세 필터**: EMA50 아래에서는 매수 차단 (하락장 방어)
4. **변동성 필터**: 변동성이 너무 낮거나 높으면 거래 안 함
5. **쿨다운**: 거래 후 8분간 대기 (과다 거래 방지)

### 자동 가중치 조정

500사이클(약 25분)마다 각 전략의 **승률**을 추적하여 가중치를 자동 조정합니다.
- 승률 높은 전략 → 가중치 증가
- 승률 낮은 전략 → 가중치 감소
- EMA 기반 이동평균으로 부드럽게 조정 (급변 방지)

## 4. 리스크 관리 (RiskManager)

**핵심 철학**: "얼마 벌지보다 얼마 잃을지를 먼저 정한다"

### 4.1 ATR 기반 동적 손절/익절

**ATR(Average True Range)** = 최근 14봉의 평균 가격 변동 폭

```
예시: BTC 현재가 1억원, ATR = 13만원 (0.13%)

┌─ 익절 라인: +78만원 (+0.78%) ← ATR × 6
│
│  ┌─ 트레일링 활성: +50만원 (+0.5%)
│  │
│  │  현재가: 1억원 ← 진입 지점
│  │
│  └─ 최소 손절: -40만원 (-0.4%)
│
└─ 최대 손절: -120만원 (-1.2%) ← 하드캡
```

| 항목 | 계산 방식 | 설정값 |
|------|----------|--------|
| **손절(Stop-Loss)** | ATR × 4 (최소 0.4%, 최대 1.2%) | 동적 |
| **익절(Take-Profit)** | ATR × 6 (최소 1.0%) | 동적 |
| **트레일링 스탑** | 0.5% 수익 후 활성, 고점 대비 0.3% 하락 시 청산 | 동적 |

### 4.2 포지션 사이징 (얼마나 살까?)

```
투자금액 = (총 잔고 × 1.5%) ÷ 손절 비율

예시:
  잔고: 100만원
  리스크: 100만 × 1.5% = 15,000원 (한 번에 최대 잃을 금액)
  손절폭: 0.5%

  투자금액 = 15,000 ÷ 0.005 = 300만원
  → 하지만 잔고의 95%인 95만원이 상한
  → 최종 투자: 95만원
```

**핵심**: 한 번의 거래에서 최대 **잔고의 1.5%**만 잃도록 설계. 100만원이면 한 번에 최대 1.5만원만 잃습니다.

### 4.3 트레일링 스탑 (수익 보호)

```
진입 → 가격 상승 → 0.5% 이익 도달 → 트레일링 활성화!

     ★ 최고점
    ╱
   ╱   ╲ 고점 대비 -0.3% → 자동 청산
  ╱     ╲
 ╱       ╲ ← 이 지점에서 매도 (수익 확보!)
╱
진입
```

수익이 0.5% 이상 나면 트레일링이 켜지고, 가격이 **최고점 대비 0.3% 하락**하면 자동으로 팔아서 수익을 확보합니다.

## 5. 서킷브레이커 (Circuit Breaker)

**핵심 개념**: "주식시장의 서킷브레이커처럼, 위험할 때 자동으로 멈춘다"

```
┌────────────────────────────────────┐
│         서킷브레이커 3대 조건         │
│                                     │
│  1. 일일 손실 3% 이상               │
│     → 당일 매매 완전 중지!           │
│                                     │
│  2. 연속 4번 손실                    │
│     → 15분간 쿨다운 (머리 식히기)     │
│                                     │
│  3. 시간당 20건 이상 거래             │
│     → 과다 거래 차단                 │
│                                     │
└────────────────────────────────────┘
```

| 조건 | 발동 기준 | 결과 |
|------|----------|------|
| 일일 손실 한도 | -3% | 당일 매매 정지 |
| 연속 손실 | 4연패 | 15분 쿨다운 |
| 시간당 거래 수 | 20건 초과 | 거래 일시 차단 |

## 6. 거래소 연동 (업비트)

### 데이터 수집
- **업비트 REST API** 사용 (ccxt 라이브러리)
- **1분봉 캔들** 200개씩 실시간 수집
- 3초마다 반복 (루프 인터벌)

### 대상 코인

| 코인 | 마켓 코드 | 특성 |
|------|----------|------|
| 비트코인 | KRW-BTC | 가장 큰 시가총액 |
| 이더리움 | KRW-ETH | 스마트 컨트랙트 대표 |
| 리플 | KRW-XRP | 빠른 결제 |
| 솔라나 | KRW-SOL | 고속 블록체인 |
| 도지코인 | KRW-DOGE | 높은 변동성 |

### 페이퍼 트레이딩 (모의 투자)

기본적으로 **모의투자 모드**로 동작합니다.
- 실제 돈 대신 가상 100만원으로 시작
- 실제 시장 데이터를 사용하되, 주문은 시뮬레이션
- 충분한 테스트 후 실전 전환 가능

```
환경변수:
  SCALPER_PAPER_TRADING=true   → 모의투자 (기본값)
  SCALPER_PAPER_TRADING=false  → 실전투자 (API 키 필요)
```

## 7. 백테스트 시스템

과거 데이터로 전략을 검증하는 시스템입니다.

### 백테스트 결과 지표

| 지표 | 의미 |
|------|------|
| **승률 (Win Rate)** | 전체 거래 중 이긴 비율 |
| **총 수익률** | 시작 잔고 대비 최종 수익 |
| **최대 낙폭 (Max Drawdown)** | 최고점에서 최저점까지 하락 비율 |
| **샤프 비율 (Sharpe Ratio)** | 위험 대비 수익률 (높을수록 좋음) |
| **수익 팩터 (Profit Factor)** | 총이익 ÷ 총손실 (1 이상이면 수익) |
| **평균 거래 시간** | 진입~청산까지 평균 소요 시간 |

### 수수료 반영
- 업비트 편도 수수료: 0.05%
- 왕복(매수+매도): 0.1%
- 백테스트에서도 수수료를 반영하여 현실적인 결과를 계산

## 부록: 용어 사전

| 용어 | 뜻 |
|------|-----|
| **스캘핑** | 아주 짧은 시간에 소폭 이익을 노리는 초단타 매매 |
| **RSI** | 상대강도지수. 0~100 사이 값으로 과매수/과매도 판단 |
| **볼린저밴드** | 이동평균 ± 표준편차로 만든 가격 범위대 |
| **VWAP** | 거래량가중평균가격. 큰 손들의 평균 매입가 |
| **EMA** | 지수이동평균. 최근 가격에 더 많은 가중치 |
| **스토캐스틱** | 현재 가격이 최근 범위에서 어디 위치인지 (0~100) |
| **ATR** | 평균진폭범위. 시장 변동성 측정 지표 |
| **앙상블** | 여러 전략을 합쳐서 하나의 결정을 내리는 방법 |
| **트레일링 스탑** | 수익 구간에서 가격을 추적하며 자동 청산하는 기법 |
| **서킷브레이커** | 과도한 손실 시 자동으로 매매를 중단하는 안전장치 |
| **백테스트** | 과거 데이터로 전략 성과를 미리 검증하는 것 |
| **샤프 비율** | (수익률 - 무위험수익률) ÷ 변동성. 1 이상이면 양호 |
