## 00-ServerMonitor: v1.0 → v2.0

### 주요 변경
1. **통합 런처 (main.py)** - 대시보드 + 텔레그램 봇 + 모니터링을 단일 프로세스로 관리
   - multiprocessing 기반 3-in-1 통합
   - 서브프로세스 크래시 자동 감지 + 재시작 (5초 간격)
   - Ctrl+C 우아한 종료 (SIGINT/SIGTERM)
   - `--no-bot`, `--no-monitor` 플래그

2. **백그라운드 헬스체크 (monitor.py)**
   - 30초 주기 프로젝트 포트 응답 확인
   - 응답 없으면 자동 재시작 (좀비 프로세스 정리)
   - 텔레그램 알림 (5분 쿨다운)

3. **리소스 임계치 알림**
   - 60초 주기 CPU/RAM/Disk 체크
   - CPU>85%, RAM>80%, Disk>90% 초과 시 텔레그램 경고

4. **텔레그램 봇 확장** (8개 → 11개 명령)
   - `/startall`, `/stopall` 전체 시작/중지
   - `/report` 서버 일일 리포트

5. **Windows 부팅 자동시작** (install_autostart.bat)

### 파일
- `main.py` (신규), `monitor.py` (신규), `install_autostart.bat` (신규)
- `app.py` (업데이트), `bot.py` (업데이트), `config.py` (업데이트)

## 06-HomeFinder: v1.5 → v2.0

### 주요 변경
1. **토지 등록/수정 CRUD UI** (land_form.html)
   - 토지/건물 겸용 등록 폼 (지목, 용도지역, 건폐율, 용적률, 접도, 지형)
   - 수정 모드: 기존 데이터 자동 로드
   - 카카오 API 좌표 자동 변환

2. **매물 상세 페이지 강화** (property_detail.html)
   - 토지/건물별 다른 정보 테이블 동적 전환
   - 수정/삭제 버튼 + 레이더 차트 라벨 자동 분기

3. **검색필터 강화**
   - 건물/토지 분류 선택 시 필터 패널 동적 전환
   - 건물 필터: 연식, 층수, 향, 세대수
   - 토지 필터: 지목, 용도지역, 건폐율, 용적률

4. **API 라우트 추가**
   - `POST /api/v1/properties/` 매물 등록
   - `PUT /api/v1/properties/{id}` 매물 수정
   - `DELETE /api/v1/properties/{id}` 매물 삭제(비활성화)
   - `GET /property/new/land` 토지 등록 페이지
   - `GET /property/{id}/edit` 수정 페이지
