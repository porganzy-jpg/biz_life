# BarcodeQuest - 바코드 모험 수집 게임 기획서

> "일상의 모든 바코드가 모험의 시작이 된다"

---

## 1. 게임 컨셉 요약

### 1.1 핵심 비전
**BarcodeQuest**는 현실 세계의 상품 바코드를 스캔하여 귀여운 캐릭터(크리처)를 수집하는
**방치형 + 수집형 + 카드뽑기** 모바일 게임입니다.

### 1.2 컨셉 키워드
- **수집의 쾌감**: 바코드마다 고유한 크리처가 숨어있다
- **자연 & 모험**: 숲, 바다, 산, 하늘 4대 자연 환경 테마
- **귀여운 캐릭터**: 둥글둥글한 2D 아트, 자연에서 영감받은 크리처들
- **방치형 성장**: 접속하지 않아도 크리처들이 탐험하고 자원을 모아옴
- **도파민 루프**: 바코드 스캔 → 카드 연출 → 희귀 등급 확인의 짜릿함

### 1.3 핵심 차별점 (특허 기술)
```
바코드 정보 + 위치(GPS) + 시간대 = 결정론적 크리처 생성

같은 바코드라도:
  - 서울에서 스캔하면 → 도시 속성 보너스
  - 제주도에서 스캔하면 → 자연 속성 보너스
  - 새벽에 스캔하면 → 야행성 크리처
  - 낮에 스캔하면 → 일반 크리처

같은 조건이면 항상 같은 크리처 (결정론적)
하지만 조건의 조합이 다양해서 무궁무진한 변주 (다양성)
```

## 3. 핵심 시스템 설계

### 3.1 바코드 → 크리처 생성 알고리즘 (Core Engine)

```
[바코드 스캔]
     │
     ▼
[EAN-13 파싱]
  ├── 국가코드 (3자리) → 크리처 출신지 + 타입 영향
  ├── 제조사코드 (4자리) → 크리처 외형 결정
  └── 상품코드 (5자리) → 스탯 분배 영향
     │
     ▼
[시드 생성] SHA256(바코드 + 위치그리드 + 시간대)
     │
     ▼
[크리처 생성]
  ├── 등급 결정 (시드 기반 확률)
  ├── 타입 결정 (국가코드 + 시드)
  ├── 스탯 생성 (시드 청크별 분배)
  ├── 외형 생성 (체형 + 색상 + 악세서리)
  ├── 특성 부여 (등급별 고유 특성)
  └── 위치/시간 보너스 적용
     │
     ▼
[카드 연출 + 수집 등록]
```

### 3.2 일관성 + 다양성 매커니즘

**일관성 (같은 입력 = 같은 결과)**:
- 동일 바코드 + 동일 위치 그리드 + 동일 시간대 → 항상 같은 크리처
- SHA256 해시의 결정론적 특성 이용
- 사용자 간 공유/교환 시 검증 가능

**다양성 (풍부한 변주)**:
- **위치 그리드**: GPS를 0.01도 단위로 양자화 (약 1.1km 격자)
- **시간대 4분할**: 새벽(0-6) / 낮(6-12) / 오후(12-18) / 밤(18-24)
- **계절 변수**: 봄(3-5) / 여름(6-8) / 가을(9-11) / 겨울(12-2)

```
예: 같은 "신라면" 바코드(8801043150842)

  서울 + 낮   → "화염두꺼비" (산 타입, Uncommon)
  서울 + 밤   → "달빛두꺼비" (하늘 타입, Rare)
  부산 + 낮   → "파도두꺼비" (바다 타입, Uncommon)
  제주 + 새벽 → "안개두꺼비" (숲 타입, Epic!)  ← 특수 조합!
```

### 3.3 등급 시스템 (가챠)

| 등급 | 확률 | 카드 연출 | 스탯 배율 | 특성 |
|------|------|----------|----------|------|
| **Common** (일반) | 55% | 초록 빛 | x1.0 | 없음 |
| **Uncommon** (고급) | 25% | 파란 빛 | x1.2 | 약한 특성 1개 |
| **Rare** (희귀) | 12% | 보라 빛 + 반짝임 | x1.5 | 특성 1개 |
| **Epic** (영웅) | 6% | 금빛 + 폭발 이펙트 | x1.8 | 강한 특성 1개 |
| **Legendary** (전설) | 2% | 무지개 + 전체화면 연출 | x2.2 | 고유 특성 + 파티클 |

**등급 부스터 조건**:
- 특정 위치(명소, 자연공원 등)에서 스캔 → +등급 확률 5%
- 새벽/심야 스캔 → +등급 확률 3%
- 연속 7일 출석 → +등급 확률 2%

## 4. 크리처 시스템

### 4.1 10대 타입

| 타입 | 아이콘 | 환경 | 특성 | 강한 상대 | 약한 상대 |
|------|-------|------|------|----------|----------|
| **잎(Leaf)** | 🌿 | 숲 | 회복, 방어 | 물, 바위 | 불, 독 |
| **불(Fire)** | 🔥 | 산 | 공격, 화상 | 잎, 얼음 | 물, 바위 |
| **물(Water)** | 💧 | 바다 | 적응, 둔화 | 불, 바위 | 잎, 번개 |
| **바람(Wind)** | 🌪️ | 하늘 | 속도, 회피 | 잎, 독 | 바위, 얼음 |
| **바위(Rock)** | 🪨 | 산 | 방어, 반사 | 불, 바람 | 물, 잎 |
| **번개(Thunder)** | ⚡ | 하늘 | 치명타, 마비 | 물, 바람 | 바위, 잎 |
| **얼음(Ice)** | ❄️ | 산 | 둔화, 동결 | 바람, 잎 | 불, 바위 |
| **독(Poison)** | 🍄 | 숲 | 지속뎀, 약화 | 잎, 물 | 바위, 번개 |
| **빛(Light)** | ✨ | 하늘 | 치유, 버프 | 어둠 | 어둠(상호) |
| **어둠(Dark)** | 🌙 | 밤 | 저주, 디버프 | 빛 | 빛(상호) |

### 4.2 크리처 외형 구성

모든 크리처는 **3가지 외형 요소**의 조합:

```
크리처 외형 = [체형] + [색상] + [악세서리]

체형 (10종):
  용(Dragon), 여우(Fox), 곰(Bear), 새(Bird), 슬라임(Slime)
  골렘(Golem), 유령(Ghost), 고양이(Cat), 늑대(Wolf), 거북(Turtle)

색상 (12종):
  진홍, 황금, 하늘, 에메랄드, 보라, 분홍,
  은빛, 무지개, 순백, 칠흑, 주황, 연두

악세서리 (10종):
  왕관, 스카프, 안경, 리본, 날개장식,
  꽃, 모자, 목걸이, 깃털, 없음

→ 10 × 12 × 10 = 1,200가지 외형 조합!
```

### 4.3 크리처 스탯

```
┌──────────────────────┐
│   🐉 황금용 (Golden Dragon)    │
│   타입: 불 | 등급: Epic        │
├──────────────────────┤
│  HP     ████████░░ 156       │
│  공격   ██████████ 124       │
│  방어   ██████░░░░  89       │
│  속도   ████████░░ 104       │
│  특수   ███████░░░  98       │
├──────────────────────┤
│  특성: "용의 심장"             │
│  → 체력 30% 이하 시 공격 +50% │
└──────────────────────┘
```

**스탯 범위** (등급별 기본):
- Common: 각 스탯 30~80
- Uncommon: 각 스탯 36~96
- Rare: 각 스탯 45~120
- Epic: 각 스탯 54~144
- Legendary: 각 스탯 66~176

### 5.3 "니어미스" 효과 (가챠 심리)

```
카드 연출 시:
  초록빛 시작 → "에이, 일반이구나..."
  → 갑자기 파란빛으로 변환! → "오! 고급!?"
  → 다시 보라빛!! → "희귀?! 진짜?!"

  이 연출이 핵심. 등급이 올라갈 수 있다는
  "가능성"을 매번 보여줘서 기대감을 유지.
```

## 6. 방치형 시스템

### 6.1 탐험대 시스템

```
┌─────────────────────────────────────┐
│         탐험대 파견                    │
│                                       │
│  [파티 크리처 3마리]                    │
│     ↓                                  │
│  [탐험 지역 선택]                       │
│     숲의 오솔길 (2시간, 쉬움)           │
│     바다 동굴 (4시간, 보통)             │
│     용의 둥지 (8시간, 어려움)           │
│     ↓                                  │
│  [오프라인에서 자동 진행]               │
│     ↓                                  │
│  [접속 시 결과 확인]                    │
│     골드 + 아이템 + 경험치              │
│     (드물게 희귀 아이템!)               │
│                                       │
└─────────────────────────────────────┘
```

### 6.2 방치 보상 테이블

| 탐험 시간 | 난이도 | 골드 | 아이템 | 크리처 EXP |
|----------|-------|------|-------|-----------|
| 2시간 | 쉬움 | 100~300 | 일반 1~2개 | +20 |
| 4시간 | 보통 | 300~800 | 일반 2~3개 + 희귀 확률 | +50 |
| 8시간 | 어려움 | 800~2000 | 희귀 1~2개 + 에픽 확률 | +120 |
| 12시간 | 전설 | 2000~5000 | 에픽 확률 + 전설 아이템 확률 | +200 |

### 6.3 자동 수확 (자원 생성)

파티에 배치된 크리처가 시간당 자원을 자동 생산:
- 숲 타입: 시간당 약초 생성
- 바다 타입: 시간당 진주 생성
- 산 타입: 시간당 광석 생성
- 하늘 타입: 시간당 깃털 생성

## 7. 아이템 시스템

### 7.1 아이템 카테고리

| 카테고리 | 예시 | 획득처 | 효과 |
|---------|------|-------|------|
| **성장 아이템** | 경험치 사탕, 레벨업 물약 | 탐험, 퀘스트 | 크리처 레벨 상승 |
| **강화 아이템** | 공격의 돌, 방어의 씨앗 | 탐험, 상점 | 스탯 영구 증가 |
| **진화 재료** | 별의 파편, 무지개 이슬 | 탐험(어려움+) | 크리처 진화에 필요 |
| **소모품** | 에너지 음료, 행운의 클로버 | 상점, 일일보상 | 일시적 버프 |
| **장식 아이템** | 꽃 왕관, 별빛 날개 | 이벤트, 업적 | 크리처 외형 커스텀 |

### 7.2 아이템 등급

| 등급 | 확률(탐험) | 효과 |
|------|----------|------|
| 일반(흰색) | 60% | 기본 효과 |
| 고급(초록) | 25% | 1.5배 효과 |
| 희귀(파랑) | 10% | 2배 효과 |
| 영웅(보라) | 4% | 3배 효과 + 부가효과 |
| 전설(금색) | 1% | 5배 효과 + 고유효과 |

### 7.3 바코드 기반 아이템 풀

바코드의 **카테고리**에 따라 드롭되는 아이템이 달라짐:

```
음식 바코드 (880, 490 등)  → 성장 아이템 확률 UP
전자제품 바코드 (885, 489) → 강화 아이템 확률 UP
음료 바코드              → 에너지 회복 아이템 확률 UP
화장품/뷰티 바코드         → 장식 아이템 확률 UP
```

```
Phase 1 (0~1초): 스캔 라인 애니메이션
  ████████████████████ → 바코드 위를 빛이 지나감

Phase 2 (1~2초): 카드 등장
  카드가 화면 중앙에서 뒤집어지면서 등장
  뒷면에 등급에 따른 빛 색상 힌트

Phase 3 (2~3초): 카드 뒤집기 + 등급 공개
  [Common]   : 초록 빛 + 작은 반짝임
  [Uncommon] : 파란 빛 + 별똥별 효과
  [Rare]     : 보라 빛 + 마법진 효과
  [Epic]     : 금빛 + 폭발 파티클 + 화면 흔들림
  [Legendary]: 무지개 + 전체화면 빛 + 특수 BGM + 3초 연출

Phase 4 (3~4초): 크리처 정보 카드
  이름, 타입, 스탯, 특성 순차적 표시
  첫 발견 시 "NEW!" 스탬프 효과
```

## 9. 시스템 로직 상세

### 9.1 에너지 시스템

```
최대 에너지: 100 + (레벨 × 5)
스캔 비용: 10 에너지
자연 회복: 1 에너지 / 3분 (시간당 20)
만충전 시간: 약 5시간

레벨업 보너스: 에너지 전량 회복 + 최대치 +5
```

### 9.2 경험치 & 레벨 시스템

```
플레이어 레벨업 필요 경험치:
  Lv.1→2:   100 EXP
  Lv.2→3:   200 EXP
  Lv.N→N+1: N × 100 EXP

크리처 레벨업:
  Lv.1→2:   50 EXP
  Lv.2→3:   100 EXP
  Lv.N→N+1: N × 50 EXP (최대 Lv.30)

경험치 획득:
  바코드 스캔: 10~30 EXP (등급에 따라)
  배틀 승리: 20~100 EXP (상대 레벨에 따라)
  탐험 완료: 20~200 EXP (난이도에 따라)
  일일 퀘스트: 50~200 EXP
```

### 9.3 배틀 시스템 (간소화)

**자동 턴제 배틀** (방치형에 적합):

```
[플레이어 크리처] vs [상대 크리처]

턴 순서: 속도 높은 쪽 먼저
최대 10턴, 이후 HP 많은 쪽 승리

데미지 계산:
  기본데미지 = (공격력 × 레벨보정) ÷ (방어력 × 0.5)
  타입 상성: 유리 ×1.5, 불리 ×0.7
  치명타: 속도/500 확률, ×1.5 데미지
  편차: ×0.85~1.00 (랜덤)

행동 패턴 (자동):
  70% 확률: 일반 공격
  20% 확률: 특수 공격
  10% 확률: 방어 (방어력 2배)
```

### 9.4 진화 시스템 (신규)

```
진화 조건:
  1. 크리처 레벨 10 이상
  2. 진화 재료 보유 (등급별 다름)
  3. 골드 비용

진화 결과:
  - 외형 변화 (더 멋진 디자인)
  - 스탯 1.5배 증가
  - 새로운 특성 추가
  - 이름 변경 (접두어 추가: "빛나는", "고대의" 등)

예: "화염두꺼비" Lv.10 + 별의 파편 ×3 + 5000G
    → "빛나는 화염두꺼비" (진화!)
```
