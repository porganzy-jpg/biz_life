# 특허 출원 초안 #2: PromoMap (위치 기반 프로모션 앱)

## 발명의 명칭
사용자 소속 기관 복지 정보와 위치 정보를 연동한 실시간 할인 매장 매칭 및 알림 시스템

## 기술 분야
본 발명은 사용자의 실시간 위치 정보와 소속 기관(기업)의 복지 할인 정보를 매칭하여, 근처의 할인 가능 매장 정보를 자동으로 알려주는 시스템 및 방법에 관한 것이다.

## 배경 기술
기존의 위치 기반 쿠폰/할인 서비스(예: 배달의민족, 카카오맵)는 일반 소비자를 대상으로 한 범용 할인 정보를 제공한다. 그러나 기업 임직원 전용 할인 혜택은 별도의 사내 게시판이나 복지몰에서만 확인 가능하여, 실제 외출 시 활용도가 낮은 문제가 있었다.

## 핵심 청구 범위

### 청구항 1
사용자의 소속 기관 정보와 해당 기관의 복지 할인 제휴 매장 데이터베이스를 유지하고,
사용자의 실시간 GPS 위치를 모니터링하여,
소정 반경 이내에 복지 할인 가능 매장이 존재할 때,
해당 매장의 할인 정보와 거리를 포함하는 알림을 사용자에게 푸시하는 것을 특징으로 하는 시스템.

### 청구항 2
상기 시스템은 지오펜싱(Geofencing) 기술을 사용하여 백그라운드에서 위치를 모니터링하고,
배터리 효율을 위해 유의미한 위치 변화가 감지될 때만 매칭 프로세스를 수행하는 것을 특징으로 하는 방법.

### 청구항 3
복수의 기업 복지 할인 정보를 통합 관리하고,
시간대별(점심시간, 퇴근시간 등) 차등 할인율을 적용하며,
사용자의 방문 이력을 기반으로 개인화된 추천을 제공하는 것을 특징으로 하는 방법.

## 선행기술과의 차별점
1. "기업 복지 할인"이라는 특수 영역에 특화
2. 위치 기반 실시간 매칭 + 푸시 알림의 결합
3. 다중 기업 복지 정보 통합 관리
