# 특허 출원 초안 #1: 바코드 게임 (BarcodeQuest)

## 발명의 명칭
상품 바코드 정보 및 위치 정보 기반 게임 캐릭터 생성 시스템 및 방법

## 기술 분야
본 발명은 상품에 부착된 바코드의 구조적 정보를 분석하여 게임 캐릭터를 생성하는 시스템 및 방법에 관한 것으로, 더욱 상세하게는 바코드의 국가 코드, 제조사 코드, 상품 코드 등의 정보와 사용자의 GPS 위치 정보 및 시간 정보를 결합하여 결정적(deterministic)으로 고유한 게임 캐릭터를 생성하는 기술에 관한 것이다.

## 배경 기술
종래의 모바일 게임에서 캐릭터를 획득하는 방식은 주로 가챠(랜덤 뽑기) 또는 게임 내 보상 방식이 사용되어 왔다. 포켓몬GO와 같은 AR 게임에서는 GPS 기반으로 가상 캐릭터를 배치하는 방식이 사용되었으나, 이는 현실 세계의 물리적 상품과의 연계가 없었다.

상품 바코드는 전 세계적으로 표준화된 정보 체계(EAN-13, UPC-A 등)를 가지고 있으며, 국가 코드, 제조사 코드, 상품 코드 등 구조화된 정보를 포함하고 있다. 그러나 이러한 바코드 정보를 게임 캐릭터의 속성 생성에 활용하는 기술은 종래에 존재하지 않았다.

## 발명이 해결하고자 하는 과제
1. 현실 세계의 상품 바코드를 게임 콘텐츠와 연결하여, 사용자가 현실 탐험을 통해 게임 콘텐츠를 획득하도록 함
2. 바코드의 구조적 정보를 활용하여 일관성 있고 재현 가능한 캐릭터 생성 방법 제공
3. GPS 위치 및 시간 정보와의 결합으로 동일 상품에서도 다양한 변형 캐릭터 생성 가능
4. 상품 제조사와의 프로모션 연계를 통한 비즈니스 모델 구현 기반 마련

## 과제의 해결 수단

### 핵심 구성 요소

#### 1. 바코드 파싱 모듈
- EAN-13 바코드를 국가 코드(3자리), 제조사 코드(4-5자리), 상품 코드(4-5자리), 체크 디짓(1자리)으로 분리
- 각 코드 세그먼트를 캐릭터 속성 결정의 입력값으로 활용

#### 2. 컨텍스트 결합 시드 생성 모듈
- 바코드 정보 + GPS 좌표(양자화) + 시간대 정보를 결합
- SHA-256 해시 함수를 통해 결정적 시드(Deterministic Seed) 생성
- 동일 입력에 대해 항상 동일한 출력을 보장 (재현성)

#### 3. 속성 매핑 엔진
- 시드값의 각 구간을 캐릭터의 속성(타입, 능력치, 외형, 희귀도)에 분배
- 국가 코드 → 캐릭터 원산지 및 주 타입 결정
- 제조사 코드 → 부 타입 및 이름 접두사 결정
- 상품 코드 → 능력치 세부 분배
- 체크 디짓 → 희귀도 보정

#### 4. 위치 보너스 모듈
- GPS 좌표를 기반으로 스캔 장소의 특성 판별 (마트, 편의점, 학교 등)
- 장소 특성에 따른 능력치 보너스 적용
- 특정 지역 최초 스캔 시 추가 보너스 부여

#### 5. 시간대 변형 모듈
- 스캔 시각에 따라 Dawn/Day/Dusk/Night 4단계 구분
- 동일 바코드 + 동일 위치라도 시간대에 따라 다른 변형(Variant) 생성

### 시스템 구성도
```
[상품 바코드] → [바코드 스캐너] → [바코드 파서]
                                      ↓
[GPS 모듈] → [위치 양자화] ──────→ [시드 생성기] → [해시 함수]
                                      ↑                ↓
[시계 모듈] → [시간대 분류] ──────┘        [속성 매핑 엔진]
                                              ↓
                                    [캐릭터 조립 모듈]
                                              ↓
                                    [게임 캐릭터 출력]
```

## 청구항

### 청구항 1 (독립항)
상품 바코드의 구조적 정보를 분석하여 게임 캐릭터를 생성하는 방법에 있어서,
(a) 상품에 부착된 바코드를 스캔하여 국가 코드, 제조사 코드, 상품 코드를 포함하는 바코드 정보를 추출하는 단계;
(b) 상기 바코드 정보와 사용자 단말의 GPS 위치 정보 및 현재 시간 정보를 결합하여 고유한 시드값을 생성하는 단계;
(c) 상기 시드값을 기반으로 게임 캐릭터의 속성(타입, 능력치, 외형, 희귀도)을 결정적으로 산출하는 단계;
(d) 상기 GPS 위치 정보에 기반한 위치 보너스를 적용하는 단계; 및
(e) 상기 산출된 속성과 위치 보너스가 적용된 게임 캐릭터를 사용자에게 제공하는 단계;
를 포함하는 것을 특징으로 하는 바코드 기반 게임 캐릭터 생성 방법.

### 청구항 2 (종속항)
제1항에 있어서, 상기 (b) 단계에서 GPS 좌표를 소정의 격자 단위로 양자화하고, 시간 정보를 복수의 시간대로 분류하여, 동일 바코드를 다른 위치 또는 다른 시간대에서 스캔할 때 서로 다른 변형 캐릭터를 생성하는 것을 특징으로 하는 방법.

### 청구항 3 (종속항)
제1항에 있어서, 상기 (c) 단계에서 국가 코드를 캐릭터의 원산지 및 주 타입에 매핑하고, 제조사 코드를 부 타입에 매핑하며, 상품 코드를 능력치 분배에 활용하는 것을 특징으로 하는 방법.

### 청구항 4 (장치 청구항)
상품 바코드 기반 게임 캐릭터 생성 시스템에 있어서,
- 바코드 스캔 모듈;
- GPS 수신 모듈;
- 바코드 정보, GPS 위치 정보, 시간 정보를 결합하여 결정적 시드를 생성하는 시드 생성부;
- 상기 시드에 기반하여 캐릭터 속성을 산출하는 속성 매핑부;
- 위치 기반 보너스를 적용하는 위치 보너스 처리부; 및
- 생성된 캐릭터를 저장 및 표시하는 캐릭터 관리부;
를 포함하는 것을 특징으로 하는 시스템.

## 발명의 효과
1. 사용자가 현실 세계를 탐험하며 다양한 상품의 바코드를 스캔하여 고유한 게임 캐릭터를 수집하는 새로운 형태의 게임 경험 제공
2. 동일 상품이라도 스캔 장소와 시간에 따라 다른 변형 캐릭터 생성, 반복 탐험 동기 부여
3. 상품 제조사와의 프로모션 연계 가능 (신제품 바코드 → 한정 캐릭터)
4. 바코드라는 보편적 인프라를 활용하여 추가 하드웨어 없이 구현 가능
