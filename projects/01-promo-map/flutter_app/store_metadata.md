## 전체 설명
🗺️ PromoMap - 직장인 할인 지도

직장 주변의 할인 혜택, 놓치고 계셨나요?
PromoMap은 직장인 복지와 연계된 주변 할인 매장을 지도에서 한눈에 보여주는 서비스입니다.

📍 주요 기능

• 실시간 주변 매장 탐색
  - GPS 기반으로 현재 위치 주변의 할인 매장을 지도에서 확인
  - 카테고리별 필터링 (음식점, 카페, 편의점, 마트 등)

• 할인 혜택 정보
  - 매장별 할인율과 할인 조건을 한눈에 확인
  - 우리 회사 전용 제휴 할인 혜택

• 매장 상세 정보
  - 주소, 전화번호, 카테고리 등 상세 정보
  - 다른 이용자들의 리뷰와 별점

• 즐겨찾기
  - 자주 가는 매장을 즐겨찾기에 저장
  - 언제든 빠르게 접근

• 리뷰 & 별점
  - 이용한 매장에 리뷰와 별점을 남겨보세요
  - 동료들의 솔직한 후기 확인

• 할인 사용 내역
  - 내가 받은 할인 혜택을 기록하고 관리

🔒 안심하고 사용하세요
- 위치 정보는 주변 매장 검색에만 사용됩니다
- 개인정보는 안전하게 암호화되어 보관됩니다

💼 회사 담당자분들께
- 직원 복지 프로그램과 연계하여 사용할 수 있습니다
- 제휴 매장 등록 및 관리 기능을 제공합니다

## 스크린샷 설명 (5장 필요)
1. 지도 화면 - 주변 할인 매장이 지도에 표시된 메인 화면
2. 매장 상세 - 매장 정보와 할인 혜택이 표시된 상세 화면
3. 검색 - 매장 검색 결과 화면
4. 즐겨찾기 - 즐겨찾기 목록 화면
5. 마이페이지 - 프로필과 사용 내역 화면
