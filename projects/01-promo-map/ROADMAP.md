## STEP 1: Google Maps API 키 발급

### 왜 필요한가?
앱에서 구글 지도를 표시하려면 API 키가 필수입니다. (무료)

### 하는 방법
1. https://console.cloud.google.com 접속
2. 새 프로젝트 생성 ("PromoMap")
3. API 및 서비스 > 라이브러리
4. "Maps SDK for Android" 검색 → 사용 설정
5. 사용자 인증 정보 > API 키 생성
6. 생성된 키를 복사

### 키를 앱에 적용
Claude에게 말하면 됩니다:
> "Google Maps API 키 `AIzaSy...` 발급했어, 앱에 적용해줘"

적용할 위치:
- `android/app/src/main/AndroidManifest.xml` → `YOUR_GOOGLE_MAPS_API_KEY_HERE` 교체

### 비용
- 월 $200 무료 크레딧 (약 28,000건 지도 로드)
- 일반적인 사용량으로는 무료 범위 내

## STEP 2: AdMob 계정 + 광고 ID 발급

### 왜 필요한가?
현재 테스트 광고 ID가 들어가 있습니다. 실제 수익을 받으려면 본인 AdMob 계정의 실제 ID가 필요합니다.

### 하는 방법
1. https://admob.google.com 접속
2. AdMob 가입 (Google 계정 필요)
3. "앱 추가" → Android → "com.promomap.app"
4. 광고 단위 생성:
   - 배너 광고 1개
   - 전면(인터스티셜) 광고 1개
5. 앱 ID + 광고 단위 ID를 복사

### ID를 앱에 적용
Claude에게 말하면 됩니다:
> "AdMob 앱 ID `ca-app-pub-xxx~yyy`, 배너 ID `ca-app-pub-xxx/aaa`, 전면 ID `ca-app-pub-xxx/bbb` 발급했어, 적용해줘"

적용할 위치:
- `AndroidManifest.xml` → AdMob 앱 ID
- `lib/core/ads/ad_helper.dart` → 각 광고 단위 ID

### 비용
- 완전 무료 (수익은 사용자가 광고를 보거나 클릭할 때 발생)

## STEP 7: AAB 빌드 + 서명

### 왜 필요한가?
Play Store에 올릴 앱 파일(AAB)을 만들어야 합니다.

### 순서
Claude에게 말하면 됩니다:
> "앱 서명 keystore 생성하고 AAB 빌드해줘"

```bash
# 1. keystore 생성 (최초 1회, 분실하면 업데이트 불가!)
keytool -genkey -v -keystore promomap-release.jks \
  -keyalg RSA -keysize 2048 -validity 10000 \
  -alias promomap

# 2. AAB 빌드
flutter build appbundle --release

# 결과물: build/app/outputs/bundle/release/app-release.aab
```

### 중요
- **keystore 파일은 절대 잃어버리면 안 됩니다!** (백업 필수)
- 잃어버리면 앱 업데이트가 불가능합니다
- USB, 클라우드, 별도 폴더에 복사해 두세요
