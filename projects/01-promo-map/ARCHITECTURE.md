사용자 폰의 GPS → 서버에 "주변 매장 알려줘" 요청 → 서버가 매장 목록 응답 → 지도에 표시

## 3. 사용자가 앱을 쓸 때 일어나는 일

### 시나리오 1: "앱을 열었다"

```
① 앱 시작 (main.dart)
   └─ 광고 시스템 초기화 (AdMob)
   └─ 환경 설정 로드 (.env)

② 스플래시 화면 (splash_screen)
   └─ "이 사람 전에 로그인한 적 있나?" 확인
   └─ 저장된 토큰이 있으면 → 자동 로그인
   └─ 없으면 → 그냥 지도 화면으로

③ 메인 화면 (shell_screen)
   └─ 하단 4개 탭: 지도 | 검색 | 즐겨찾기 | MY
```

### 시나리오 2: "지도에서 주변 매장 보기"

```
① 지도 화면 열림 (map_screen)
        ↓
② 폰 GPS 켜짐 → "내 위치: 서울 강남 37.50, 127.04"
        ↓
③ 서버에 요청 전송:
   "GET /api/v1/stores/nearby?lat=37.50&lng=127.04&radius=500"
        ↓
④ 서버가 응답:
   [{이름: "VIPS 강남점", 할인: "30%", 거리: "200m"},
    {이름: "올리브영", 할인: "15%", 거리: "350m"}, ...]
        ↓
⑤ 지도에 주황색 마커 표시 + 하단에 매장 카드 리스트
```

### 시나리오 3: "매장 상세 보기"

```
① 매장 카드 탭 (store_detail_screen)
        ↓
② 서버에서 상세 정보 가져옴:
   - 매장명, 주소, 전화번호
   - 할인 혜택 목록
   - 평균 별점 + 리뷰 목록
        ↓
③ 3번째 매장을 볼 때 → 전면 광고 한번 표시 (수익!)
        ↓
④ 하단에 배너 광고도 표시 (수익!)
```

### 시나리오 4: "회원가입 → 즐겨찾기"

```
① 하트 버튼 탭 → "로그인이 필요합니다" 팝업
        ↓
② 이메일/비밀번호 입력 → 서버에 "POST /auth/register"
        ↓
③ 서버: 비밀번호 암호화 → DB에 저장 → JWT 토큰 발급
        ↓
④ 앱: 토큰을 안전한 저장소에 보관 (FlutterSecureStorage)
        ↓
⑤ 다시 하트 탭 → 즐겨찾기에 추가됨!
   (다음에 앱 열면 자동 로그인)
```

## 5. 데이터는 이렇게 흐른다

### 로그인 흐름

```
사용자: "로그인 버튼 클릭"
  │
  ▼
[LoginForm] 이메일/비밀번호 입력
  │
  ▼
[AuthNotifier] 로그인 로직 실행
  │
  ▼
[AuthRepository] → [AuthAPI] → "POST /api/v1/auth/login"
  │                              {email: "...", password: "..."}
  ▼
[서버] 비밀번호 확인 → JWT 토큰 2개 발급
       (access_token: 1시간, refresh_token: 30일)
  │
  ▼
[SecureStorage] 토큰을 암호화해서 폰에 저장
  │
  ▼
[AuthState] → isAuthenticated = true
  │
  ▼
화면이 자동으로 업데이트됨 (Riverpod이 감지)
```

### 토큰 자동 갱신 (사용자가 모르는 사이에)

```
앱 사용 중 서버 요청
  │
  ▼
[AuthInterceptor] "모든 요청에 토큰 자동 첨부"
  │
  ├─ 서버 응답: 200 OK → 정상 진행
  │
  └─ 서버 응답: 401 만료됨!
       │
       ▼
     [자동으로 refresh_token으로 새 토큰 발급]
       │
       ▼
     [원래 요청을 새 토큰으로 다시 시도]
       │
       ▼
     사용자는 아무것도 모른 채 정상 사용
```

## 6. 광고는 이렇게 동작한다

```
앱 시작 시:
  └─ MobileAds.instance.initialize()  (광고 시스템 준비)

검색/즐겨찾기/매장상세 화면:
  └─ BannerAdWidget 로드  (하단 고정 배너)
     └─ Google에서 광고 받아옴 → 화면에 표시
     └─ 사용자가 보거나 클릭하면 → 수익 발생

매장 상세 화면 (3번째 방문마다):
  └─ AdManager.showInterstitial()  (전면 광고)
     └─ 5초 정도 전체 화면 광고 표시
     └─ 사용자가 닫으면 → 매장 상세 보임
     └─ 수익은 배너보다 5~10배 높음
```

## 7. 기술 선택 이유 (왜 이걸 썼나?)

| 기술 | 선택 이유 |
|------|----------|
| **Flutter** | 코드 1번 작성하면 Android + iOS + Web 전부 가능. 네이티브에 가까운 성능 |
| **Riverpod** | 데이터가 바뀌면 관련 화면만 자동으로 새로고침. 코드가 깔끔해짐 |
| **Dio** | 토큰 만료 시 자동 갱신 기능을 인터셉터로 구현 가능 |
| **GoRouter** | 딥링크 지원 (나중에 "promomap.co.kr/store/5" 같은 URL로 앱 열기) |
| **Google Maps** | 전세계에서 가장 많이 쓰는 지도. Flutter 공식 플러그인 존재 |
| **FastAPI** | Python으로 빠르게 API 개발. 자동 API 문서 생성 |
| **SQLite → PostgreSQL** | 로컬에선 파일 1개로 간편하게, 프로덕션에선 PostgreSQL로 동시접속 대응 |
| **AdMob** | Google 공식 광고 플랫폼. Flutter 공식 지원. 가장 큰 광고 네트워크 |
| **JWT 토큰** | 서버에 세션 저장 불필요. 앱에 토큰만 저장하면 됨. 확장성 좋음 |

## 8. 보안 구조

```
비밀번호: bcrypt 해싱 (복호화 불가능)
토큰 저장: FlutterSecureStorage (AES 암호화)
API 통신: HTTPS (SSL/TLS 암호화)
토큰 만료: access 1시간, refresh 30일
CORS: 허용된 도메인만 API 접근 가능
Rate Limiting: 로그인 10회/분, 검색 60회/분 제한
```
