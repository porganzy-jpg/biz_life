# 녹음 대본 (학습 최적화판)

> 기존 유튜브 학습 데이터 2,188자를 분석해 **비어 있는 소리와 음역만** 골라 만든 대본입니다.
> 총 약 7분. 녹음 파일은 `media/song/rvc/my_recordings/` 에 넣어 주세요.
>
> **분석 결과**
> - 초성 19개는 이미 충분 → 대본에서 신경 쓸 필요 없음
> - **받침 8개가 아예 없음**: ㄲ ㄳ ㄵ ㄽ ㄾ ㄿ ㅊ ㅋ / 3개 희소: ㄺ ㄼ ㅀ
> - **모음 ㅞ 없음, ㅙ 희소**
> - 음높이가 110~130Hz에 47% 몰림. 낮은 톤(90Hz 이하) 7%, 높은 톤(150Hz 이상) 11%뿐
>   → 그 음역에서 음색이 무너지므로 낮게·높게 말하는 구간을 일부러 넣었습니다

## 녹음 요령

| 항목 | 기준 |
|---|---|
| 장소 | 조용한 방. 에어컨·선풍기·공기청정기 끄기 |
| 거리 | 휴대폰이면 입에서 20cm, 정면에서 살짝 비껴서 |
| 톤 | **평소 유튜브에서 말하듯이.** 또박또박 낭독하면 오히려 본인 목소리에서 멀어집니다 |
| 실수 | 멈추지 말고 3초 쉰 뒤 그 문장부터 다시. 편집은 제가 합니다 |
| 파일 | 부(部)별로 나눠도 되고 한 파일로 쭉 녹음해도 됩니다 |

## 1부. 쇼츠 나레이션 — 실사용 (1분)

영상에 그대로 들어갑니다. **문장 사이 1초씩 쉬고, 쉼표에서 살짝 멈춰** 주세요.

```
혼자 사는 아저씨가 게임을 만들었습니다.
3층짜리 버스입니다.
주방, 공방, 침실. 집이 굴러갑니다.
바코드를 찍으면 동료가 탑니다.
이 친구는 잠이. 눈이 안 보입니다.
생전에 못 가본 곳을,
대신 가주는 버스.
이 버스는, 사실 천국입니다.
이렇게 살아도, 삽니다.
오늘 뭐 사셨어요? 그게 당신 몬스터입니다.
```

## 2부. 빠진 소리 채우기 (1분 30초)

기존 데이터에 없던 받침과 모음이 들어 있습니다. **평소 말투로** 읽어 주세요.

```
부엌 밖에서 닭이 울고, 흙 묻은 꽃이 피었다.
여덟 시에 앉아서 신문을 읽고 밥을 볶았다.
밟지 마, 넓은 마당에 낚싯대를 놨어.
그건 옳지 않아. 싫으면 싫다고 말해.
내 몫은 얼마야? 넋 놓고 앉아 있었다.
강아지가 그릇을 핥고, 나는 시를 읊었다.
밝을 때 떠나서 맑은 하늘을 봤다.
몇 시야? 빛이 낯설고 볕이 뜨겁다.
웬일로 이렇게 일찍 왔어? 괜찮은 거야?
궤도를 벗어나면 왜 안 되는데?
쾌활하게 웃으면서 훼방을 놓네.
외곬으로 살다 보니 삯도 못 챙겼다.
깎고 닦고 볶다 보면 하루가 다 간다.
얘, 뻔뻔하게 귀뚜라미 흉내 내지 마.
```

## 3부. 낮은 톤 (40초)

**평소보다 한 톤 낮고 느리게, 혼잣말하듯** 말씀해 주세요. 90Hz 이하 구간을 채웁니다.

```
그냥... 오늘은 아무것도 하기 싫다.
뭐, 그럴 수도 있지.
됐어. 그만하자.
예전엔 안 그랬는데.
밤이 깊었네.
조용히 있고 싶다.
```

---

## 4부. 높은 톤 (40초)

**평소보다 밝고 높게, 놀란 것처럼** 말씀해 주세요. 150Hz 이상 구간을 채웁니다.

```
어? 이게 왜 여기 있지?
와, 진짜 대박인데?
야! 흰둥아, 안 돼!
진짜요? 그게 된다고요?
축하합니다! 전설 등급입니다!
아니 그게 아니라니까?
```

## 5부. 긴 모음 (40초)

RVC가 음색의 뼈대를 배우는 데 가장 효율적인 부분입니다.
**한 소리를 3초씩 평탄하게** 내 주세요. 사이에 1초 쉬고요.

```
아 —————

```

## 6부. 자유 발화 (2분) — 품질에 가장 크게 기여

대본 없이 평소처럼 혼잣말하듯 말씀해 주세요.
**낭독보다 자유 발화가 억양·호흡이 자연스러워 학습 효과가 가장 큽니다.**
웃음, 한숨, "어…" 같은 군말이 섞여도 좋습니다. 오히려 도움이 됩니다.

주제 예시
- 오늘 뭐 먹었고 편의점에서 뭘 샀는지
- 흰둥이가 요즘 뭘 하는지, 산책은 어디로 가는지
- 최근에 본 영화나 드라마 감상
- 이 게임을 왜 만들고 싶었는지

1. 무음 기준 자동 분할 + 음량 정규화 + 잡음 구간 제외

3. **2~6부** → 기존 유튜브 데이터와 합쳐 재학습용 데이터셋 구성
4. 재학습 설정 정리 후 Colab 절차 안내
