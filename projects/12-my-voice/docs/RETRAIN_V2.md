# 재학습 (v2) — 준비 완료

## 왜 하는가 — 측정 근거

새로 녹음해 주신 **깨끗한 음성을 기준**으로 재니 원인이 드러났습니다.

| 비교 대상 | 음색 거리 |
|---|---|
| 내 녹음끼리 (도달 가능한 최저선) | **12.8** |
| 변환 결과 + EQ 후처리 (현재) | 19.1 |
| 변환 결과 (후처리 전) | 34.0 |
| **유튜브 음원 vs 내 실제 목소리** | **39.7** |

마지막 줄이 핵심입니다. v1 모델의 학습 데이터인 유튜브 음원 자체가 실제 목소리에서 39.7만큼 떨어져 있어,
**유튜브 압축과 당시 마이크 특성까지 음색으로 배웠습니다.** 후처리는 증상을 가리는 것이고 재학습이 원인을 없앱니다.

## 데이터 — `ajossi_v2_dataset.zip` (44MB, 증강 없음)

| 구성 | 분량 | 비중 |
|---|---|---|
| 직접 녹음 1차 (2~6부, 나레이션 제외) | 2.2분 | |
| 직접 녹음 2차 (자유 발화 전체) | 2.8분 | |
| **깨끗한 녹음 소계** | **4.9분 / 35클립** | **49%** |
| 유튜브 음원 (94클립 중 잡음 적은 상위 30개) | 5.0분 | 51% |
| **합계** | **10.0분 / 65클립** | |

- v1은 유튜브 100%였고, v2는 절반이 깨끗한 직접 녹음입니다.
- 유튜브 클립은 스펙트럼 평탄도로 줄세워 잡음이 적은 것만 골랐습니다.
- 두 녹음의 음색 거리는 18.3(유튜브는 37.4)이라 같은 사람·비슷한 환경으로 확인됐습니다.
  1차는 낭독, 2차는 자유 발화라 음높이 중앙값이 120Hz와 99Hz로 갈려 음역 다양성에도 도움이 됩니다.
- 1부 나레이션은 학습에서 제외했습니다. 쇼츠에 원본 그대로 쓸 것이기 때문입니다.
