# 노래 학습용 녹음 대본

> **왜 필요한가**: 지금 모델의 학습 데이터는 전부 말소리다. 노래를 한 번도 본 적이 없어서
> 긴 음, 비브라토, 높은 음에서 음색이 흔들린다. 음정·박자는 원곡을 정확히 따라가지만
> (측정 오차 0.06반음) "잘 못 부르는 느낌"이 나는 이유가 이것이다.
>
> **노래 녹음 3~5분**을 학습 데이터에 넣으면 이 부분이 크게 개선된다.
> 음정이 틀려도 상관없다. 모델은 음색만 배운다.

---

## 녹음 요령

| 항목 | 기준 |
|---|---|
| 반주 | **없이 불러 주세요.** 반주가 섞이면 학습 데이터로 못 씁니다. 이어폰으로 들으며 목소리만 녹음 |
| 장소·거리 | 말할 때와 동일 (조용한 방, 입에서 20cm, 살짝 비껴서) |
| 음역 | 편한 음역으로. 무리해서 높이 올리지 마세요 |
| 실수 | 음정 틀려도 그냥 계속. 편집은 제가 합니다 |

## 1부 · 긴 음 (1분) — 가장 중요

한 소리를 **5초씩 흔들림 없이** 끌어 주세요. 사이에 2초 쉬고요.
같은 음을 낮게 / 중간 / 높게 세 번씩 반복합니다.

```
아 —————————   (낮게)
아 —————————   (평소 말하는 높이)
아 —————————   (편하게 올릴 수 있는 만큼)

에 —————————   (낮게 / 중간 / 높게)
이 —————————   (낮게 / 중간 / 높게)
오 —————————   (낮게 / 중간 / 높게)
우 —————————   (낮게 / 중간 / 높게)
```

## 2부 · 음계 오르내리기 (1분)

"아" 하나로, 도레미파솔파미레도를 천천히 오르내려 주세요. 세 번 반복.
음정이 정확하지 않아도 됩니다. **음높이가 이어지며 변하는 소리**가 필요한 것입니다.

```
아~~~~~~~~~ (낮은음에서 높은음으로 천천히 미끄러지듯)
아~~~~~~~~~ (높은음에서 낮은음으로)
```
이 미끄러지는 소리도 3회씩 해주시면 좋습니다.

## 3부 · 아는 노래 (2~3분)

가사가 있는 노래를 **반주 없이** 불러 주세요. 아무 노래나 괜찮습니다.

- 애국가, 아리랑, 생일 축하합니다 같은 익숙한 곡
- 좋아하는 발라드 한 곡
- 콧노래(허밍)도 30초 정도 섞어주시면 좋습니다

부드러운 곡과 힘 있는 곡을 섞으면 더 좋습니다.
