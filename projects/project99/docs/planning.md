# AutoIncome - 디지털 상품 자동생성 파이프라인 기획서

## 1. 프로젝트 개요

### 목표
초기 투자 0원으로, 로컬 PC에서 자동 실행되는 디지털 상품 생성 시스템을 구축하여
Etsy, Gumroad, Redbubble 등 무료 마켓플레이스에서 수동적 수익(Passive Income)을 창출한다.

### 핵심 컨셉
- **Create Once, Sell Forever**: 디지털 상품은 한 번 만들면 무한 재판매 가능
- **Volume Strategy**: 대량 생성 → 시장에서 자연 선별 → 히트 상품 발굴
- **Zero Marginal Cost**: 추가 판매 시 비용 0원

## 3. 상품 카테고리

### 3-1. 디지털 월페이퍼 (Phone & Desktop Wallpapers)
- **수요**: Etsy에서 "digital wallpaper" 월간 검색 50,000+
- **가격**: $1.99-$4.99 (묶음 $5.99-$14.99)
- **생성 방식**: 그라디언트, 추상화, 미니멀, 패턴
- **사이즈**: Phone (1080x1920), Desktop (2560x1440), iPad (2048x2732)

### 3-2. 인용구 아트프린트 (Quote Art Prints)
- **수요**: "inspirational quote print" 월간 검색 30,000+
- **가격**: $2.99-$7.99
- **생성 방식**: 타이포그래피 + 배경 디자인
- **사이즈**: A4 (2480x3508), 8x10in (2400x3000), 11x14in

### 3-3. 심리스 패턴 (Seamless Patterns)
- **수요**: 디자이너, POD 셀러들의 B2B 수요
- **가격**: $3.99-$9.99
- **생성 방식**: 타일형 반복 패턴 자동생성
- **사이즈**: 3600x3600 (300dpi)

### 3-4. POD 디자인 (Print-on-Demand Ready)
- **수요**: 티셔츠, 머그컵, 폰케이스 디자인
- **가격**: Redbubble 로열티 $2-5/건
- **생성 방식**: 텍스트 기반 + 그래픽 요소
- **사이즈**: 4500x5400 (투명 배경 PNG)

## 4. 시스템 아키텍처

```
┌─────────────────────────────────────────────────┐
│                  AutoIncome                       │
├─────────────────────────────────────────────────┤
│                                                   │
│  [Config] ─→ [Trend Scanner] ─→ [Niche Queue]   │
│                                                   │
│  [Niche Queue] ─→ [Design Engine] ─→ [Output]   │
│                      │                            │
│              ┌───────┼───────┐                    │
│              │       │       │                    │
│           Wallpaper Quote  Pattern   POD          │
│           Generator Generator Generator Generator │
│                                                   │
│  [Output] ─→ [Listing Generator] ─→ [CSV/JSON]  │
│                                                   │
│  [Scheduler] ─→ 매일 자동 실행 (Windows Task)     │
│                                                   │
└─────────────────────────────────────────────────┘
```

### 모듈 구성
1. **config.py** - 설정 관리 (니치, 색상 팔레트, 폰트 등)
2. **trends/niche_finder.py** - 트렌드 키워드/니치 분석
3. **design/wallpaper_gen.py** - 월페이퍼 자동생성 (그라디언트, 추상화)
4. **design/quote_gen.py** - 인용구 아트프린트 생성
5. **design/pattern_gen.py** - 심리스 패턴 생성
6. **design/pod_gen.py** - POD 디자인 생성
7. **listing/seo_optimizer.py** - SEO 메타데이터 생성
8. **main.py** - 전체 파이프라인 오케스트레이터
9. **run.py** - 엔트리포인트 + 스케줄러

## 7. 수익화 로드맵

### Phase 1: 시스템 구축 + 첫 업로드 (1-2주)
- 자동생성 시스템 완성
- 첫 100개 상품 Etsy + Gumroad에 업로드
- Redbubble에 POD 디자인 50개 업로드

### Phase 2: 스케일업 (2-8주)
- 매일 50개 자동생성 → 주말에 일괄 업로드
- 판매 데이터 분석 → 잘 팔리는 스타일 집중
- 상품 설명/태그 최적화

### Phase 3: 최적화 (2-6개월)
- A/B 테스트 (색상, 스타일, 가격)
- 히트 상품 변형 대량 생성
- 번들 상품 구성 (10개 묶음, 50개 묶음)
- 소셜 미디어 자동 홍보 추가
