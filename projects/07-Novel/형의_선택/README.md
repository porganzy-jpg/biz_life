# 형의 선택

장애가 심했지만 누구보다 처절하게 살아 성공한 형이, 모두가 그를 완전히 행복하다고 믿는 정점에서 스스로 삶을 끝낸다. 동생은 형을 아는 괴인들과 함께 형의 삶을 거슬러 고향에 닿고, 형이 평생 '고를 수 없었다'는 것을 알게 된다. 같은 뼈대를 열두 가지 배경과 결말로 쓴 판본 모음.

## 원칙

- 형을 죽게 한 것은 몸이 아니라 '고를 수 없음'이다. 장애를 감동의 도구로 쓰지 않는다.
- 자살 방법은 어느 판본에도 쓰지 않는다. 죽음을 미화하지 않는다.
- 형의 논리를 존중하되 이야기가 그것을 정답으로 선언하지 않는다.
