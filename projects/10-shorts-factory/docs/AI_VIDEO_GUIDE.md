# AI 영상 제작 가이드

> 이 PC(GTX 1050, VRAM 2GB)에서는 **로컬 생성이 불가능합니다.**
> 가장 가벼운 모델(LTX-Video)도 VRAM 8GB가 최소입니다. 웹 서비스를 씁니다.

---

## 원칙: 텍스트가 아니라 "까뮈 사진"에서 시작한다

텍스트로 "검은 프렌치 불독"을 매번 생성하면 **컷마다 다른 개**가 나옵니다. 88컷이면 88마리.

image-to-video(i2v)는 **넣은 이미지를 그대로 유지하면서 움직임만** 만듭니다.
그러니 시작 이미지를 **실제 까뮈·바위 사진**으로 쓰세요.

- 캐릭터 일관성 문제가 통째로 사라짐
- 이미지 생성 크레딧을 안 씀 (영상 크레딧만)
- AI로 만든 영상인데 등장하는 개는 진짜 까뮈

**text-to-video는 쓰지 마세요.** 사물·배경 인서트에만 예외적으로 씁니다.

**사진 촬영 요령**

- 배경은 단순하게. 잡동사니가 많으면 AI가 그걸 움직이려다 화면이 뭉개짐
- 물그릇은 **흰색/투명** (검은 개 + 검은 그릇이면 발이 안 보임)

## 3단계 — 생성 설정

```
모드      : Image to Video (i2v)
시작 이미지: ref_kkamu_front.jpg
비율      : 9:16 (세로)
길이      : 5초 (짧을수록 실패율이 낮음)
모션 강도  : 낮음 / Low
```

**프롬프트는 `AI_PROMPTS.md`에 컷별로 다 써뒀습니다.**

### 프롬프트 3원칙

1. **움직임을 작게.** `subtle`, `slow`, `slight`만 쓰세요. 큰 동작을 요구하면 다리가 늘어나고 얼굴이 녹습니다. 동물 i2v가 깨지는 원인 1위입니다.
2. **카메라는 고정.** `static camera, no camera movement`. 카메라를 움직이면 개의 형태가 무너집니다.
3. **입 모양은 요구하지 마세요.** 더빙 스타일이라 립싱크가 필요 없습니다. `talking`, `barking`을 넣으면 얼굴이 일그러집니다.

## 4단계 — 생성 1회로 컷 여러 개 만들기

**이게 무료로 버티는 핵심입니다.**

서비스는 5초를 뽑아주는데 제 대본은 컷이 1~3초입니다. 즉 **5초 생성 1회 = 컷 3~4개**.

`kkamu_front_take.mp4` 5초짜리를 받았다면:

```markdown
| 3  | 1.0 | kkamu_front_take.mp4@0.2 | 까뮈 | 일어나. | | |
| 5  | 1.2 | kkamu_front_take.mp4@1.6 | 까뮈 | 5분 뒤엔 지각이야. | | |
| 7  | 1.0 | kkamu_front_take.mp4@3.1 | 까뮈 | 그게 돼? | | |
```

같은 클립의 다른 구간이라 표정이 미묘하게 달라 반복으로 안 보입니다.
**88컷을 88번 생성할 필요가 없습니다. 20~25회면 충분합니다.**

---

> **정지 이미지로 캐릭터 테이크를 때울 수 없습니다.** 실측으로 확인했습니다.
> 이미지를 넣으면 `@초`가 가리킬 다른 순간이 없어서, 한 편에서 12번 말하는 바위가
> 12번 다 똑같은 얼굴로 나옵니다. `KENBURNS_FRAMINGS`(크롭 위치 변경)로 완화는 되지만
> 근본 해결은 아닙니다. **캐릭터는 반드시 움직이는 5초 영상으로 뽑으세요.**
> 정지 이미지는 1~2회만 등장하는 사물/배경용입니다.

## 5단계 — 파이프라인에 넣기

1. 생성된 mp4 다운로드
2. `clips/` 에 넣고 이름을 대본의 클립 칸과 맞춤
3. `python make.py --all`

끝입니다. 스토리보드 카드가 그 컷부터 자동으로 사라집니다.

```bash
python make.py --all --shotlist   # 아직 안 채운 컷 확인
```

## 실패했을 때

| 증상 | 원인 | 대응 |
|---|---|---|
| 다리가 늘어나거나 발이 여러 개 | 모션 강도 과다 | `subtle`만 남기고 동작 서술 삭제, 강도 Low |
| 얼굴이 다른 개로 변함 | 레퍼런스가 어둡거나 흐림 | 밝은 정면 사진으로 교체 |
| 화면이 전체적으로 출렁임 | 배경이 복잡 | 단순한 배경에서 다시 촬영 |
| 물이 이상하게 움직임 | 액체는 AI 취약점 | 물결 서술 빼고 `still water` 로 |
| 2마리가 섞임 | 다중 캐릭터 한계 | **단독 샷 2개를 따로 만들어 컷을 나눌 것** |

**2마리 동시 컷은 2개뿐입니다** (`two_blankets`, `sofa_back_two`).
잘 안 나오면 단독 샷 두 컷으로 쪼개는 게 훨씬 빠릅니다. 오히려 컷이 빨라져서 이 장르엔 더 맞습니다.

## 현실적인 소요

| 항목 | 무료만 사용 | 유료(월 1~3만원대) |
|---|---|---|
| 1편(20컷, 생성 20~25회) | **3~5일** | 반나절 |
| 5편 전체 | 2~3주 | 3~4일 |

무료로 가신다면 **매일 크레딧 리셋될 때마다 몇 컷씩** 쌓는 방식이 됩니다.
재사용 3회 이상인 5개 클립부터 만드세요. 그것만 있어도 애니매틱이 확 삽니다.
