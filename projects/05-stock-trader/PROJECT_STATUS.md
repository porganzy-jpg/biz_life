# StockBot v3.3 - 프로젝트 현황

## 개요
한국 주식 자동매매 봇. **5대 퀀트 전략 앙상블** (v3.2 Z-score 기반) + 시장 국면 감지 + 서킷브레이커 + SQLite DB.
한국투자증권 API(mojito SDK) 연동, Telegram 알림, 장 시간 자동 스케줄러.
yfinance 기반 실시간 데이터 + 200만원 소규모 자본 최적화.

## 버전 이력

### v3.3 (2026-03-02) — 현재 버전
- **뉴스 부스트 완전 제거**: 백테스트 검증 결과 순수 퀀트가 모든 구간에서 우위
  - 상승장: 순수 퀀트 +20.08% vs 뉴스+긍정 +17.36% (+2.73%p 우위)
  - 하락장: 순수 퀀트 +4.14% vs 뉴스+긍정 +2.30% (+1.84%p 우위)
  - 원인: 뉴스 블렌딩 공식 `quant×0.85 + (50+sent×15)×0.15`가 강한 시그널을 50으로 회귀시킴
- **1년 풀백테스트 최적 설정 적용** (12개 설정 비교, 2025년 전체):
  - 1위: v3.2 트레일링(-5%) + TP 15% → **+35.40%**, Sharpe 2.36, MDD -5.01%
  - 소자본(300만 이하) 익절 10% → 15%로 상향
- **익절 전량 매도**: 기존 50% 분할 매도 → 전량 매도 (v3.3)
- **대시보드 v3.3**:
  - 스캔 테이블: 6열→10열 (5대 서브스코어 추가)
  - 용어 사전 모달 (?버튼): 수학 공식 + 예시 포함 상세 설명
  - 전 항목 인라인 툴팁 추가 (마우스 오버 시 한국어 설명)
  - 오타 수정: "횟보" → "횡보"

### v3.2 (2026-02-28)
- **Z-score 기반 스코어링 엔진 전면 교체**:
  - 기존: 다단계 if-else 구간 점수 → 신규: Z-score + tanh 연속 함수
  - 점수 분포 개선: 기존 40~60 집중 → 신규 10~90 넓은 분포
- **5개 크리티컬 버그 수정**:
  - C1: 서브전략 스코어 범위 5~95로 확대 (기존 30~70 고정)
  - C2: confidence 계산을 config 기반으로 수정
  - C3: OBV 및 RSI NaN/division-by-zero 방어
  - C4: execution_engine 수량 계산 ×100 제거
  - C5: backtest_portal.py division-by-zero 방어
- **적응형 임계값**: score_history 50건 이상 시 75th/25th 백분위로 자동 조정
- **폭락 가드**: 20일 -25% 이상 하락 종목 매수 차단
- **tanh MACD**: 기존 히스토그램 구간 점수 → tanh(histogram/std) 연속 함수

## 5대 전략 앙상블 (v3.2)

| 전략 | 가중치 | 원리 | 핵심 지표 |
|------|:------:|------|----------|
| 평균회귀 | 25% | 많이 빠진 건 오르고 많이 오른 건 빠진다 | RSI, 볼린저밴드 %B |
| 추세추종 | 20% | 오르는 주식은 계속 오른다 | MACD, MA 정배열 |
| 한국형 모멘텀 | 20% | 급등주 단기 역전 + 폭락 가드 | 20/60일 수익률 |
| 거래량 | 20% | 거래량은 주가의 연료 | OBV, 거래량 비율 |
| 변동성 | 15% | 변동 축소=안정, 확대=위험 | 20/60일 변동성 비율 |

**국면별 가중치 자동 조정:**
- 상승장(BULL): 추세추종↑, 모멘텀↑
- 하락장(BEAR): 평균회귀↑, 변동성↑
- 횡보장(SIDEWAYS): 평균회귀↑, 거래량↑

**스코어링 엔진 (v3.2):**
1. 각 지표를 Z-score로 표준화: `Z = (값 - 평균) / 표준편차`
2. tanh 함수로 0~100점 변환: `점수 = 50 + 45 × tanh(Z × 0.5)`
3. 5전략 가중 평균 → 최종 점수 (10~90 범위)
4. 적응형 임계값: 최근 50건 점수의 75th(매수)/25th(매도) 백분위

### 대시보드 기능
- 6개 상단 카드: 총자산, 현금, 누적손익, 보유종목, 승률, 국면
- 시장 국면 패널: ADX, 변동성, 20일 수익률, MA 괴리
- 관심종목 10열 스캔: 점수, 신호, 5대 서브스코어 (색상 코딩)
- 성과 차트: 자산곡선(MDD), 일별손익, 전략기여도, 수익률분포
- 전략 분석: 히트맵, 롤링승률, 전략토글, 샤프 랭킹
- 시장 레짐: 국면 타임라인, 권장 가중치
- 포트폴리오: 상관관계 히트맵, 섹터배분, 분산점수, HHI
- 스마트 주문: 실행품질, 슬리피지 분포, 거래량 프로필
- 용어 사전: ? 버튼 클릭 → 수학 공식 + 예시 포함 상세 설명
- 인라인 툴팁: 모든 항목에 마우스 오버 시 한국어 설명

## 실행 방법

```bash
# 1. 패키지 설치
pip install yfinance mojito2 pandas numpy ta python-dotenv fastapi uvicorn

# 2. 환경변수 설정
cd projects/05-stock-trader
cp .env.example .env
# .env 파일에 API 키 입력

# 3. 대시보드 실행 (포트 8082)
cd dashboard
python app.py
# → http://localhost:8082

# 4. CLI 자동매매 (페이퍼 모드)
cd trading-bot
python trader.py

# 5. 라이브 전환 (2주 이상 페이퍼 검증 후)
# .env: TRADING_MODE=live, LIVE_TRADING_CONFIRMED=true, KIS_IS_PAPER=false
```

## 안전 장치
1. **기본값 페이퍼 모드**: `TRADING_MODE=paper`가 디폴트
2. **이중 확인**: live 전환에 env 변수 2개 + 콘솔 CONFIRM 입력 필요
3. **서킷 브레이커**: 일일 -3%, 연속 5패, 일 20거래 초과 시 자동 중단
4. **손절/익절**: -5% 손절, +15% 익절, -5% 트레일링 스탑
5. **현금 보유**: 최소 15% 현금 유지
6. **텔레그램 알림**: 모든 매매/서킷브레이커 이벤트 통보
7. **폭락 가드**: 20일 -25% 이상 하락 종목 매수 차단
8. **소규모 주문 바이패스**: 5주 이하 직접 시장가 주문 (TWAP 분할 안 함)
