# BarcodeQuest - Midjourney 배경 에셋 프롬프트 가이드

## 공통 스타일 접미사 (모든 프롬프트 끝에 붙이기)

```
--ar 16:9 --s 750 --q 2 --v 6.1
```

> **첫 이미지가 마음에 들면** `--sref [이미지URL]`로 스타일 레퍼런스를 고정하면
> 이후 모든 이미지가 동일한 화풍으로 생성됩니다.

## 4. 작업 순서 (권장)

### Phase 1 - 스타일 확정 (1일)
1. **메인 로비** 프롬프트로 4장 생성
2. 가장 마음에 드는 1장 선택
3. 해당 이미지를 `--sref` 스타일 레퍼런스로 등록

### Phase 2 - 핵심 배경 (2~3일)
4. Zone 1 (Memory Forest) 4시간대 배경 생성 → 스타일 일관성 확인
5. Zone 2~4 나머지 배경 생성 (총 16장)

### Phase 3 - UI 배경 (1일)
6. 도감, 인벤토리, 스캔 화면 배경
7. 승리/패배 화면

### Phase 4 - 후처리
8. 해상도 업스케일 (Midjourney U 버튼 또는 Topaz Gigapixel)
9. 게임 해상도에 맞게 크롭/리사이즈
10. 필요시 Photoshop에서 UI 영역 여백 조정

## 5. 팁

- **`--s 750`**: Stylize 값이 높을수록 더 예술적. 500~1000 사이에서 조절
- **`--q 2`**: 퀄리티 최대치. 시간은 더 걸리지만 디테일 증가
- **`--v 6.1`**: 최신 Midjourney 버전 사용
- **`--sref`**: 첫 이미지 확정 후 반드시 사용하여 시리즈 통일감 유지
- **`--cref`**: 특정 캐릭터를 여러 배경에 넣을 때 사용
- **Vary (Region)**: 생성된 이미지의 특정 부분만 수정 가능
- **Pan**: 이미지를 좌우/상하로 확장하여 더 넓은 배경 생성
- 배틀 배경은 **하단 1/3을 상대적으로 단순하게** 유지 (UI 오버레이 영역)

## 6. 에셋 네이밍 컨벤션

```
bg_[용도]_[존]_[시간대].png

예시:
bg_battle_forest_morning.png
bg_battle_forest_afternoon.png
bg_battle_ocean_sunset.png
bg_battle_summit_night.png
bg_lobby_main.png
bg_ui_collection.png
bg_ui_inventory.png
bg_ui_scan.png
bg_result_victory.png
bg_result_defeat.png
```

총 필요 에셋: **약 24장**
- 배틀 배경: 16장 (4존 × 4시간대)
- 로비: 1장
- UI 배경: 4장 (도감, 인벤토리, 스캔, 설정)
- 결과 화면: 2장 (승리, 패배)
- 여분/이벤트: 1장+
