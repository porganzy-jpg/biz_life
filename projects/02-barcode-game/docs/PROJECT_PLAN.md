# PART 1: Heaven — 바코드 여행단 🚌

## 1. 프로젝트 개요

### 1.1 핵심 컨셉
**"거대한 3층 버스를 타고 아름다운 세계를 여행하며, 바코드 스캔으로 동료와 물자를 모아 각 여행지 사람들에게 상품을 만들어 전달하는 힐링 경영 시뮬레이션"**

플레이어는 거대한 3층 여행 버스의 선장(관리자)이 된다.
버스 안에는 폴아웃 쉘터처럼 다양한 기능의 방(공방, 주방, 창고, 침실, 운전석 등)이 있고,
각 방에 어울리는 캐릭터들이 자기 역할을 수행한다.
바코드 스캔을 통해 새로운 동료 캐릭터와 재료/아이템을 획득하고,
여행지마다 필요한 상품을 제작하여 납품하면서 여행을 이어간다.

### 1.2 게임 장르 정의
- **메인 장르**: 경영 시뮬레이션 (Fallout Shelter 계열)
- **서브 장르**: 힐링/여행 + 수집 + 크래프팅
- **플레이 스타일**: 세미 방치형 (능동 플레이 + 방치 생산)
- **아트 스타일**: 아기자기한 도트(픽셀) 아트, 밝고 따뜻한 톤

### 1.3 레퍼런스 게임
| 레퍼런스 | 차용 요소 |
|---------|----------|
| **Fallout Shelter** | 횡단면 뷰 룸 관리 시스템, 캐릭터 배치, 자원 관리 |
| **AFK Journey** | 고퀄리티 2D 그래픽, 여행/모험 분위기, 월드맵 |
| **Cats & Soup** | 귀여운 캐릭터, 힐링 감성, 심플한 인터랙션 |
| **거대 차량 내부 공간** | 3층 구조의 공간감 연출, 각 층별 다른 기능 |
| **따뜻한 분위기** | 노을, 비오는날, 캠프파이어 등 감성적 연출 |

### 1.4 타겟 사용자
- **1차**: 10~30대 캐주얼 모바일 게이머 (힐링/경영 시뮬 선호)
- **2차**: Cats & Soup, 쿠키런 등 아기자기한 게임을 좋아하는 유저
- **3차**: 쇼핑할 때 재미 요소를 원하는 일반 소비자
- **4차**: 자녀와 함께 즐기는 부모 (바코드 교육 + 게임)

### 1.5 한 줄 피치
> "매일 만나는 상품 바코드가 여행 동료와 재료로! 3층 버스 위의 작은 세계에서 아름다운 풍경을 만나는 힐링 여행 시뮬레이션"

## 2. 게임 월드 & 스토리

### 2.1 세계관 (핵심 — 서서히 드러나는 비밀)

> **이 버스는 사실 천국이다.**

플레이어가 탑승하는 거대한 여행 버스는 천국에 존재하는 특별한 탈것이다.
**살면서 너무 아팠던, 힘들게 살았던 모든 생명체**가 이곳에 온다.
동물이건, 사람이건 — 생전에 아파서, 움직일 수 없어서, 원하는 곳을 가지 못했고
보고 싶은 것을 보지 못한 이들이 천국에서 이 버스 여행을 지원받는다.

버스 안의 캐릭터들은 각각의 아픈 사연을 품고 있으며,
여행지에 도착할 때마다 생전에 그리워했던 추억을 하나씩 떠올린다.
여행 경비를 마련하기 위해 각 여행지의 마을에 물건을 배달하고,
여행을 계속 이어나간다.

**이 설정은 게임 초반에 직접적으로 드러나지 않는다.**
처음에는 단순히 "귀여운 캐릭터들이 버스를 타고 여행하는 힐링 게임"으로 보인다.
플레이를 진행하면서 캐릭터들의 대사, 회상 씬, 풍경과의 반응 등을 통해
서서히 "이곳이 천국이었다"는 사실을 깨닫게 된다.

### 2.1.1 천국 버스의 탑승 자격
- **아파서 자유롭지 못했던 생명체**: 병, 장애, 구속 등으로 생전에 원하는 곳을 가지 못한 존재들
- **동물**: 주인이 가고 싶어했던 곳, 함께 가지 못했던 곳을 대신 여행
- **사람**: 자신이 평생 가보고 싶었지만 갈 수 없었던 곳을 여행
- **재회**: 나중에 주인이나 소중했던 존재가 천국에 오면, 버스에서 **재회**할 수 있음
  → 같은 칸에서 함께 일하면 시너지 효과 (능력치 대폭 상승)

### 2.2 스토리 전달 방식 (Show, Don't Tell)
- **초반**: 밝고 행복한 여행. 캐릭터들이 "가고 싶은 곳"을 이야기하는 정도
- **중반**: 캐릭터들이 "예전에..." 하며 소중했던 사람/주인과의 추억을 조금씩 언급
  - 특정 풍경에 도착하면 감정적인 반응을 보임
  - "이 바다 냄새... 어디선가 맡아본 적이 있어"
- **후반**: 캐릭터의 과거가 본격적으로 드러남 (회상 컷씬)
  - 함께했던 시간, 이별의 순간, 생전의 아픔
  - "나는... 더 이상 곁에 없구나" → 깨달음
- **재회편**: 소중했던 존재가 천국에 도착 → 버스에서 재회
  - 감동적인 재회 컷씬, 함께 일하며 시너지
  - 과금/바코드를 통해 재회 캐릭터 영입 가능
- **엔드**: 목적지에 도착한 캐릭터가 그리워했던 풍경을 바라보며 평화를 찾음
  - 울림 있는 엔딩, 플레이어도 함께 감동받는 구조

### 2.3 메인 스토리라인
1. **시작**: 작은 버스 한 대. 첫 번째 동료(잠이)를 만남. 어디론가 가고 싶다고 함
2. **초반**: 가까운 마을들을 다니며 배달, 새 동료 합류 (튜토리얼)
3. **중반**: 버스 확장 (2층→3층→4층), 바다/산/사막 등 새로운 지역 해금
4. **후반**: 각 캐릭터의 과거 스토리가 열림, 감정적 여행 시작
5. **엔드게임**: 각 캐릭터의 "약속된 장소"에 도착 → 개별 엔딩
   - 모든 캐릭터의 여행을 완수하면 최종 엔딩

### 2.4 테마 키워드
**천국** · **아픔과 치유** · **추억** · **여행** · **이별과 재회** · **따뜻함** · **지상천국** · **아름다운 세계**

### 2.5 디자인 원칙
- **지상천국의 풍경**: 노골적인 "천국" 분위기가 아닌, 현실 세계의 아름다운 풍경들을 보여줌
  - 산토리니의 바다, 알프스의 초원, 할슈타트 호수마을, 벚꽃 터널, 아이슬란드 오로라 등
  - "지상에 이런 곳이 있었구나" → 자연스럽게 천국이라는 느낌
- **2가지 핵심 뷰**:
  - **버스 내부 뷰**: 횡단면으로 방과 캐릭터를 들여다보는 뷰 (경영/관리)
  - **버스 외부 뷰**: 창밖의 아름다운 풍경을 시네마틱하게 보여주는 뷰 (감성/여행)
- **따뜻하고 자연스러운 색감**: 지나치게 밝거나 판타지하지 않게, 실제 풍경의 아름다움
- **시네마틱 연출**: 풍경 도착 시 카메라 연출로 감동 극대화
- **도트 아트에 구애받지 않음**: 퀄리티와 감성이 우선, 스타일은 유연하게
- **풀 3D가 아니어도 됨**: 2D 일러스트 + 패럴랙스, 또는 2.5D 등 최적의 표현 방식 선택

## 3. 핵심 게임 시스템

### 3.1 버스 관리 시스템 (메인 시스템 - Fallout Shelter 차용)

#### 3.1.1 버스 구조
```
┌─────────────────────────────────────────────────┐
│ 3F  [전망대] [휴게실] [특수공방] [VIP룸]         │  ← 확장 후반부
├─────────────────────────────────────────────────┤
│ 2F  [주방]  [공방①]  [공방②]  [창고]  [침실②]   │  ← 확장 중반부
├─────────────────────────────────────────────────┤
│ 1F  [운전석] [거실] [침실①] [창고①] [상점]       │  ← 초기 시작
├─────────────────────────────────────────────────┤
│     ⊙======================================⊙   │  ← 바퀴 (이동)
└─────────────────────────────────────────────────┘
```

#### 3.1.2 방(Room) 종류와 기능

| 방 이름 | 층 | 기능 | 생산물 |
|--------|---|------|--------|
| **운전석** | 1F | 이동 속도, 연료 효율 | 여행 진행 |
| **거실** | 1F | 캐릭터 사기(모랄) 회복 | 행복도 |
| **침실** | 1F/2F | 캐릭터 체력 회복, 경험치 보너스 | 스태미나 |
| **창고** | 1F/2F | 재료/완제품 보관 | 보관 용량 |
| **주방** | 2F | 식사 제작 → 캐릭터 버프 | 음식 아이템 |
| **공방** | 2F | 재료 → 상품 제작 (납품용) | 납품 상품 |
| **상점** | 1F | 여행지 도착 시 자동 판매 | 골드 수입 |
| **전망대** | 3F | 풍경 감상 → 풍경 포인트 수집 | 풍경 카드 |
| **휴게실** | 3F | 특수 이벤트, 캐릭터 대화 | 호감도/스토리 |
| **특수공방** | 3F | 고급 상품 / 전설 아이템 제작 | 프리미엄 상품 |
| **VIP룸** | 3F | 특별 손님(NPC) 탑승 → 퀘스트 | 특수 보상 |

#### 3.1.3 방 업그레이드
- 각 방은 **Lv.1 ~ Lv.5**까지 업그레이드 가능
- 레벨업마다 생산 효율 ↑, 수용 인원 ↑, 외관 변화
- 같은 종류의 방을 나란히 배치하면 **합체** → 대형 방 (효율 보너스)

### 3.2 바코드 스캔 시스템 (핵심 차별점)

#### 3.2.1 바코드 → 캐릭터 생성
실제 상품의 EAN-13 바코드를 스캔하면 **캐릭터 또는 재료**가 생성된다.

```
EAN-13 바코드 구조:
┌─────────┬──────────────┬───────────┬─────────┐
│ 국가코드 │  제조사코드   │  상품코드  │ 체크섬  │
│  (3자리) │   (4자리)    │  (5자리)  │ (1자리) │
│   880    │    1234      │   56789   │    0    │
└─────────┴──────────────┴───────────┴─────────┘
```

**캐릭터 생성 규칙:**
- **국가코드 (3자리)** → 캐릭터 출신 지역 & 기본 직업 성향
  - 880 (한국) → 요리사 계열, 식재료 보너스
  - 490 (일본) → 장인 계열, 공방 효율 보너스
  - 690 (중국) → 상인 계열, 판매 보너스
  - 000 (미국) → 운전사 계열, 이동 보너스
  - 300 (프랑스) → 예술가 계열, 풍경 보너스
  - 400 (독일) → 기술자 계열, 방 업그레이드 보너스
  - 880+ (기타) → 여행자 계열, 올라운드

- **제조사코드 (4자리)** → 외형 & 성격 결정
  - 코드 패턴에 따라 10종 기본 외형 중 선택
  - 색상, 액세서리, 표정 조합

- **상품코드 (5자리)** → 스탯 결정
  - 요리 실력 / 제작 실력 / 운전 실력 / 체력 / 사교성

- **체크섬 (1자리)** → 등급 (레어도)
  - ★★★★★ 전설 / ★★★★ 에픽 / ★★★ 레어 / ★★ 언커먼 / ★ 커먼

#### 3.2.2 바코드 → 재료/아이템 생성
캐릭터 대신 재료가 나올 수도 있다 (확률 기반):
- **식품 바코드** → 식재료 (주방 사용)
- **생활용품 바코드** → 공방 재료
- **음료 바코드** → 연료 / 에너지
- **문구/잡화 바코드** → 장식 아이템, 방 꾸미기 재료

#### 3.2.3 바코드 특수 규칙
- **같은 바코드 반복 스캔**: 첫 스캔만 캐릭터/아이템 생성, 이후는 소량 자원
- **희귀 패턴**: 바코드 숫자에 연속/회문/특수 패턴이 있으면 등급 보너스
- **위치 보너스**: 실제 매장에서 스캔하면 해당 지역 테마 보너스
- **시간대 보너스**: 아침/낮/저녁/밤에 따라 생성 변화

### 3.3 캐릭터 시스템

> 모든 탑승 캐릭터는 **생전에 아팠거나, 힘들게 살았던 생명체**이다.
> 동물, 사람 모두 탑승할 수 있으며, 각자 소중한 사연과 가고 싶은 목적지를 가지고 있다.
> 생전에 연결되어 있던 존재끼리는 나중에 **재회**하여 함께 여행할 수 있다.

#### 3.3.1 캐릭터 스탯
| 스탯 | 설명 | 영향 |
|------|------|------|
| **후각** (Nose) | 냄새/재료 감별 능력 | 주방, 작물 수거 효율 |
| **제작** (Craft) | 공방에서의 작업 효율 | 상품 품질, 제작 속도 |

#### 3.3.2 특성 시스템 (직업 대체)

3. **인앱 구매**: 재회 패키지 — 캐릭터 + 재회 컷씬 + 전용 스토리 챕터
   - **가격대**: ₩5,000~15,000 (캐릭터당)
   - **시즌 재회 패키지**: ₩19,900 (한정 스토리 + 캐릭터 + 코스튬)

**재회 시너지 효과:**
- 같은 칸 배치: 능력치 +80% (양쪽 모두)
- 전용 대화 해금: 감동적인 회상 대화 씬
- 합동 특기: 함께 있을 때만 발동하는 특수 능력
- 여행지 도착 시 전용 컷씬

**과금 유인:**
- 재회 전: 캐릭터의 외로운 대사, 빈자리 힌트 ("여기 누가 있었으면...")
- 재회 후: 극적인 감동 + 실질적 능력치 보상 → 자연스러운 과금 동기
- 감정적 가치 + 실용적 가치의 결합

#### 3.4.3 풍경 수집 시스템
- 각 여행 루트에는 **고유 풍경**이 있다

- 풍경 종류: 일출, 일몰, 별하늘, 비오는 마을, 노을진 바다, 벚꽃길, 눈덮인 산 등
- 같은 루트도 **시간대/날씨**에 따라 다른 풍경 → 수집 요소
- 풍경 카드 세트 완성 시 특수 보상 (버스 스킨, 전설 캐릭터 등)

#### 3.4.4 랜덤 이벤트 (이동 중)
- 길가 상인 만남 → 희귀 재료 교환
- 고장난 차량 발견 → 도와주면 동료 영입 기회
- 폭풍우 → 운전 스탯 체크, 성공 시 특수 풍경
- 숨겨진 샛길 발견 → 비밀 지역 해금
- 다른 여행 상단 조우 → 교역/정보 교환

## 5. 바코드 생성 알고리즘 (특허 핵심)

### 5.1 EAN-13 파싱 → 게임 요소 변환

```python
class BarcodeGenerator:
    """바코드 → 캐릭터/아이템 생성 엔진 (특허 핵심)"""

    # 국가코드 → 캐릭터 출신지 & 직업 성향
    COUNTRY_JOB_MAP = {
        '880': {'region': '한식마을', 'job_tendency': 'chef',    'bonus_stat': 'cook'},
        '490': {'region': '장인마을', 'job_tendency': 'crafter', 'bonus_stat': 'craft'},
        '690': {'region': '교역도시', 'job_tendency': 'merchant','bonus_stat': 'social'},
        '000': {'region': '모험도시', 'job_tendency': 'driver',  'bonus_stat': 'drive'},
        '300': {'region': '예술마을', 'job_tendency': 'artist',  'bonus_stat': 'social'},
        '400': {'region': '공학도시', 'job_tendency': 'mechanic','bonus_stat': 'craft'},
    }

    # 제조사코드 → 외형 결정
    APPEARANCE_MAP = {
        range(0, 1000):    'round_face',    # 동글동글
        range(1000, 2000): 'sharp_face',    # 날카로운
        range(2000, 3500): 'fluffy',        # 복슬복슬
        range(3500, 5000): 'tall',          # 키큰
        range(5000, 6500): 'small',         # 아담한
        range(6500, 8000): 'chubby',        # 통통한
        range(8000, 10000): 'elegant',      # 우아한
    }

    # 상품코드 → 스탯 (5자리 → 5개 스탯)
    def calculate_stats(self, product_code: str) -> dict:
        d = [int(c) for c in product_code]
        return {
            'cook':    d[0] * 8 + 20,   # 20~92
            'craft':   d[1] * 8 + 20,   # 20~92
            'drive':   d[2] * 6 + 15,   # 15~69
            'stamina': d[3] * 10 + 30,  # 30~120
            'social':  d[4] * 7 + 15,   # 15~78
        }

    # 체크섬 + 패턴 분석 → 등급
    def determine_rarity(self, barcode: str) -> str:
        score = self._calc_rarity_score(barcode)
        if score >= 900: return 'LEGENDARY'   # ★★★★★ (2%)
        if score >= 750: return 'EPIC'        # ★★★★  (8%)
        if score >= 550: return 'RARE'        # ★★★   (20%)
        if score >= 300: return 'UNCOMMON'    # ★★    (30%)
        return 'COMMON'                       # ★     (40%)
```

### 5.2 결정론적 생성 원칙
- 같은 바코드 = 항상 같은 캐릭터 (동일성 보장)
- GPS 컨텍스트 추가 시: 같은 바코드 + 다른 장소 = 지역 변이 버전
- 시간대 컨텍스트: 낮/밤에 따라 미세한 외형 변화

### 5.3 특허 청구항 핵심
1. 상품 바코드를 인식하여 국가/제조사/상품 코드를 파싱하는 단계
2. 파싱된 코드를 경영 시뮬레이션의 캐릭터 직업/스탯/외형으로 변환하는 단계
3. 위치 정보 기반 변이 생성으로 수집 다양성을 확보하는 단계
4. 생성된 캐릭터를 이동형 공간(버스) 내 기능별 방에 배치하는 단계
5. 캐릭터의 작업 결과물을 여행지 납품 시스템과 연동하는 단계

## 6. 게임 진행 구조

### 6.1 초반 (Chapter 1: 출발)
- 1층 미니버스, 방 3개 (운전석, 거실, 창고)
- 초기 동료 2명 (셰프 1, 장인 1)
- 근거리 마을 2~3곳 왕복
- 튜토리얼: 바코드 스캔, 상품 제작, 납품
- **목표**: 버스 2층 확장 자금 모으기

### 6.2 중반 (Chapter 2~4: 확장과 여행)
- 2층 확장 → 공방, 주방, 침실 추가
- 새로운 지역 해금 (호수 → 산 → 해안)
- 동료 10명+ 운영
- 납품 의뢰 복잡도 증가 (복합 상품)
- 풍경 수집 시작
- **목표**: 3층 확장 + 전설 루트 해금

### 6.3 후반 (Chapter 5~7: 대륙 횡단)
- 3층 확장 → 전망대, 특수공방, VIP룸
- 사막, 화산, 설산 등 극한 지역
- 전설 재료 & 전설 캐릭터 등장
- 다른 여행 상단과 교류/경쟁
- 풍경 컬렉션 후반부
- **목표**: 대륙 횡단 완주

### 6.4 엔드게임
- 전 지역 자유 여행
- 시즌 이벤트 (벚꽃 시즌, 눈꽃 시즌 등)
- 버스 커스터마이징 (외관, 인테리어)
- 랭킹: 납품량, 풍경 수집, 버스 꾸미기 등
- 주간/월간 특수 납품 챌린지

## 7. 수익화 모델

### 7.1 과금 설계
| 항목 | 설명 | 가격대 |
|------|------|--------|
| **재회 패키지** | 재회 캐릭터 + 전용 스토리 + 컷씬 | ₩5,000~15,000 |
| **시즌 재회 패키지** | 한정 재회 스토리 + 캐릭터 + 코스튬 | ₩19,900 |
| 바코드 에너지 충전 | 일 10회 무료, 추가 충전 | ₩1,000~3,000 |
| 버스 확장 가속 | 확장 대기 시간 스킵 | ₩2,000~5,000 |
| 프리미엄 버스 스킨 | 외관 테마 변경 | ₩5,000~10,000 |
| 방 데코 팩 | 인테리어 장식 세트 | ₩3,000~5,000 |
| 시즌 패스 | 월간 보상 트랙 | ₩9,900/월 |
| 풍경 프레임 | 풍경 카드 꾸미기 | ₩1,000~2,000 |

> **핵심 과금 포인트 — "재회 시스템"**
> 각 캐릭터에게는 생전의 소중한 존재가 있다. 그 존재가 나중에 천국에 오면
> 재회 캐릭터로 영입 가능. 감동적인 스토리 + 실질적 시너지 보상 →
> 자연스럽고 감성적인 과금 동기. 플레이어가 "사야 할 이유"가 아니라
> "만나게 해주고 싶다"는 감정에서 결제하도록 유도.

### 7.2 브랜드 협업 (B2B)
- **브랜드 캐릭터**: 특정 브랜드 바코드 → 한정 콜라보 캐릭터
- **이벤트 납품**: 신제품 연계 특수 납품 퀘스트
- **제휴 매장 보너스**: 편의점/마트 방문 시 바코드 스캔 보너스
- **광고 데이터**: 스캔 히트맵, 인구통계, 행동 분석 대시보드

### 7.3 밸런스 원칙
- 과금 = 편의성 & 꾸미기 (Pay-to-Skip, Pay-to-Decorate)
- 무과금으로도 전 컨텐츠 클리어 가능
- 바코드 스캔 자체의 재미를 과금으로 훼손하지 않음

# PART 2: Hell — 바코드 배틀 🔥

> **2탄은 1탄(Heaven)의 성공 후 출시한다.**
> 같은 바코드 스캔 특허 기술을 사용하되, 완전히 다른 게임 경험을 제공한다.
> Heaven이 치유와 따뜻함이라면, Hell은 전투와 모험이다.

## H1. 프로젝트 개요

### H1.1 핵심 컨셉
**"바코드를 스캔하여 지옥의 몬스터를 포획하고, 육성하여 던전을 정복하는 배틀 RPG"**

플레이어는 지옥에 떨어진 영혼이다.
살아남기 위해 바코드 스캔으로 지옥의 몬스터를 포획하고,
포켓몬처럼 몬스터를 육성·진화시켜 지옥의 층(層)을 하나씩 정복해 나간다.
최종 목표는 지옥의 최하층에서 탈출하여 다시 지상으로 돌아가는 것.

### H1.2 게임 장르 정의
- **메인 장르**: 몬스터 수집/배틀 RPG (포켓몬 계열)
- **서브 장르**: 던전 탐험 + 수집 + 육성 + PvP
- **플레이 스타일**: 능동 플레이 중심 (턴제 배틀)
- **아트 스타일**: 다크 판타지, 강렬한 색감, 고퀄리티

### H1.3 레퍼런스 게임
| 레퍼런스 | 차용 요소 |
|---------|----------|
| **포켓몬스터** | 몬스터 포획/육성/진화, 타입 상성, 턴제 배틀 |
| **하데스** | 지옥 층별 진행, 로그라이크 요소, 다크 감성 |
| **소울 시리즈** | 어둡고 웅장한 세계관, 보스 디자인 |
| **메가테니** | 악마 합체/협상, 다크 RPG |
| **원신** | 오픈필드 탐험, 원소 반응 시스템 |

### H1.4 타겟 사용자
- **1차**: 포켓몬/배틀 RPG를 좋아하는 10~30대 코어 게이머
- **2차**: 1탄(Heaven) 유저 중 더 자극적인 게임을 원하는 유저
- **3차**: PvP 경쟁을 좋아하는 유저
- **4차**: 몬스터 수집 컬렉터

### H1.5 한 줄 피치
> "상품 바코드로 지옥의 몬스터를 포획하라! 턴제 배틀로 지옥을 정복하는 다크 RPG"

## H2. 게임 월드 & 스토리

### H2.1 세계관
지옥은 **9층 구조**로 이루어져 있다 (단테의 신곡 모티브).
각 층은 고유한 테마, 환경, 몬스터 생태계를 가진다.

```
[1층] 림보 — 안개의 황야 (튜토리얼)
[2층] 탐욕 — 황금 미궁
[3층] 분노 — 불의 전장
[4층] 이단 — 뒤틀린 도시
[5층] 폭력 — 피의 강
[6층] 사기 — 거짓의 시장
[7층] 배신 — 얼음 감옥
[8층] 심연 — 혼돈의 공허
[9층] 왕좌 — 마왕의 성 (최종 보스)
```

### H2.2 스토리
- 플레이어는 이유를 알 수 없이 지옥에 떨어진 영혼
- 유일한 무기: 바코드 스캐너 (지옥에서는 "소울 캡처" 장치)
- 지옥의 몬스터를 포획하여 동료로 만들고, 지옥의 각 층을 정복
- 각 층의 보스를 물리치면 다음 층으로 이동 가능
- **반전**: 지옥의 최하층에 도달하면, 사실 이곳이 천국으로 가는 시험이었음을 알게 됨
- **Heaven 연결**: 1탄의 천국 버스에 탑승할 자격을 얻기 위한 여정

### H2.3 Heaven과의 연결 (크로스오버)
- Hell에서 얻은 특수 아이템 → Heaven에서 사용 가능 (계정 연동)
- Heaven의 캐릭터가 Hell에 특별 게스트로 등장
- 양쪽 게임을 모두 플레이하면 해금되는 **크로스오버 스토리**
- Hell 클리어 후 → Heaven의 버스에 탑승하는 **진엔딩**

## H3. 핵심 게임 시스템

### H3.1 바코드 → 몬스터 포획
바코드 스캔 특허 기술을 배틀 RPG에 적용:

```
EAN-13 바코드 → 몬스터 생성:
- 국가코드 (3자리) → 몬스터 속성 (화/수/풍/지/암/광)
- 제조사코드 (4자리) → 몬스터 종족 & 외형
- 상품코드 (5자리) → 스탯 (HP/ATK/DEF/SPD/SP)
- 체크섬 (1자리) → 등급 (S/A/B/C/D)
- 특수 패턴 → 전설/희귀 몬스터
```

### H3.2 배틀 시스템
- **턴제 배틀** (포켓몬 스타일)
- **파티**: 최대 4마리 편성
- **속성 상성**: 화→풍→지→수→화, 암↔광
- **스킬**: 몬스터별 4개 스킬 슬롯
- **합체**: 2마리 몬스터를 합쳐 상위 몬스터 생성 (메가테니 차용)
- **진화**: 레벨 + 특수 조건 충족 시 진화
- **보스전**: 각 층의 보스는 특수 기믹 + 멀티 페이즈

### H3.3 몬스터 시스템
- **6대 속성**: 화(火), 수(水), 풍(風), 지(地), 암(暗), 광(光)
- **등급**: S급(전설) / A급(에픽) / B급(레어) / C급(언커먼) / D급(커먼)
- **성장**: 레벨업 → 진화 → 각성 → 초월
- **개체값**: 같은 종이라도 바코드에 따라 스탯이 다름 (수집 동기)
- **도감**: 전체 몬스터 도감 + 지옥 층별 도감

### H3.4 던전 탐험
- 각 지옥 층은 **필드 + 던전**으로 구성
- 필드에서 야생 몬스터 조우 → 바코드 포획 또는 배틀
- 던전: 로그라이크 요소 (랜덤 맵, 랜덤 보상)
- 함정, 퍼즐, 숨겨진 방
- 보스 층: 스토리 이벤트 + 대규모 보스전

### H3.5 PvP 시스템
- **랭크 매치**: 실시간 1:1 턴제 배틀
- **토너먼트**: 주간/월간 대회
- **길드전**: 길드 단위 영역 쟁탈
