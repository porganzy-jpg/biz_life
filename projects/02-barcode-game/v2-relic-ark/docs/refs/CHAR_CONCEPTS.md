# 캐릭터 컨셉 여섯 — 제로베이스 탐색 (2026-09-27)

> 기존 캐릭터(`a`·`b`·`c`)를 고치지 않는다. **아예 다른 여섯 방향**을 하나씩 만들어 놓고 고른다.
> 이유: 세 번 연속 기존 것을 손보면서 앞선 오독(얼굴 최소·극단 대비·평면 채색)을 계속 물려받았다. 끊는다.

## 규칙
- **같은 인물로 만든다: 정찰병.** 에어락으로 나가는 사람이고 잠수복과 헬멧을 쓰므로 이 게임의 얼굴이다. 여섯을 나란히 놓고 비교할 수 있어야 한다.
- 각 컨셉은 **내부적으로 완결된 하나의 답**이어야 한다. 조금씩 다른 변주가 아니라 서로 다른 세계관의 답.
- 공통 제약은 셋뿐: ①심해 잠수복 차림 ②흙 계열 따뜻한 색이 바탕(차가운 색은 물에만) ③70px에서 실루엣이 읽힌다.
- 그 외 비율·얼굴·질감·선·기법은 **컨셉마다 자유롭게 다르게.**

## 여섯 컨셉

### C1. 동화 삽화 (storybook)
레퍼런스의 정확한 독해판. 4~5등신, 땅딸막하고 둥글다. **얼굴을 전부 그린다** — 눈동자·눈썹·입·주근깨·볼 홍조. 연필과 붓의 거친 결, 부드러운 가장자리, 음영 2~3단. 따뜻한 황토 광원 속에 인물이 잠긴다. 복슬복슬한 부피(목 실링이 솜 덩어리).

### C2. 통통 치비 (cozy chibi)
2.5~3등신. 머리가 크고 몸이 작고 전부 둥글다. 큰 눈에 하이라이트, 작은 입, 볼 홍조. 선은 굵고 부드럽게. 모바일 아늑한 게임의 정석. 사용자가 처음 준 레퍼런스(통통한 생존자)에 가장 가깝다.

### C3. 잠수복이 캐릭터다 (suit-first)
체형을 숨긴다. 두툼하게 누빈 잠수복 한 덩어리에 둥근 창이 달린 헬멧. **얼굴 대신 헬멧 창의 불빛**이 표정을 대신한다(밝기·색·기울기). 실루엣만으로 구분. 걸어 다니는 보따리 같은 느낌.

### C4. 픽셀 도트
32~48px 도트. 제한 팔레트 12~16색. 작은 화면에서 가장 잘 읽히고 애니메이션이 싸다. 평면 단면 화면과 궁합이 좋다. 향수 자극.

### C5. 종이 오림 (paper cutout)
판지를 오려 겹친 느낌. 납작한 색 면 + 종이 결 + 아주 얕은 그림자. 관절이 핀으로 연결된 종이 인형처럼 움직인다. 민속 공예·그림자극의 결.

### C6. 펠트 인형 (felted wool)
양모를 뭉쳐 만든 인형. 보풀 같은 가장자리, 실밥, 바느질 자국. 손으로 만든 물건처럼 보인다. 따뜻함이 재질에서 직접 나온다. 스톱모션 애니메이션의 촉감.

## 각 컨셉이 답해야 할 것
| 질문 | 왜 |
|---|---|
| 70px에서 무엇으로 보이는가 | 실제 게임 크기. 여기서 안 읽히면 탈락 |
| 어두운 방 배경에서 뜨는가 묻히는가 | 단면 화면의 조건 |
| 표정을 어떻게 표현하는가 | 얼굴 / 헬멧 불빛 / 자세 중 무엇으로 |
| 여덟 역할로 확장 가능한가 | 지금은 정찰병 하나지만 8명이 구분돼야 한다 |
| 제작 비용 | 우리 파이프라인으로 얼마나 싸게 반복되는가 |

## 고르는 기준 (사용자)
한 줄이다 — **"저 사람을 지켜 주고 싶은가."** 아늑한 생존물의 주인공은 보호하고 싶은 대상이어야 한다.
