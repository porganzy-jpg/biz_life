# 외부 도구 링크 (사용자 제시)

## 소서리스 (Sorceress) — AI 게임 에셋 제작 스위트
- **스위트**: https://sorceress.games
- **위저드지니(게임 엔진)**: https://sorceress.games/wizgen
- 가격: **49달러 일회성**(현재·향후 도구 전부), 무료 체험 100크레딧

### 우리에게 쓸모 있는 도구
| 도구 | 하는 일 | 우리 용도 |
|---|---|---|
| **True Pixel** | 이미지·영상 → 도트 스프라이트 | **C4 픽셀 도트 컨셉**을 채택하면 1순위 |
| **Pixel Snap** | AI 그림을 진짜 픽셀 격자에 맞춤 | 도트 정합 |
| **3D to 2D** | 3D 에셋 → 2D 스프라이트 시트 | 우리가 Blender로 하는 것과 같은 일. 더 빠를 수 있음 |
| **Auto-Sprite v2** | 프롬프트 → 애니메이션 스프라이트 시트 | 일관성 위험이 커서 **캐릭터에는 쓰지 않는다** |
| **Tileset Forge** | AI 아트 → 게임용 타일셋 | 배경 타일 |
| **Sound Studio** | 음악·효과음·음성 | 우리는 로컬 합성이 돌아가므로 보조 |
| 이미지·영상 모델 모음 | Flux 2 Pro, GPT Image 2 등 | **GTX 1050 2GB라 로컬 생성이 불가**한 우리 병목에 직접 닿는다 |

### 도입 시 지켜야 할 것
- **캐릭터를 통째로 생성하지 않는다.** 일관성 함정(교본 07 §3-4). 캐릭터는 3D 소스에서 뽑거나 절차 생성.
- 여기서 나온 결과물은 **플레이어가 보는 것이면 AI 공개표(07 §6)에 올린다.**
- 구매 전 **출력물의 상업적 이용 허용 여부**를 약관에서 확인할 것.
- **위저드지니(엔진)는 쓰지 않는다.** "설명하면 게임을 만들어 준다"는 교본 07 §3-1의 실패 사례 1번이고, 우리는 이미 동작하는 서버·데이터 구조가 있다.
