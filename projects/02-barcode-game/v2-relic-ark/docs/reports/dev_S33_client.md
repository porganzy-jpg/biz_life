# 개발 S33 화면 — 오늘의 목표 셋 · 방 생산 숫자 · 빈 칸 안내 · 얻은 자원 크게 (2026-10-17)

사용자 요청 「뭘 해야 할지 모르겠다」에 대한 화면 작업이다. 설계는 docs/GOALS_WEEK1.md, 서버는 API_S19 §22(goals·production·move_preview.room_per_day_after·build_options.produces), 문장은 PM 결정대로 서버 goals[].title_ko·done_ko·all_done_ko 를 쓰고 판 제목만 ui_moments goal.panel_title 에서 읽는다. 확인은 8041 에서만 했다(사용자 8002 는 건드리지 않음, 확인 뒤 8041 껐음). **커밋하지 않음.**

## 3. 확인 중 서버에 알린 것
- 서버가 production[slot] 을 새 값으로 통째로 바꿔 옛 값(staff·per_person·label·ko…)이 사라졌던 것을 알렸다. 서버가 고쳐 지금은 그 위에 더한다(8041 재확인).
- goals_done_now 가 여러 응답에 겹쳐 왔다. 화면은 id 마다 한 번만 말한다.

## 4. 교본
- D2(숫자는 화면의 무엇으로): 방의 하루 값과 끌 때 예보가 숫자로 보인다. 「3명 = 1.6배」는 끄는 동안의 예보로 체감된다.
- D5(첫 3분 루프): 목표 셋이 첫날 「사람 두기 → 찍기 → 건네기」를 그대로 따른다. 새 탭은 판을 펴는 것(폰) 하나다.
- B4·풍요: 목표에 실패가 없고, 보상은 장면 한 줄과 내일 부탁이다.

## 5. 남은 것
- 떠날 때 카드에서 셋 다 끝낸 날의 tomorrow_ask.clear·subtype_ko 는 서버 문장(line)을 그대로 보인다. 하위 종류를 따로 굵게 하는 표시는 하지 않았다.
- 건네기 결과 칩(「사기 +2 · …」)은 사용자 결정 대기라 하지 않았다.
