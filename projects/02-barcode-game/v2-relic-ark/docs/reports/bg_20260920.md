## 1. 만든 것 — 방 정의 3개 (`tools/blender_iso.py`)

`ROOMS` 딕셔너리에 `mall_camp` / `mall_food` / `mall_escalator` 등록. 셸은 기존과 같은 6×6m 바닥·벽 2.6m·뒷벽 둘(+X·+Y), 카메라 45°/45° 직교 그대로.

### 공통: 새 셸 `shell("mall")`
지상 매장층이므로 콘크리트 대신 **타일·유리**로 지었다(기존 `shell("room")`은 손대지 않고 분기만 추가).
- 광택 타일 바닥 + 1m 간격 줄눈, 벽 하단 타일 줄눈(가로 3·세로 5)
- 벽 상단 z=1.75~2.55의 **채광 유리 띠** + 금속 멀리언·선반턱 → "지상은 밝고 차갑다"
- 정면 오른쪽에 매장 **기둥**(타일 + 금속 갓), 바닥 테두리 콘크리트 curb(기존과 동일한 타일 경계 인식용)
- 새 재질(`make_materials`에 추가, 기존 재질명과 충돌 없음): `mallfloor` `grout` `tilewall` `tilewall2` `glass_lt`(채광 유리, 약한 발광) `glass_dirty`(깨진 유리·난간) `metal_lt` `chrome` `cardboard` `rubber` `esc_dk`

### 새 소품 헬퍼 (전부 원시 도형)
`cart()` 쇼핑카트(프레임+바구니 살대+바퀴+손잡이, 적재 옵션) · `can_pile()` 통조림 피라미드 · `shards()` 깨진 유리 조각 · `sapling()` 어린 나무 · `mall_fill()` 매장층 전용 필라이트 보정

### mall_camp — 진열대 사이의 텐트촌 (주색 `#F2A93B`)
진열대(`shelf_unit`) 뒤열 3대 + 가운데열 2대, 그 사이 통로에 캔버스 텐트 2동, 침낭 2, 모닥불(+따뜻한 보조광), 러그, 빨래줄, 물통 3, 접이식 상(냄비·통조림·성냥)과 스툴 2, 종이상자·배럴·배낭·쓰레기통, 계산대 잔해(+라디오), 통조림 더미 1. 초록: 화분 3, 벽 덩굴 2, 바닥 이끼 5. 랜턴 1개(주색) + 모닥불만이 광원.
레벨 2: 진열대 1대·침낭 1 추가.

### mall_food — 식품관 (주색 `#E0B54A`)
색색 포장이 찬 진열대 6대(2열), **죽은 냉장고 2대**(내부 선반·남은 포장 보임, 어두운 유리문), **카트 2대**(1대는 적재), 통조림 더미 4, 팔레트+포대 4, 쓰러진 진열대와 쏟아진 포장, 채소 상자, 죽은 자판기 + 종이상자 더미, 식품관 간판. **덩굴이 진열대 윗단을 타고 감고**(잎 구체 13 + 흘러내리는 덩굴 4) 바닥엔 이끼 5.
레벨 2: 진열대 1대·통조림 더미 1 추가.

### mall_escalator — 무너진 에스컬레이터 (주색 `#7DE0A8`)
큐브 반복 14단(디딤판은 어두운 고무 + 크롬 노징), 가운데 3단이 **무너져 내려앉은 판 + 휜 철골**. 양쪽 난간: 오른쪽은 더러운 유리 온전, 왼쪽은 조각 둘만 남고 프레임·손잡이(고무)만. 위층 바닥 조각·천장 파편과 **위에서 내려오는 스포트**(좁은 각, 옅은 초록빛) → "빛이 위에서". 계단 틈과 바닥에서 **어린 나무 3그루·잡초 6무더기**, 깨진 유리 조각 2군데, 넘어진 안내판, 잔해 7. 계단 밑엔 야영 흔적(침낭·모닥불·러그·물통·배낭·빨래줄)로 아늑함을 남겼다.

### GLB 1MB 제한 대응 (`tools/blender_export_glb.py`, rooms 부분)
첫 내보내기는 1092 / 1835 / 1010 KB로 기준 초과였다. 소품을 줄이는 대신 **데이터 낭비**를 제거했다.
1. `join_static_meshes()`: 정적 방의 메시를 **텍스처 있는 CC0 소품 / 단색 원시도형** 둘로 합치고, 단색 쪽의 **UV·버텍스컬러를 버린다**(단색 재질엔 불필요). 큐브 수백 개가 각각 노드·액세서가 되던 낭비도 사라진다.
2. `sphere()`/`cyl()`에 해상도 인자, `plant()`/`vine()`에 `lod` 인자 추가(**기본값은 기존과 동일**, 매장층 3방만 저폴리 사용). 잎 구체 512→240 정점.
결과 692 / 808 / 576 KB. 참고로 같은 파이프라인으로 `pantry`를 내보내면 699 → 566 KB로 줄지만, **기존 6방 GLB는 건드리지 않았다**(다음 내보내기 때 자동으로 작아진다).

## 3. 자가 평가 (아트 원칙 대조)

| 기준 | 판정 | 근거 |
|---|---|---|
| 랜턴 1 = 주색 1 | O | 방마다 매단 랜턴 1개만 주광원. camp 주황, food 노랑, escalator 초록. 모닥불은 주황 계열이라 camp·escalator의 톤과 충돌하지 않음 |
| 초록 | O | 세 방 모두 화분·덩굴·이끼. food는 덩굴이 진열대를 감고, escalator는 계단에서 나무가 자람 |
| 아늑한 생존 | O | 세 방 모두 "오늘 밤 여기서 잔다"의 흔적(침낭·모닥불·빨래줄·물통·러그). escalator도 계단 밑 야영을 넣어 통로가 아닌 거처로 읽힘 |
| 소품 밀도 2배 | O | 오브젝트 285 / 437 / 223개. 빈 바닥 구간을 3차에 걸쳐 채움(접이식 상·자판기·쓰러진 진열대 등) |
| 카메라 45°/45°, 6m 격자 원점 | O | 기존 `camera()`·`CUR` 그대로. footprint 좌표가 기존 방과 완전히 동일 |
| 일상 공간이 유적 | O | 진열대·냉장고·카트·계산대·자판기·에스컬레이터 = 현실 매장 집기가 그대로 유적 |
| 타일 ≤ 1MB | O | PNG 540KB 이하, GLB 808KB 이하 |

**3회 수정 이력(요청된 자가 검수 루프)**
1. 1차: 벽·바닥이 밝은 회색 + 채광 유리 발광 과다 → 전체가 차갑게 날아감. 매장 팔레트를 두 단계 어둡게, 유리 발광 0.35→0.10.
2. 2차: 여전히 냉기. `mall_fill()`로 `lantern()`이 까는 큰 차가운 필라이트를 420→95~160으로 낮추고 랜턴을 2000~2300으로 올림. 텐트를 프레임뿐인 `k:tent`에서 `k:tent-canvas`로 교체(주요 시각 개선).
3. 3차: 에스컬레이터가 여전히 창백 → 구조를 전용 어두운 재질(`esc_dk`)로, 채광 스포트 2600→850W·좁은 각으로 바꿔 국소 광원화. 식품관 오른쪽 빈 바닥에 자판기·상자 더미 추가.

**아직 아쉬운 점(리스크)**
- `mall_food` 가운데~오른쪽이 갈색 위주라 시선을 끄는 지점이 약하다. 색색 포장이 진열대에만 몰려 있어 앞쪽으로 더 흘려야 한다.
- 에스컬레이터 디딤판이 위에서 오는 빛에 다소 밝게 날아간다. 의도한 연출이지만 값 대비를 더 줄 수 있다.
- `k:tent-canvas` 두 동이 같은 모델이라 실루엣이 반복된다. 캐릭터 담당의 천막 파츠가 나오면 교체 여지.
- 매장층엔 아직 **깨진 정면 유리 너머 공룡 실루엣**이 없다(`CONCEPT_MALL_DINO.md` §3 스카이라인). 지상 타일 뒤에 깔 패럴랙스 레이어는 별도 태스크가 필요하다.

## 4. 회귀 확인

- `pantry`를 임시 폴더에 재렌더해 기존 `art_raw/iso/pantry.png`와 픽셀 비교 → **diff bbox = None(완전 동일)**. `tile_meta`의 pantry footprint 좌표도 동일(신규 키 `size_m`·`res`만 추가됨).
- 기존 방 7종의 정의·재질·헬퍼 기본 인자는 변경하지 않았다. 추가한 것은 ① 새 재질 10종 ② `shell()`의 `"mall"` 분기 ③ 새 헬퍼 5개 ④ `sphere`/`cyl`/`plant`/`vine`의 **기본값이 기존과 같은** 선택 인자 ⑤ 새 방 3개.
- GLB 파이프라인 변경이 기존 방에서도 도는지 `pantry`로 검증(566KB, 라이트 2개 보존, 메시 2개) 후 **원본 파일을 되돌려 놓았다**.
- 소유 영역 밖 파일 수정 없음.

## 5. 요청 — 개발 에이전트

1. **클라이언트 GRID/layout에 `mall_*` 타일 등록.** `static/poc3d.html`의 `layout` 배열은 지금 지하 3×3만 있다(`hall/pantry/well/library/infirmary/rock×4`). 매장층은 B0 지상 2칸이므로 `ground_surface` 판 위에 `mall_camp`·`mall_food`·`mall_escalator`를 배치할 슬롯이 필요하다(`README.md` §4: 지상 2칸 = 슬롯 0,1 → 3종이므로 슬롯 확장 또는 층 전환 UI 검토).
2. **2D 홈(아이소 격자)에도 동일 등록.** `static/art/iso/mall_*.png` + `tile_meta.json`의 footprint(다른 방과 완전히 동일)를 쓰면 좌표 계산은 그대로다.
3. **방 데이터(`data/rooms.json`)에 매장층 3종 정의**가 필요하다면 건설 비용·생산·설명은 개발/시나리오 소관. 배경은 타일 id만 `mall_camp` / `mall_food` / `mall_escalator`로 맞춰 주면 된다.
4. 지상 타일은 `rock`·`lot`처럼 랜턴 자동 추가 대상에서 제외할지 판단 필요(`poc3d.html`의 `if (id !== 'rock' && id !== 'lot')` 조건). 매장층은 GLB에 자체 랜턴이 들어 있으므로 **추가 포인트라이트 없이도 된다**.
