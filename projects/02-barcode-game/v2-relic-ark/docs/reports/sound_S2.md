# 사운드 보고서 — S2-F (2026-09-20)

담당: relic-sound. 태스크: `docs/TASKS.md` S2-F(앰비언트 3·SFX 7·힐링 스팟 큐 1·큐시트·문턱 크로스페이드 규격).

## 0. 적용한 교본 원칙

- **A1** 안/밖 대비를 소리로 먼저 가른다 → §3 스펙트럼 중심주파수 표로 수치화(안 2025Hz < 밤 3130Hz < 낮 4682Hz).
- **A2** 음악은 드물게 → `music` 버스는 평소 무음, `cue_spot_found.ogg` 재생 시에만 켠다(AUDIO_CUES §1).
- **A3** 힐링 스팟 큐는 물 → 물튀김 → 낮은 배음 한 음 → 모달 코드 → 멜로디 3~4음 순서, D 도리안(D-F-A-B, Dm6 성격 코드)으로 "장조도 단조도 아닌" 색을 냄.
- **A5** 위협은 낮게·멀리서, 개가 먼저 짖는다 → `sfx_dog_warn.ogg`는 저역 위주(중심주파수 349Hz)로 합성했고, 큐시트에 "위협 연출보다 0.3~0.5초 먼저 트리거"를 명시.
- **A6** SFX는 짧고 유물답게 → `sfx_scan_ok.ogg`에 비프 2음 + 종이 찢기 + 카트 바퀴를 순서대로 넣음(§2 코드 설명).
- **A8** 예산과 형식 → OGG(Vorbis), 앰비언트 각 ≤600KB(실제 210~341KB), SFX 각 ≤40KB(실제 4.6~14.8KB), 총 1.12MB ≤3MB.
- **A9** 무료·합성 우선 → 이번 스프린트는 전부 로컬 절차적 합성(`numpy`/`scipy`), 외부 CC0 파일 미사용(`audio/SOURCES.md`에 이유 기록, 의도적 이탈 아님 — A9의 "우선순위" 중 합성을 택한 것).
- **A10** 침묵을 설계한다 → `cue_spot_found.ogg` 시작에 0.8초 무음(`gen_audio_cue.py`의 `LEAD_SILENCE=0.8`).
- **00_COMMON P3** 감정의 가속도 → 발견 큐가 위기(밤·개 경고) 직후에 오도록 트리거 설계를 제안(AUDIO_CUES §3-4).
- **07_AI_GAMEDEV W1/체크리스트 1** 사람이 읽고 고칠 수 있는 크기 → 생성 스크립트를 기능별로 4개 파일(공통/앰비언트/SFX/큐)로 쪼갬, 각 함수는 시드 고정으로 재현 가능.

## 2. 합성 방식 설명 (요약, 상세는 `audio/SOURCES.md`)

- **안(amb_inside, 50초 루프)**: 48/55Hz 저역 비트(터빈) + 3.2~8kHz 랜덤 플리커 히스(랜턴) + 성긴 물방울(글리산도+클릭, 11회) + 천 스침(대역 노이즈 버스트, 7회) → 전체 로우패스 4.5kHz → 짧고 어두운 합성 리버브(0.4s, wet 0.18).
- **밖·낮(amb_outside_day, 50초 루프)**: 핑크노이즈 바람(150~7kHz, 돌풍 LFO) + 잎 스침(2.2~8.5kHz, 같은 LFO로 결맞음) + 새 글리산도 칩 16회(랜덤 피치 2.2~4.8kHz) → 하이패스 70Hz → 길고 밝은 리버브(2.0s, wet 0.32).
- **밖·밤(amb_outside_night, 50초 루프)**: 좁고 낮은 바람(90~1.8kHz) + 귀뚜라미 펄스(캐리어 4.2/6.1kHz × 트릴게이트 25Hz × 패킷 2.5초) + 야간 대기 히스(1.2~7kHz, 옅게) + 저역 스윕 공룡 울음 1~2회(85~100→32~42Hz, 가장자리 회피) → 밝은 리버브지만 낮보다 낮은 웨트(1.8s, wet 0.28).
- **SFX 7종**: 클릭+저역 붐(랜턴), 크래클 루프 1.5초(모닥불), 노이즈 버스트+플롭+물방울 후속(물 튀김), 비프 2음+종이 찢기(랜덤 진폭 텍스처)+카트 바퀴(16회 지터 클릭)(스캔 성공), 종이 미끄러짐+3배음 종(쪽지 도착), 대역 노이즈+저역 텀프(카드 놓기), 저역 노이즈+글리산도 조합 2회(개 경고).
- **힐링 스팟 큐(cue_spot_found, 0.8초 무음+30초 루프)**: 물소리 베드(3초에 걸쳐 차오름) → 1.2초 물튀김 → 3초 D3 배음(피아노풍, 4개 부분음) → 7초부터 Dm6 코드(D3/F3/A3/B3, 2초 어택 패드) → 10/13.5/17/21초 멜로디(A4-G4-F4-D5) → 24.5초 잔잔한 물튀김 → 밝은 리버브(3.2s, wet 0.35).
- **루프 이음매**: 모든 루프는 목표 길이(L)+여유(fade)를 생성한 뒤 `crossfade_loop()`로 등파워 크로스페이드. 저주파 변조(터빈 앰프, 바람 돌풍, 귀뚜라미 패킷)는 루프 길이의 정수 분의 1 주기로 맞춰 이음매에서 변조가 끊기지 않게 했다.

## 4. 05_SOUND §5 자가 검수

1. **눈 감고 들어도 안/밖을 아는가?** 그렇다. 안은 저역 웅웅+물방울 클릭이 지배적(중심주파수 2025Hz, RMS -22.5dB로 셋 중 가장 조용), 밖은 바람의 광대역 히스+새/귀뚜라미의 고역 성분이 뚜렷하다(중심주파수가 밤도 안보다 1.55배 높음). **주의**: 최초 구현에서 밤 앰비언트가 저역 바람+귀뚜라미 위주라 중심주파수가 안(2025Hz)보다 낮은 1259Hz로 나왔다 — "밤이라 어둡다"를 "실내처럼 어둡다"로 잘못 번역한 것. 야간 대기 히스(1.2~7kHz)를 추가하고 크리켓 비중을 높여 3130Hz로 재작업했다. 이 과정 자체가 A1의 좋은 반례라 기록해 둔다.
2. **발견 큐 직전에 침묵이 있는가?** 그렇다. 파일 자체에 0.8초 무음을 넣었다(A10, `LEAD_SILENCE=0.8`). 발견 연출 시점에 게임이 이 파일을 트리거하면 자동으로 침묵-후-소리 구조가 된다.
3. **리더는 기계·상업의 소리, 정원사는 자연의 패턴인가?** 이번 스프린트 산출물에는 리더/정원사 전용 시그니처가 없다(범위 밖 — 부족 모티프 6종은 스프린트 3 후보). `sfx_scan_ok.ogg`(비프+카트바퀴, 상업/기계 계열)만 리더 쪽 어휘에 해당하는 간접 근거. 다음 스프린트에서 A4·A7을 정면으로 다룰 것을 제안.
4. **개 짖음이 위협보다 먼저 오는가?** 파일 자체는 순서를 강제할 수 없다(사운드가 만드는 건 소재, 순서는 트리거 타이밍의 몫). `docs/AUDIO_CUES.md`에 "`ai:dog_warn`을 위협 연출보다 0.3~0.5초 먼저 트리거"를 명시해 개발에 요청했다. `sfx_dog_warn.ogg` 자체는 저역 중심(348.9Hz)으로 합성해 A5의 "위협은 낮게, 멀리서"와도 맞춘다.
5. **총 용량·형식·큐시트가 규격 안인가?** 총 1.12MB(≤3MB), 형식 OGG Vorbis, 큐시트 `docs/AUDIO_CUES.md` 존재. 통과.

## 5. 미완·리스크

- **부족 모티프 6종(A7)**: 이번 태스크(S2-F) 범위 밖. `docs/TASKS.md` 스프린트 3 후보에 이미 있음.
- **CC0 외부 음원 미사용**: 절차적 합성만으로 충분했지만, 크리켓·공룡 울음 등은 실제 CC0 필드 레코딩보다 사실감이 떨어질 수 있다. 플레이테스트 반응이 안 좋으면 `freesound.org`(CC0 필터)로 보강 예정(그때 `audio/SOURCES.md` 표를 채운다).
- **리더/정원사 시그니처(A4)**: 미착수.
- **청취 검증의 한계**: 이 에이전트는 사람 귀로 직접 들어보지 못하고 수치(RMS·피크·중심주파수)로만 자가검수했다. PM 재현 시 실제로 재생해 "정말 안/밖이 구분되는지" 확인 요청.
- **cue_spot_found 루프 재생 방식**: 0.8초 무음을 매 반복에 포함할지, 최초 1회만 포함할지는 게임 오디오 엔진 구현에 달려 있다(§AUDIO_CUES §3-4에 두 옵션 제시).

## 6. 개발에게 요청 (요약, 상세는 `docs/AUDIO_CUES.md` §3)
