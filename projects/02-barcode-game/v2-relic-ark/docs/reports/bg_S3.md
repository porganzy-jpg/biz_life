### 코드 재사용 (정의 중복 0)
`blender_dome.py`는 `blender_scenes.py`를 `importlib`로 불러 `iso`(=`blender_iso`)·`fresh()`·`alpha_mat()`·`join_scene()`·`export()`·`preview()`·`aim()`·`sky()`를 **그대로 쓴다.** 재질·원시도형(`cube/cyl/sphere`)·CC0 소품 로더(`prop`)·생활 소품(`bedroll/plant/vine/laundry/jug/shelf_unit/can_pile/shards/moss`)은 한 줄도 다시 정의하지 않았다.
`git diff tools/blender_iso.py tools/blender_scenes.py tools/blender_rooms.py tools/blender_export_glb.py tools/gen_art.py` → **비어 있음(무변경).**

기존 헬퍼가 `z=0`을 가정하는 문제는 새 정의가 아니라 래퍼 하나로 풀었다:
```python
def at(z, fn, *a, **k):      # 생성된 루트 오브젝트만 z 만큼 올린다
```
덕분에 3개 층(z=7.0 / 11.4 / 15.8)의 방 안에서 S1·S2의 소품 헬퍼가 그대로 산다.

## 2. 구조 — 격자·원점·방향 규약

- **원점 (0,0,0) = 해저 바닥에 박힌 앵커 기둥 발의 중심.** +Z 위.
- **유리 껍질** = 중심 (0,0,15), 반지름 13의 구. 바닥 z=2, 꼭대기 z=28. 즉 돔은 해저에서 2m 떠 있고 기둥이 그것을 꿴다.
- **6m 격자 유지.** 기둥 셀을 중심에 두고 이웃 여섯 칸이 거리 6.0m·60° 간격에 놓인다. 방 셀은 **맞변 6.0m 정육각 프리즘**(= 기존 한 칸), 벽 높이 **2.6m**(기존 규약), 슬래브 0.3m.
- **층 3개**, 층간 4.4m: L0 z=7.0 / L1 z=11.4 / L2 z=15.8.

| 방 | 층 | 슬롯각 | 등불색 | 성격 |
|---|---|---|---|---|
| 에어락 | L0 | 240° (카메라 최근접) | `#FFA82A` | 바닥 문풀 + 아래로 뻗는 관 |
| 저장고 | L0 | 0° | `#E88A38` | 통조림 피라미드·선반·통 |
| 거주 | L1 | 180° | `#FF9236` | 침낭 3·빨래줄·쪽지·화분 |
| 작업장 | L1 | 300° | `#FF6E1E` | 작업대·모루·건져 온 쓰레기 |
| 온실 | L1 | 60° | `#FFB63F` | 재배단 3·화분 16·덩굴 |
| 전망 라운지 | L2 | 240° | `#FFB468` | 의자 3·낮은 탁자·유리 쪽 난간 |
| 목욕탕 | L2 | 120° | `#FF9A5E` | 민물 욕조·김·수건·빨래줄 |
| 도서실 | L2 | 0° | `#FFA844` | 3면 서가·책상·바닥 책탑 |

- **벽 제거 규칙(B6)**: 6면 중 카메라를 향하는 면(`cos(면각 − 225°) > 0.1`)을 없앤다 → 180°·240°·300° 벽이 빠지고 0°·60°·120°만 남는다. 벽이 없어도 육각이 읽히도록 **모서리 기둥 6 + 상단 림보 6**은 항상 세웠다. 기둥을 향한 안쪽 벽에는 문(문설주 2 + 상인방)을 뚫고, 기둥에서 셀까지 짧은 연결관을 놓았다.

### 사선 절단 (핵심)
평면 단면이 아니라 **구를 기울어진 평면으로 자른다.** 남기는 조건은
```
dot(u, VXY) < 0.62 − 0.45 · u.z          (u = 껍질 법선, VXY = 수평 시선 방향)
```
법선이 `VXY + 0.45·Z` 인 평면 = **수평에서 24° 기운 사선**. 결과:
- 카메라를 정면으로 보는 허리께 유리는 사라져 **내부가 직접 보이고**,
- **꼭대기 유리는 남아서** 위에서 유리 너머로 방을 내려다보게 되며(투과),
- **아래앞쪽 유리도 남아서** 가장 낮은 방이 유리 뒤로 보인다.
절단 평면 ∩ 구 = 반지름 10.7m의 기울어진 원 → 이 자리에 밝은 구조 칼라(`cutrim`)를 둘러 "잘린 면"이 화면에서 읽히게 했다.

## 3. 자가 평가 — 직군 교본 03 §5 다섯 문항

**1) 주색 하나와 등불 하나가 보이는가?**
방 단위로는 **예** — 방마다 등불 하나(점광 + 발광 전구)뿐이고 그 색이 방의 주색이다. 화면 단위로는 **의도적으로 둘**: 난색(안)과 한색(밖). 이건 B1 위반이 아니라 D1의 요구다.
다만 "방마다 다른 등불색"(태스크 지시)과 "세 번째 주색 금지"(D1)가 충돌해서, **색상환이 아니라 같은 난색 대역 안의 색온도 차이로만** 구분했다(`#FF6E1E` 작업장 ~ `#FFB63F` 온실). 초록·청록 등불은 쓰지 않았다. 이 해석을 D1 우선으로 기록한다.

**2) 초록이 자란 자리가 있고, 사람이 오늘 밤 자는 흔적이 있는가?**
**예.** 초록은 온실(재배단 3 + 화분 16, 시드 난수 산포)·거주·라운지·목욕탕·도서실의 화분과 덩굴에 있다. 물속이라 야생 초록이 자랄 자리가 없으므로 **초록은 전부 사람이 기른 것**이다 — 이 세계에서 B2의 "초록 = 생명"이 더 세게 읽힌다.
자는 흔적: 거주에 침낭 3 + 베개 + 빨래줄 + 벽 쪽지 3 + 컵 둘 놓인 낮은 탁자. 에어락엔 잠수복 5벌과 채집망의 유물 3개, 목욕탕엔 수건 4장과 김. **빈 바닥 없음.**

**3) 안/밖 중 어디인지 밝기만으로 알 수 있는가?**
**예.** 물은 거의 검정(그라디언트 `#04161F`→`#000101`)이고 돔 안이 화면에서 제일 밝다. 색까지 갈라 뒀다(난색/한청록).

**4) 격자처럼 놓인 소품이 있는가?**
인공 구조(유리 격자·서가·재배단·잠수복 걸이·선반)는 격자가 맞다 — B5의 "사람이 만든 것". 자연물(화분·덩굴·이끼·관벌레·바위·부유물·발광 생물)은 전부 시드 난수 산포다.

**5) 용량·격자 원점·회귀 diff가 기준 안인가?**
격자 원점 ✅ (§2, 실측 bbox §4). 회귀 ✅ (기존 도구 5개 무변경, `git diff` 비어 있음). **용량은 §4에 정직하게 적는다 — 처음 뽑은 GLB가 2,505 KB로 B8의 1.5MB를 넘었다.**
