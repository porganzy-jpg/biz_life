## 1. 정한 값

| 항목 | 임시값 | 확정 | 근거 한 줄 |

### 사슬 각인 열하나 (`arc_imprints`)

**역할 진화(위기 각인 3개)에는 세지 않는다**(`count_toward_evolution: false`). 시나리오 제안을 승인했다. 받은 것으로 변하는 것과 위기로 변하는 것은 다른 성장이다(B6).

시나리오의 자리표시 값을 대부분 승인했고, 셋을 고쳤다:
- **펴진 손** 건설 할인 0.03 → **0.05**: 기존 각인 「비킨 자」와 같은 크기. 3%는 화면에 보이지 않는다.
- **상 차리는 이** 사기 상한 1 → **2**: 기존 사기 상한 각인과 같은 크기.
- **잎을 나누는 이** → 새 키 **`food_daily_all` −0.05/인**: "모두의 하루 식량"이라 자기만 쓰는 키와 다르다. 주민 10명이면 소비의 8%.

나머지 여덟은 승인했다. 공통 예산은 자동 대항 +0.2 / 사기 회복 +1 / 생산 ±2~5% / 방 +1/틱이고, 대가는 효과의 절반 크기다.

### 장식 손님 여덟 (`visitor_effects`)

**오는 방식**: 꼬리표가 있으면 하루 **0.35** 확률로 오고, 하루 머문다.

| 손님 | 효과 |
|---|---|
| 담요게 | 그 방 주민 다음 아침 사기 +0.3 |
| 등불고기 | 그날 그 방 조명 전력 −1 |
| 소라게 장수 | 같은 값·다른 갈래 유물을 맞바꾼다 |
| 책장새우 | 그날 기록 +1 |
| 꼬마 장어 | 식량 −1, 사기 +0.5 |
| 아기 해파리 | 기르는 방 +10% |
| 유리별 | 그 방 금 수리비 −1 |
| 나사게 | 부품 +1(3일에 한 번) |

**크기 확인**: 여덟이 다 와도 하루 재료 +1 남짓이다. 보통 플레이어 하루 건설 재료의 5% 아래라 경제에 닿지 않는다.
