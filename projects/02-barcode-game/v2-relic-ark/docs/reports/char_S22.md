## 1. 맞는가 — 감사 결과

## 3. 합성 규격 — 클라이언트 담당(aeb00832c0aeacab8)용
정본은 `static/art/chars/front/p2/meta.json` 의 `imprint_compose` 다(아래와 같은 내용).

**격자.** 모든 겹이 같은 셀(원화 64, `_x4` 256), 같은 3열 × 31행이다. **오프셋은 0**이다 — 행·프레임마다 위치가 이미 각 칸에 들어 있으므로 본체와 같은 (열, 행) 칸을 같은 자리에 그리면 된다. 행별 오프셋 데이터가 따로 필요 없게 만들었다.

**한 사람을 그리는 순서**(아래로 갈수록 위에 얹는다):
1. 본체 `src/<role>[_b].png`(체형 B 는 `_b`)
2. 머리 `hair/<role>_<body>/<hair>.png`
3. 얼굴: 머리가 `short` 가 아니고 얼굴이 `f0` 가 아니면 `faces/<role>_<body>/<hair>_<face>.png`, 아니면 `faces/<role>_<body>/<face>.png`(`combo_patch_rule`)
4. 잠수복 겹 `suit/<role>_<body>.png` — **원정(바깥)일 때만**
5. 각인 — 그 사람이 가진 것만, **별도 오프스크린 한 장**에 모은다:
   - 파일은 `imprints/role/<role>_<body>/<id>.png` 가 있으면 그것을 쓴다.
   - 없으면 몸 모양 폴더를 쓴다: 어른 A = `imprints/`, 어른 B = `imprints/b/`, 아이 A = `imprints/kid/`, 아이 B = `imprints/kid_b/`. 파일 이름은 `<id>.png` 다.
6. 5에서 모은 한 장을 `imprints/rolemask/<role>_<body>.png` 로 지운다(`globalCompositeOperation = 'destination-out'`, 같은 칸).
7. 지운 각인 한 장을 본체 위에 그린다(`source-over`).

**주의**
- 가림판은 **각인 한 장에만** 건다. 본체 캔버스에 걸면 모자·도구가 지워진다.
- 좌우 반전: 옆모습 행(오른쪽 원본)·방별 작업(왼쪽 원본)을 반전할 때는 1~7 전부에 같은 반전을 건다(셀 가운데 축).
- 배율: `_x4.png` 를 쓰거나 x1 을 NEAREST 정수 확대한다(`image-rendering: pixelated`). 방 ×3 화면이면 x1 × 3.
- 각인이 몸 앞 물건에 가려지는 프레임(132프레임)은 시트 칸이 이미 비어 있다. 클라이언트가 따로 할 일은 없다.
- `water_memory`(이마 젖은 머리)는 머리 위에 얹히도록 설계된 것이라 머리 패치 **다음**(5단계)에 그리면 맞다.
- 각인 위치는 체형 A/B/아이마다 다르다. 반드시 체형 폴더를 골라야 한다(역할만으로 고르면 틀린다).
