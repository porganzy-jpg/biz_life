# 개발 — 타이틀·불러오기 화면 보고 (2026-10-13)

/base 에 들어오면 바로 방주로 가던 것을, 접속 → 타이틀(키아트 느린 시차 + 로고 + 실제 진행) → 「눌러서 시작」 → 방주 로 바꿨다. **커밋하지 않음.**

## 1. 만든 것
| 파일 | 내용 |
|---|---|
| static/title.js (새 파일) | 타이틀 전부. base.js 보다 먼저 불린다 |
| static/base.html | `<body>` 바로 뒤 `<script src="/static/title.js">` 한 줄. 파비콘 icon_48·icon_192, apple-touch-icon icon_192(`data:,` 빈 아이콘 대체) |
| static/base.js | 첫 로드 끝에 `ARKTITLE.arkLoaded(st)`(실패면 `arkFailed`). 큰 창 줄(qReady)은 `ARKTITLE.gate`(첫 탭) 뒤에 연다 → 밤사이·만남·방송이 타이틀 뒤에 숨어 지나가지 않는다. 모든 방 플레이트·금 간 판 미리 받기는 `afterReady` 로 첫 화면 뒤에. 잠긴 칸 문장은 ui_moments `sealed.{tower,rock}.{label,line}`(시나리오 요청, 기본값도 새 문장) |
| static/base_cards.js | 카드 틀·뒷면·빛 미리 받기를 `afterReady` 로(첫 화면 뒤) |

### 화면
- **키아트**: 배경 담당 `static/art/title/meta.json` 그대로 사용. 화면 비에 가까운 크롭(landscape 1280×800 / phone 844×390), 층 far·cliff·tower·near, 시차 0.15/0.45/0.7/1.0. 카메라는 가로 ±1.5%·세로 ±1%, 주기 8초·10초(meta motion_hint) + 마우스 쪽으로 조금. 층은 오는 대로 0.6초에 걸쳐 나타난다. meta 가 없으면 M5 층(back·cliff·tower_shell·elevator_shaft·entrance·front)으로 같은 방식.
- **로고**: 로고 A `brand/zealandia/lockup_horizontal_dark.png` 를 meta 의 crops[*].logo 자리에(1280: 743,448 w486 / 844: 520,241 w303 h105 — 작게). 새로 만들지 않음.
- **글**: 처음 = `title.tagline[0]` 「내 집의 진짜 물건이, 바다 밑 사람들의 삶이 됩니다.」 / 다시 온 사람 = `title.return.zero|one|many`({n} = 서버 `overnight.items` 중 needs 를 뺀 수). 불러오는 동안 `title.loading[]` 을 2.4초마다 돌림. 단추 = `title.start_label[0]` 「눌러서 시작」.
- **배치**: 1280 은 로고 아래에 글·진행·단추, 844 는 로고 아래가 좁아(44px) 로고 위 물빛 쪽에. 진행 막대 자리에 다 되면 단추가 들어선다(큰 창 하나).
- **진행(가짜 아님)**: title.js 가 `HTMLImageElement.src` 를 이 화면이 열려 있는 동안 감싸 실제로 시작된 그림 요청 수와 끝난 수를 센다 + 첫 `/api/ark`. 진행 = 25%×방주 장부 + 75%×그림 끝/시작. 다 됨 = 장부 옴 && 시작한 그림 모두 끝 && 0.5초 동안 새 요청 없음. 25초 넘으면 남은 그림이 있어도 들어갈 수 있다(들어가서 마저). 다 되면 원래 Image.src 로 되돌린다. 손등불(loading_lantern 8칸)이 진행률 round(p×7) 칸으로 켜지고, 다 켜지면 숨쉬기.
- **소리**: 첫 탭에서 `sfx_lantern_on`(0.45) + `amb_inside` 고리 재생을 0→0.22 로 천천히(자동 재생 정책 — 탭 전에는 소리 없음).
- **줄임 동작**: 시차·카메라·층 나타나기·단추 맥박·손등불 숨쉬기 없음, 닫힘 즉시.
- Enter·Space 로도 시작. 방주를 못 불러오면 「다시 시도」(새로고침).

## 3. 교본
- D5(첫 3분 루프): 탭 하나가 늘었다 — 원칙과 다르다. 이유: 사용자 요청이고, 이 탭이 없으면 브라우저가 소리를 막는다(첫 소리 = 첫 탭). 다 되기 전에는 누를 것이 없어 기다림이 늘지는 않는다.
- D3(기다림은 보상으로): 불러오는 동안 손등불이 켜지고 관리실 문장이 돈다. 막대만 있지 않다.
- D8(모바일 성능): 느린 망에서 첫 화면을 먼저 받게 미리 받기를 뒤로. 타이틀 캔버스는 탭 뒤 0.75초에 멈추고 지운다.
- D7: 층·로고 자리·손등불 칸 수는 meta.json, 문장은 ui_moments.title 에서 읽는다.

## 4. 남은 것·리스크
- 느린 망에서 HTML+title.js 가 오기까지 2.8초는 서버 왕복 수(지연 400ms) 탓. 줄이려면 title.js 를 HTML 에 넣어야 한다(지금은 한 줄 규칙을 지켰다).
- 진행률은 「시작된 요청」 기준이라 초반에 분모가 작다가 커진다. 막대는 뒤로 가지 않게 최댓값만 따른다.
- 실제 아이폰 사파리의 소리 첫 재생 확인은 사용자 몫.
