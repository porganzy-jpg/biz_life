# 개발 S35 화면 — 실내복 · 살림 띠 · 바닥이면 기색 흐리게 · 방은 사람 때문에 열린다 (2026-10-25, 커밋하지 않음)

서버 API_S19 §24, docs/C_PLAN.md §3·§4, 캐릭터 docs/reports/char_indoor.md 「클라이언트 규격」(정본 indoor/meta.json outfit_rule)대로 했다. 확인은 8041 에서만 했다(8002 는 건드리지 않음, 확인 뒤 8041 껐음).

## 1. 실내복 (base.js · base_core.js · base_people.js)
- 시트 뿌리 폴더만 옷차림에 따라 바꾼다. 셀·행·발 기준선·반전·배율 규칙은 그대로다.
  - **실내(`front/p2/indoor/`)**: 방 안·홀·엘리베이터·걷기·끌기.
  - **투구 판(`front/p2/`)**: 에어락·문간 자리, 바깥에서 온 손님, 바깥에 나간 사람, 습격 중 방 안 사람.
  - 원정은 이 화면에 없다(expedition3d 몫).
- 시트 사슬은 p2i(실내) → p2 → c → b → a 다. 실내 시트가 없으면 조용히 p2 로 내려간다. 마스크도 같은 뿌리를 쓴다.
- **각인**: 같은 뿌리의 `imprints/`·`rolemask/` 를 쓴다. 실내 몸은 각인 자리가 달라서 실내 판에는 `indoor/imprints/` 와 `indoor/meta.json imprint_fit_result.override_files`(51판)를 쓴다. 머리 위 표식(pips)은 같은 파일이다.
- **초상**: 인물 카드·얼굴 띠·「어디로」 얼굴은 `indoor/<role>.png`(x4)다.
- **에어락에서 옷이 바뀌는 순간**: 그 사람 몸에 0.6초 김(밝은 타원이 부풀며 사라짐)이 한 번 핀다(문 열림 대신). 들고 끄는 동안은 지금 옷을 유지한다. 처음에는 끄는 동안 실내복으로 바뀌었다가 다시 돌아가는 깜빡임이 있었고, 이를 고쳤다.
- 확인(844·1280):
  - 시작: 문간 셋 모두 투구 판.
  - 요리사를 식량창고로 옮기면 걸어 들어가는 순간 실내복으로 바뀐다(바뀜 기록 1회).
  - 습격(debug longneck) 중에는 방 안 요리사도 투구 판이다.
  - 얼굴 띠 초상은 indoor 시트다(1280 확대 스크린샷: 요리 모자·실내복).

## 2. S35 서버 필드
- **살림 띠**:
  - PM 결정대로 식량·물만 띠(household[].fill, 3일치 = 가득)로 그린다. 전력·부품은 숫자다.
  - 띠 칩을 누르면 살림 한 줄(「식량 2.2일치.」)이 맨 앞에 붙는다.
- **바닥이면**(household_dim):
  - 얼굴 띠의 기색과 얼굴이 한 단계 흐려진다.
  - 필요 줄 대신 「살림이 비어 다들 기운이 없습니다」를 보인다. 열린 이야기 줄은 그대로다.
  - household_note 는 그날 한 번 방송한다.
- **닫힌 방 종류**: 짓기 목록에서 자물쇠 표시와 함께 `locked_ko` 「농부가 오면 열립니다 / 학자가 오면 열립니다 / 의무병이 오면 열립니다 / 이 방을 편해할 분이 오면 열립니다」로 보이고, 눌리지 않는다. 서버의 「아직 ○○을 편해할 분이 없습니다」 조건 줄은 겹치므로 뺀다. 「여기를 지으면」 줄에서는 닫힌 방이 흐리게 뒤로 간다.
- **room_news**(「열림 · 온실 — ○○ 님 덕분」, 머물 칸 없음): 한 번씩 방송한다.
- **목표의 사람 이름**: goals[].title_ko 를 그대로 쓴다.
- **덤**: 짓기·도감 패널이 열리면 얼굴 띠를 잠시 숨긴다(844 에서 띠가 패널 위로 겹치던 것).
