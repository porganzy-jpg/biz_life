# 개발 S35 화면 — 실내복 · 살림 띠 · 바닥이면 기색 흐리게 · 방은 사람 때문에 열린다 (2026-10-25, 커밋하지 않음)

서버 API_S19 §24, docs/C_PLAN.md §3·§4, 캐릭터 docs/reports/char_indoor.md 「클라이언트 규격」(정본 indoor/meta.json outfit_rule)대로 했다. 확인은 8041 에서만 했다(8002 는 건드리지 않음, 확인 뒤 8041 껐음).

## 1. 실내복 (base.js · base_core.js · base_people.js)
- 시트 뿌리 폴더만 옷차림에 따라 바꾼다. 셀·행·발 기준선·반전·배율 규칙은 그대로다.
  - **실내(`front/p2/indoor/`)**: 방 안·홀·엘리베이터·걷기·끌기.
  - **투구 판(`front/p2/`)**: 에어락·문간 자리, 바깥에서 온 손님, 바깥에 나간 사람, 습격 중 방 안 사람.
  - 원정은 이 화면에 없다(expedition3d 몫).
- 시트 사슬은 p2i(실내) → p2 → c → b → a 다. 실내 시트가 없으면 조용히 p2 로 내려간다. 마스크도 같은 뿌리를 쓴다.
- **각인**: 같은 뿌리의 `imprints/`·`rolemask/` 를 쓴다. 실내 몸은 각인 자리가 달라서 실내 판에는 `indoor/imprints/` 와 `indoor/meta.json imprint_fit_result.override_files`(51판)를 쓴다. 머리 위 표식(pips)은 같은 파일이다.
- **초상**: 인물 카드·얼굴 띠·「어디로」 얼굴은 `indoor/<role>.png`(x4)다.
- **에어락에서 옷이 바뀌는 순간**: 그 사람 몸에 0.6초 김(밝은 타원이 부풀며 사라짐)이 한 번 핀다(문 열림 대신). 들고 끄는 동안은 지금 옷을 유지한다. 처음에는 끄는 동안 실내복으로 바뀌었다가 다시 돌아가는 깜빡임이 있었고, 이를 고쳤다.
- 확인(844·1280):
  - 시작: 문간 셋 모두 투구 판.
  - 요리사를 식량창고로 옮기면 걸어 들어가는 순간 실내복으로 바뀐다(바뀜 기록 1회).
  - 습격(debug longneck) 중에는 방 안 요리사도 투구 판이다.
  - 얼굴 띠 초상은 indoor 시트다(1280 확대 스크린샷: 요리 모자·실내복).

## 2. S35 서버 필드
- **살림 띠**:
  - PM 결정대로 식량·물만 띠(household[].fill, 3일치 = 가득)로 그린다. 전력·부품은 숫자다.
  - 띠 칩을 누르면 살림 한 줄(「식량 2.2일치.」)이 맨 앞에 붙는다.
- **바닥이면**(household_dim):
  - 얼굴 띠의 기색과 얼굴이 한 단계 흐려진다.
  - 필요 줄 대신 「살림이 비어 다들 기운이 없습니다」를 보인다. 열린 이야기 줄은 그대로다.
  - household_note 는 그날 한 번 방송한다.
- **닫힌 방 종류**: 짓기 목록에서 자물쇠 표시와 함께 `locked_ko` 「농부가 오면 열립니다 / 학자가 오면 열립니다 / 의무병이 오면 열립니다 / 이 방을 편해할 분이 오면 열립니다」로 보이고, 눌리지 않는다. 서버의 「아직 ○○을 편해할 분이 없습니다」 조건 줄은 겹치므로 뺀다. 「여기를 지으면」 줄에서는 닫힌 방이 흐리게 뒤로 간다.
- **room_news**(「열림 · 온실 — ○○ 님 덕분」, 머물 칸 없음): 한 번씩 방송한다.
- **목표의 사람 이름**: goals[].title_ko 를 그대로 쓴다.
- **덤**: 짓기·도감 패널이 열리면 얼굴 띠를 잠시 숨긴다(844 에서 띠가 패널 위로 겹치던 것).

## S36 전 작은 손질 (같은 날, 커밋하지 않음)
1. **가까이 보면 목표 판이 방 이름표를 가림**: 배율이 1.1 이상이면 펼친 목표 판을 「오늘의 목표 n/3 ▸」 한 줄로 접는다. 멀리 보면 다시 편다. 가까이 볼 때 직접 펴면 그 배율 동안은 펴 둔다. 화살표도 같이 바뀐다. 함께 찾은 것: 「다음 할 일」 줄이 숨는 날(4일째부터 idle)에는 목표 판이 얼굴 띠 뒤에 깔려 보이지 않았다. 목표 판을 「다음 할 일」 줄 또는 얼굴 띠 중 아래쪽 밑에 두게 고쳤다.
2. **폰 가로에서 문어 「어디로」 카드가 위 줄을 덮음**: 높이를 calc(100% − 110px)로 묶고 안에서 밀어 보게 했다.
- 확인(8041, 5일째 방주):
  - 844: 문어 카드 위 끝 54px, 위 줄 아래 끝 38px. 겹침 없음.
  - 1280: 배율 1.62 에서 목표 판이 한 줄로 접힘(방 이름 「식량창고 0/4」이 보임). 맞춤 배율 0.5 에서 다시 펴짐.
  - 콘솔 오류 0. 스크린샷 s35fix_goals_zoom_{844,1280}.png, s35fix_octwhere_{844,1280}.png.
  - 덤: 5일째 문어 조각 카드에 가보 줄이 맨 앞(heirloom_first)으로 뜨는 것도 실화면으로 처음 확인했다(S31 남은 확인).
- 참고: 확인 중 8041 이 anyio import 오류로 500 을 냈다. 다른 세션이 같은 시각(22:28)에 anyio 를 다시 설치하던 중이라, 반쯤 깔린 파일을 읽은 탓이었다. 8041 을 다시 띄우니 정상이었다. 8002 는 건드리지 않았다.
- **S36(쓰는 자리)**: 서버 작업 트리에 core.rooms[slot].use_spots·/api/ark.use_news 가 들어와 있다. 하지만 API 문서(§25) 공지가 아직 없고, 방마다 「쓰는 자리 둘」의 그림 좌표(칸 좌표)가 배경·캐릭터 메타에 없다. 둘이 오면 시작한다.

## 실내복 후속 (캐릭터 실화면 확인 · PM 결정, 커밋하지 않음)
1. **처음 실내복으로 바뀔 때 몇 프레임 색 사각형이 나오던 것**:
  - 타이틀 「다 됨」 뒤(ARKTITLE.afterReady)에 실내 시트 8역할 × 체형 A·B 를 미리 받는다.
  - 실내 시트가 아직 안 왔으면 투구 판(p2)으로 그린다. 그것도 없으면 같은 역할 A 체형 시트로 그린다.
  - 검수 ARKBASE.rectCount(): 사각형은 타이틀 뒤(첫 시트가 오기 전)의 6~8번뿐이고, 타이틀을 누른 뒤로는 0 이다.
2. **PM 결정 — 문간에서 기다리는 사람도 실내복**:
  - 새 방주 첫 화면의 셋이 실내복이다.
  - 투구 판은 막 돌아온 원정대(expedition_return.members, K.ext.podGearing)·바깥에 나간 사람·손님·습격 중 방 안 사람에만 쓴다.
3. **844 목표 판**: 처음엔 접힌 한 줄이다. 펼친 뒤 다른 곳을 누르면 다시 접는다(확인: 접힘 → 펼침 → 바깥 누름 → 접힘).
4. **생김새(body·hair·face)**:
  - 서버가 residents_list[] 에 body·hair·face 를 주면 그대로 쓴다.
  - 체형 B 는 <role>_b 시트다. 머리·얼굴은 기본(short+f0)과의 차이 패치를 옷차림 뿌리의 hair/<role>_<body>/<hair>.png 와 faces/…/<hair>_<face>.png(또는 <face>.png)로 얹는다(meta layer_rule). 패치가 다 오기 전에는 기본 얼굴이다.
  - 지금 서버에는 필드가 없어 견본(긴머리 + 얼굴 ②)으로 확인했다(ARKBASE.looks() = cook_a|long|f1|in, 사각형 0).
  - 확인 중 찾은 결함: 합성한 캔버스에 naturalWidth 가 없어 색 사각형으로 떨어졌다. 고쳤다.
- 844·1280 콘솔 오류 0, 400 이상 0. 스크린샷 s35b_pods_{844,1280}.png.

## 겉모습 필드 연결 (API §26, 커밋하지 않음)
- residents_list[].appearance {body, hair, face, sheet} 를 apply 때마다 p.body·hair·face 로 옮긴다(base_people.js). 그리기는 위 「생김새」 절 그대로다(체형 B 시트 + 머리·얼굴 차이 패치).
- 확인(8041, 새 방주 넷, 844·1280):
  - 서버 값 그대로 그려졌다. 예: cook_b|curly|f1, engineer_b|scarf|f2, scout_a|tied|f2. 짧은머리·f0 인 사람은 패치 없이 기본 시트다.
  - 사각형은 타이틀 뒤 6번 그대로이고, 한 번(1280)은 체형 B 시트가 늦게 와서 7번이었다.
  - 콘솔 오류 0, 400 이상 0.
- 남은 것: 초상(인물 카드·얼굴 띠)은 x4 시트를 오려 쓰는데, 머리·얼굴 패치가 x1 만 있어 초상에는 아직 기본 머리·얼굴만 보인다(체형 B 시트는 반영됨). 캐릭터 담당이 x4 패치를 주거나, 화면이 x1 패치를 정수 확대해 얹으면 된다. 다음 손질 때 x1 확대 쪽으로 붙이겠다.
