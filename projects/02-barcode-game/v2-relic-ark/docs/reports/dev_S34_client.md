# 개발 S34 화면 — 사람이 주인공(C안) 1차: 얼굴 띠 · 건네기 결과 칩 · 이유 표시 설명 (2026-10-17)

사용자가 C안(사람이 주인공)을 골랐다. 서버 없이 되는 것부터 했다. 확인은 8041 에서만 했다(사용자 8002 는 건드리지 않음, 확인 뒤 8041 껐음). **커밋하지 않음.**

## 1. 만든 것
| 항목 | 화면 | 파일 |
|---|---|---|
| 얼굴 띠 | 위 줄 바로 아래 식구마다 둥근 칩 하나. 얼굴, 이름, 오늘 필요 표시(물방울; 받았으면 초록 점), 열린 이야기 표시(등불색 고리, 천천히 숨쉼), 기색 한 줄. 누르면 그 사람 카드(ppop). 화면에서 가장 앞(z 8)이고, 그 아래로 「다음 할 일」 → 목표 판 순서로 자리를 자동으로 맞춘다. 사람이 많으면 가로로 밀어 본다. 바깥에 나간 사람은 흐리게 「바깥에 나가 계십니다」 | base_people.js(새 파일), base.css |
| 기색 한 줄 고르는 순서 | 세 번째 기억 → 열린 이야기(arc_line 또는 「할 이야기가 있는 눈치입니다」) → 오늘 필요(받았으면 「오늘 바라던 것을 받으셨습니다」) → 「오늘은 조용히 지내십니다」. **기색 날(mood_hints 해금, 4일째~)에는 필요한 것의 이름을 말하지 않고 「뭔가 찾는 눈치입니다」**(수첩·기색으로 맞히는 재미를 지킨다). 문장 키 `faces.*`(시나리오가 주면 그것) | base_people.js |
| 건네기 결과 칩 | 건넨 직후 화면 가운데 위쪽에 칩 최대 다섯이 차례로 뜬다(4.2초). 순서는 사기 ±n → 「○○ 생산 +10%(오늘)」(effects.room_bonus) → 수첩 +1(revealed) → 마음 ±n(S34 서버 필드: heart/trust/heart_delta 중 오는 것) → 이야기 n/m → 기억 하나 → 꾸밈 n/m → 머리맡에 「물건」. 서버 effects 에 있는 것만 보이고, 「선반에」를 고를 때는 띄우지 않는다 | base_people.js, base_core.js react |
| 이유 표시 설명 | 「어디로」 단추 안의 이유 표시(필요·좋아함·반가움·매듭·기억·꾸밈)를 누르면 건네지 않고 무엇에 좋은지 한 줄 말풍선을 띄운다(5초). 문장 키 `why_help.<종류>`, 없으면 기본 문장 | base_people.js |
| 방 생산 숫자 | 이미 방 카드를 눌렀을 때만 보인다(S33 outputLine). 겉에는 방 이름·정원·사람만 보인다. 생산 방울(식+1)은 거두는 단추라 그대로 두었다 | — |

## 3. 교본·판단
- C안 원칙: 첫 화면에서 가장 먼저 보이는 것이 사람의 얼굴과 기색이다. 방 숫자는 한 번 눌러야 나온다.
- D2(숫자는 화면의 무엇으로): 건넨 결과를 칩으로 보여 줘서 「무엇이 좋아졌나」가 바로 읽힌다. 마음은 서버 필드가 오면 같은 자리에 붙는다.
- D5: 탭이 늘지 않았다. 이유 표시 누르기는 고르기 전에 하는 선택이다. 위험: 이유 표시를 눌러 건네려던 사람이 한 번 더 눌러야 한다. 그래도 PM 지시를 따랐다.
