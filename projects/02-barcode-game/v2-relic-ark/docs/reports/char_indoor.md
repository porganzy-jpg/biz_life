  - 머리카락: 6종 모두 「머리통 위쪽 전체 + 얼굴 창 앞머리 띠」로 시작한다. 그래서 기본(short)이 늘 다른 다섯에 덮인다(패치 규칙의 전제). 긴머리는 관자놀이에서 어깨까지 옆머리를, 곱슬은 머리통 둘레 곱슬을 더한다. 두건은 같은 자리를 천 색으로 칠한다.
  - 머리 위 역할 표식 8종 — 「머리 위는 역할 자리」:

| 역할 | 실내 표식 |
|---|---|
| 요리사 | 흰 요리 모자 + 주황 띠 |
| 정찰병 | 헐렁한 올리브 후드(앞이 트임) + 꼭지·꼬리 |
| 의무병 | 머릿수건 + 이마 십자 |
| 기술자 | 머리카락 위 고글 |
| 농부 | 밀짚 챙 |
| 학자 | 납작 모자 + 깨진 안경 |
| 교섭가 | 접은 챙 모자 + 목도리 |
| 아이 | **노란 털모자 + 방울** |

    모자는 머리카락·얼굴보다 위에 얹되 **얼굴 창 칸은 비킨다.**
  - 일옷 8종: 공기통·허리 랜턴·목 실링·멜빵·놋쇠 버클·무게추 장화를 뺐다. 그 대신 다음을 넣었다.

**한 사람 그리기**(뿌리 = 위 표의 폴더):
1. `<뿌리>/src/<role>[_b].png`(x4 는 `<뿌리>/<role>[_b].png`)
2. `<뿌리>/hair/<role>_<body>/<hair>.png`
3. 얼굴: 머리 ≠ short 이고 얼굴 ≠ f0 이면 `<뿌리>/faces/<role>_<body>/<hair>_<face>.png`, 아니면 `<face>.png`
