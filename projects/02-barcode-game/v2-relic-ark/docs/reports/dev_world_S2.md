## 2. 구현 내용과 설계 판단

### 2-1. 지형 (400×250m, 절차적 하이트맵 + 4채널 스플랫)
- `PlaneGeometry(400,250,200,125)` = 2m 격자 25,000쿼드. 높이는 **결정적 value noise**(`SEED=20260920`) 4옥타브 + 강 카빙 + 몰 평탄화 + 스팟 분지. 같은 시드 = 같은 지형(**D6**).
- 정점마다 **`splat` 어트리뷰트(vec4 = 풀/아스팔트/이끼/물 가중치)** 를 굽는다. 텍스처가 없으면 그 가중치로 섞은 단색(vertexColors)이 쓰이고, 텍스처가 있으면 `onBeforeCompile` 로 주입한 셰이더가 **4장을 월드 XZ 기준 6m 타일로 블렌딩**한다. 수동 샘플링이라 sRGB→선형 변환(`pow 2.2`)을 직접 하고, 타일별 밝기 보정 `gain4 = (1.8, 1.15, 3.0, 1.15)` 를 곱한다 — `moss.png`(#2D4323)가 매우 어두워 그대로 섞으면 초록이 죽기 때문(bg_S2 §7-6 "초록 비율 절반 이상").
- 물은 전역 평면 1장(y=-0.6)이 강과 스팟 분지를 동시에 덮는다.
- 강은 월드 +X 쪽 경계다. 벽이 아니라 위험·거리가 경계(**D9**).

### 2-2. 몰 블록과 문턱 컷 (핵심 구도 판단)
- 기존 방 GLB **14개**(hall·mall_camp×2·mall_food·mall_escalator·pantry·library·infirmary·well·rock×3·lot×2)를 6.2m 격자로 배치.
- **몰 블록만 월드에서 −45° 회전시켰다.** 직교 아이소 카메라(방위 45°)에서 축정렬 벽은 화면에서 −35° 사선으로 갈린다. 몰을 45° 돌리면 문턱 벽이 **화면에서 정확히 수직선**이 되어 첫 컷이 좌/우 반반으로 갈린다(WORLD_PRESENTATION §1-1 "왼쪽은 어둡고 랜턴, 오른쪽은 초록"). 지형·스팟은 축정렬 그대로이고 `toLocal/toWorld` 헬퍼 두 줄로 오간다.
- **어둡게 만드는 법**: 반투명 어두운 천장 평면(59×50m, opacity 0.34, y=5.4)이 **그림자를 드리운다**(`castShadow`). 태양 방위는 항상 문턱 바깥쪽으로 고정하고 고도만 하루에 따라 바꾸므로 천장 그림자가 안쪽을 계속 덮는다. 겉만 덧칠하는 것보다 "빛이 못 들어온다"가 물리적으로 맞고, 랜턴 하나하나가 실제로 보인다(아트 원칙 "랜턴 1 = 주색 1").
- 랜턴: GLB의 KHR 라이트는 **세기 45 고정 클램프**(D10). 총 개수가 GTX 1050의 포워드 렌더를 무너뜨리므로 **문턱에 가까운 10개만 남기고 제거**, 여기에 문턱 랜턴 1 + 스팟 빛기둥 2 = 씬 전체 포인트 라이트 13개(**D8**).

### 2-3. 안개(미탐험) = 종이 레이어
- 1024×640 캔버스에 절차적 **종이 섬유**(얼룩 2,600 + 실선 900, 시드 고정)를 그려 `CanvasTexture`로. 지형 지오메트리를 복제해 +0.3m 띄우고 **UV를 월드 좌표에서 직접 계산**(`flipY=false`)해 좌표 어긋남을 원천 차단.
- 정찰병이 2.5m 움직일 때마다 반경 24m를 `destination-out` 방사 그라디언트로 지운다.
- **안개 밑의 것은 보이지 않는다**: 나무 200·덤불 420·잔해 160(InstancedMesh 4개 = 드로우콜 4)을 0 스케일로 숨겨 두고 안개가 걷힌 반경에 들어온 인스턴스만 드러낸다. 힐링 스팟 오브젝트도 30m 안에 와야 안개 위로 형태가 올라온다. 이게 없으면 나무·전철이 종이 위로 삐져나와 "무지"가 거짓말이 된다.

### 2-4. 주민 · 짐승 · 공룡
- `scout/cook/medic.glb`. **재정규화 금지 준수** — 스케일을 건드리지 않고 발 높이만 `heightAt()`로 맞춘다. 클립 `death,idle,pickup,run,sitdown,standup,walk` 확인.
- 길 찾기 = **직선 + 문턱 회피 근사**(D9): 안↔밖이면 문 안/바깥 웨이포인트 2개를 끼우고, 밖↔밖인데 선분이 몰을 관통하면 옆으로 우회. 실패하면 직진 폴백.
- 지면 클릭 = 선택된 주민(또는 전원)을 그 지점으로. `홀 허브 복귀` 버튼이 전원을 홀로 부른다.
- **개 1마리**가 정찰병 왼쪽 1.3m 에 붙어 다닌다(1.6m 넘게 벌어지면 Walk, 붙으면 Idle). 사람끼리는 떨어져 서고 짐승만 곁에 있다 = 신뢰의 역전이 배치로 보인다(TRUST_AND_COMPANIONS).
- **트리케라톱스 2마리**가 초원 멀리(월드 130,−55 / 146,−44)에서 큰 원을 그리며 Walk 한다. 위협이 아니라 풍경 — 낮 장면의 내용물(하루 사이클 ⑤).

### 2-5. 하루 사이클
- 새벽→낮→저녁→밤 4단계를 **연속 보간**(하늘색·안개색·태양색/세기/고도·반구광·랜턴 세기·천장 불투명도). 버튼 `시간 넘기기` / `자동`(단계당 20초).

### 2-6. 힐링 스팟 (물에 잠긴 전철)
- 월드 (62, 30) — 문턱에서 약 69m. 지형에 얕은 분지를 판다.
- S2-D 씬 GLB 규약대로 배치: 원점이 승강장 상면(y=0), 수면이 +0.14 이므로 `position.y = WATER_Y − 0.14`. 재질명 `Water` 를 찾아 우리 물 셰이딩(청록 0x3FA79E, opacity 0.74, roughness 0.1)으로 덮고, GLB 조명 2개는 0.3배(=13.5) + decay 2 + distance 22.
- **발견 판정**(정찰병 반경 6m) → 안개를 반경 30m + 둘레 12곳으로 걷어내고 → **정찰병을 `marker_threshold`(스팟 로컬 −6.0, 0.48, +5.2)에 세우고 −Z(전철 쪽)를 보게 한다** → 카메라가 2.6초에 걸쳐 내려앉고(고도 45°→26°, 줌 26→15) → 0.9초 뒤 `discovery_text` 가 화면 아래쪽에 페이드 인. "아무도 들어가지 않고 문간에 서서 오래 본다"가 연출로 실행된다.
- **금붕어 5마리**를 `koi_1~5` 마커에 붙였다(원시 캡슐+꼬리, 마커는 `visible=false`). 각자 다른 반경·속도로 수면 18cm 아래를 돈다.
- `data/spots.json` 은 `/static` 만 mount 된 탓에 아직 브라우저에서 못 읽는다 → 본문을 폴백 상수로 넣고, 서빙 경로가 생기면 그쪽이 이기도록 `loadSpotsJson()` 훅을 열어 뒀다(§8 요청 1).

### 2-7. 스캔 훅 (카트 도착)

## 3. 좌표계 (S2-B 요청) 와 SPOT_POS 제안

### 3-1. 이 화면의 좌표계
- Three.js 오른손 **Y-up**. 지형은 **X ∈ [−200, +200], Z ∈ [−125, +125]** (400×250m).
- **원점 (0, 0) = 몰 문턱(입구) 한가운데**, 지면 높이 0.
- **바깥으로 나가는 방향 = (+X, +Z) 대각선**, 단위벡터 (0.707, 0, 0.707). 화면에서는 **정확히 오른쪽**.
- **몰 안쪽 = (−X, −Z) 방향**(몰 로컬 x 0 ~ −58m, 로컬 |z| ≤ 23m).
- 화면 위쪽 = 월드 (+0.707, 0, −0.707).
- 강은 대략 x ≈ 112~160 구간(z에 따라 사인 곡선)에 흐른다.

## 4. 오디오 (S2-F 큐시트 대응)

**연결 완료.** `world3d.js` §10.5 `AUDIO` 모듈. 11개 파일 전부 디코드 확인(로그 `audio ready 11/11`).

- **버스 3개**: `amb`(0.70) / `sfx`(0.85) / `music`(0.90) GainNode → destination. `window.WORLD.audio.setBus('amb', 0.5)`.
- **시작**: 첫 사용자 입력(`pointerdown`/`keydown`, capture)에서 AudioContext 생성 + 전 파일 프리로드 + 현재 상황 앰비언트 페이드 인 0.8초.
- **상시 앰비언트**: 안=`amb_inside`(−12dB) / 밖 낮=`amb_outside_day`(−10dB) / 밖 밤=`amb_outside_night`(−13dB). **귀의 위치는 정찰병**으로 확정했다(안개를 걷는 사람 = 플레이어의 시점. 카메라는 자유롭게 떠다니므로 귀로 쓰면 앰비언트가 튄다).
- **크로스페이드**: 문턱 **1.5초**, 시간대 전환 **3.0초**.
- **덕킹**: 스팟 발견 시 amb −6dB(0.3초), `cue_spot_found` 를 music −6dB로 페이드 인, **`loopStart=0.8s`** 라 앞 0.8초 무음은 첫 회에만. 발견 오버레이를 닫으면 1.2초 페이드 아웃 + 덕킹 해제.
- **실패 시 무음**: 404·디코드 실패·자동재생 차단 모두 try/catch로 조용히 넘어간다. 콘솔 에러 0 유지 확인.

## 5. 스프린트 중 들어온 추가 요청 처리

### 5-1. 배경(S2-D)이 지적한 결함 4건 — **4건 전부 처리**
1. **파사드 자동 −90° 보정 제거 → 명시적 한 줄.** `const FACADE_YAW = Math.PI / 2;` 로 고정했다. 규약(§7-2: 정면 = GLB 로컬 +Z)에서 우리 몰의 바깥은 **몰 로컬 +X** 이고, rotY(+90°)가 로컬 +Z를 +X로 보낸다. (S2-D 가 걱정한 대로 −90°는 정면이 안쪽을 향해 틀렸다.) 자동 추정 코드는 지웠다.
   - 덧붙여 **입구 뒤판이 없는 문제**도 처리했다: 파사드 뒤 5.5m 에 어두운 판(46×7m, #0E0B08) + 문턱 랜턴 1개를 넣어 문턱 너머로 지형이 비치지 않는다.
2. **텍스처 4장 블렌딩.** `grass.png` 한 장 `map` → **정점 `splat` 어트리뷰트 + `onBeforeCompile` 4채널 블렌딩**으로 교체(§2-1). 타일 6m, sRGB 수동 변환, 타일별 밝기 보정. 이끼 가중치도 낮춰 초록 비율을 절반 이상으로 되돌렸다.
3. **스팟 물 z-파이팅.** 원판 `spotWater` 는 **hall.glb 대체물 전용**으로 남기고 씬 GLB가 붙는 순간 `visible=false`. 실제 수면은 GLB의 `keep_water_surface` 하나만 쓰고, 재질명 `Water` 를 찾아 우리 물 값으로 덮었다.
4. **`loadSpotGLB()` y 오프셋.** `-0.4` → **`WATER_Y - 0.14`** 로 재계산(= −0.74). 수면이 지형 수위와 정확히 맞는다.
   - 추가 요청도 처리: `marker_threshold` 에 정찰병 세우고 −Z 보기 ✔ / `koi_1~5` 에 금붕어 5마리 ✔ / 스팟 조명 2개 ×0.3 ✔.
   - **미처리**: `static/art/parallax/{skyline,dino_far,dino_near}.png` 는 이번 화면에 넣지 않았다. 직교 아이소 카메라라 패럴랙스 판을 제대로 쓰려면 하늘 레이어와 카메라 거리 규약을 따로 정해야 해서 스프린트3으로 미룬다(리스크 §9).

### 5-2. 캐릭터(S2-E) 각인 노드 — **필수 1건 처리**
- 로드 직후 `imp_` 로 시작하는 노드를 전부 `visible=false` 로 끈다. 로그로 확인: **주민 3인 모두 `imp 노드 40개 숨김`**. 안 껐으면 모두가 각인 8개를 달고 나왔을 것이다.
- `setImprints(root, ids)` 를 넣고 액터에도 `a.setImprints(ids)` 로 노출했다. `window.WORLD.setImprints` / `WORLD.IMPRINT_IDS`(8종) 도 공개. **주민 데이터 연결은 아직**이다 — 이 화면은 주민 3인을 하드코딩하고 있고, `/api/ark` 의 `residents_list[].imprints` 를 읽어 붙이는 것은 주민 목록을 서버에서 받아오는 스프린트3 작업이다(§8 요청 3).
- 재정규화 금지 규칙은 그대로 지켰다(스케일 미변경).
- 선택 에셋도 반영: **개 1마리**(§2-4), **트리케라톱스 2마리**(§2-4). 까마귀·고양이·육식 공룡은 트리거가 없어 넣지 않았다.

### 5-3. 시스템(S2-B) 연계
- **`/api/ark` 의 `voice`** 를 문턱 컷에서 띄운다. 로드 1.2초 뒤 리더 한 줄, 스캔 성공 1.8초 뒤 한 줄, `morning_lines` 가 있으면 이어서. → **첫 30분 대본 1비트(리더의 첫 말)가 채워졌다.**
- **`app.js` 의 `window.ARK.voiceToast` 는 재사용하지 않았다.** world.html 은 `app.js` 를 로드하지 않는다(index.html DOM·상태에 묶여 있어 그대로 끌어오면 두 화면이 서로의 DOM을 건드린다). 대신 **스타일만 같은 톤**(좌측 랜턴색 바 + 세리프 본문)으로 맞추고 `window.WORLD.voiceToast(voice)` 로 같은 시그니처를 노출했다.
- `/api/rumors` 의 소문 표식은 이번에 지도에 찍지 않았다(좌표 규약 미확정, §3). 스프린트3.

## 8. 02_DEV §5 자가 검수

1. **새 숫자가 화면의 무엇으로 보이는가?** 자원 4개 = 카트로 들어와 진열대에 쌓이는 궤짝, 하루 = 하늘색·그림자 길이·랜턴 세기·막대, 탐험도 = 걷힌 종이 면적과 그 안에 드러나는 나무, 신뢰 = 개가 사람 곁에 붙는 거리. 각인은 아직 노드만 있고 숫자 연결 전(§5-2).
2. **첫 3분 루프의 탭 수가 늘었나?** 늘지 않았다. 스캔은 버튼 1회이고 결과가 카드 시트 대신 화면 안 카트로 보인다. 오히려 "시트 닫기" 탭이 사라진다.
3. **같은 입력이면 같은 결과인가?** 지형·소품 배치·안개 종이·스팟 위치 전부 `SEED=20260920` 결정적. 남은 비결정 요소는 랜턴 깜빡임 위상뿐(장식, 상태에 영향 없음).
4. **폰 가로 720px에서 손가락으로 조작 가능한가?** 844×390에서 확인: 핀치 줌·드래그 팬·지면 탭 이동 동작, HUD 겹침 없음, 주민 선택/스캔 44px.
5. **회귀 7항목 로그가 있는가?** 이 태스크는 신규 파일만 추가했고 서버·기존 클라이언트를 수정하지 않았다. 7항목 회귀 책임은 S2-B에 있고, 이쪽은 공용 접점(`/api/scan`, `/api/ark`)이 규약대로 동작함을 로그로 확인했다(§6).

## 9. 남에게 요청할 것

**시스템(S2-B) / 시나리오**
1. **`data/spots.json` 을 브라우저가 읽을 길이 없다**(`server.py`는 `/static`만 mount). `/api/rumors` 에는 `discovery_text`가 없다. ① `/api/rumors` 응답에 `discovery_text` 추가 또는 ② `/api/spots` 신설 중 하나를 부탁한다. 그때까지 본문은 world3d.js 안 폴백 상수라 **시나리오가 글을 고쳐도 이 화면에 반영되지 않는다**(D7 위반 상태, 임시).
2. **`pos` 좌표를 §3-3 제안값으로** 바꿔 주면 이 화면에 소문 표식을 바로 찍을 수 있다.
3. **주민 목록 API**: `/api/ark` 에 `residents_list`(id·role·imprints)가 클라이언트로 내려오면 `setImprints()` 를 붙여 각인이 몸에 보인다(GROWTH_AND_MYTH "각인은 몸에 남는다"). 지금은 주민 3인이 하드코딩이다.
4. 저장 스키마: `fog`(캔버스 요약), `discovered_spots`, `residents_pos` 가 있으면 새로고침해도 세계가 유지된다.

**배경(S2-D)**
5. 파사드·스팟·텍스처 규약은 전부 맞았고 §5-1대로 반영했다. 다음은 **부족 방향 랜드마크 6개**와 **패럴랙스/스카이라인의 카메라 거리 규약**(직교 아이소에서 하늘 판을 어느 거리·크기로 둘지)을 정해 주면 스프린트3에서 붙인다.
6. 스팟 씬 GLB가 전체적으로 무채에 가깝다. 청록 물과 분홍 꽃이 더 살면 "발견"의 색 대비가 세진다(ART_REFERENCES 초록·청록).

**캐릭터(S2-E)**
7. `imp_<id>` 노드 규약 그대로 동작한다(40노드 확인). **각인 파츠의 기본 가시성을 GLB 익스포트 단계에서 끌 수 있으면** 클라이언트 보정이 필요 없다(glTF `KHR_node_visibility` 또는 별도 이름 규약).
8. 짐승은 `dog.glb`(idle/walk)만 썼다. **고양이·까마귀의 "소문을 물어 오는" 동선 규약**(어디서 나타나 어디로 가는가)을 정해 주면 스프린트3 소문 표식과 함께 붙인다.
9. 공룡은 트리케라톱스만 배치했다. **육식 공룡의 밤 등장 규칙**(거리·속도·경고 타이밍)은 시나리오/PM 결정이 필요하다.

## 10. 미완 · 리스크

- **안개와 높은 구조물**: 종이는 지면에 붙는 레이어라 키 큰 것은 원리상 뚫고 나온다. 인스턴스 소품은 "안개 밑에서는 숨긴다"로, 스팟은 거리 기준(30m) 통째 토글로 우회했지만 경계에서 툭 나타난다. 알파 페이드로 다듬는 것이 스프린트3.
