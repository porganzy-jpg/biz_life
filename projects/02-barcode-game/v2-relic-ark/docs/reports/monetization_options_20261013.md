# 수익 모델 비교 — 기존안(기획서 수익화 절) vs 대안(무료 14일 + 한 번 구매 + 이야기 책) (2026-10-13)

> 요청: DECISIONS 2026-10-13 ④ — 비교 문서를 받고 사용자가 결정한다.
> 근거: 재검토 `design_next_level_20261013.md` §4, 기존안(상위 기획서 수익화 절 — 재검토가 "§10.1"로 인용한 표, `../docs/PROJECT_PLAN.md` §7과 같은 계열), 공통 교본 P5(수익은 존중에서), M10(정서 보호).
> **표기**: [기억] 출처 URL 없이 기억에 기댄 사실 · [조사] 재검토 문서가 조사로 표시한 것 · [추정] 이 문서의 계산(가정이 바뀌면 숫자가 바뀐다). 매출 숫자는 **전부 추정**이고, 결정에 쓰는 것은 숫자의 크기보다 **방향과 위험**이다.

## 0. 결론 먼저

**대안(무료 14일 + 「방주 열쇠」 한 번 구매 + 「이야기 책」 확장)을 권한다.**

| 기준 | 기존안 | 대안 |
|---|---|---|
| 1인당 매출(90일) | 조금 많다(약 750원) | 비슷하다(약 580원) |
| 핵심 동사(찍기)·희귀도·가보의 무게 | 팔아서 깎는다 | 지킨다 |
| 서비스 종료·평판·규제 위험 | 크다 | 작다 |
| 만드는 비용 | 시즌·광고 연동 운영이 계속 든다 | 6주 한 장의 이야기 책 |

1인 개발 웹 게임에서는 차이 나는 매출보다 **줄어드는 위험**이 더 크다.

## 1. 두 모델

### 기존안 (2026-09 계열 기획서)

| 항목 | 내용 |
|---|---|
| 시즌 패스 | 월 보상 트랙 + **스캔 상한 +10** |
| 프리미엄 팩 | 돈으로 여는 카드 팩, **희귀도 확률 상향** |
| 보상형 광고 | 보면 추가 스캔 5회 |
| 꾸밈 | 카드백·방주 스킨(시즌 한정 포함) |

### 대안 (재검토 §4-3)

| 층 | 내용 | 가격(안) |
|---|---|---|
| 무료 | 1막 앞 14일(벽 4, 첫 사슬 셋, 물때 2주). 스캔은 늘 무료, 상한 20 그대로 | 0 |
| 본편 | 「방주 열쇠」 한 번 구매: 1막 전체·30일 등뼈·첫 결말 | 9,900~12,900원 |
| 확장 | 「이야기 책」: 새 주민 2와 사슬, 벽 3, 손님 4, 물때 규칙 6. 영구, 기한 없음 | 3,900~5,900원 |
| 표현 | 카드 틀·등불 색·엽서 틀. 시즌 한정 없음 | 1,900원 안팎 |
| 응원 | 「등불 하나 더」 후원 | 자유 |

**팔지 않는 것**: 스캔, 확률, 시간 단축, 기억 속 물건 추가분, 표류병 추가분, 수첩 정답.

## 2. 게임 설계와 부딪치는 곳

| 기존안 항목 | 부딪치는 결정 | 결과 |
|---|---|---|
| 스캔 상한 +10 패스 | 핵심 루프 A(스캔 = 선물), 띄엄띄엄 플레이어는 하루 3회 | 하루 20이 모자란 사람은 거의 없다(sim: 보통 6~8). 그런데 팔리는 순간 "찍기 = 돈의 영역"이 된다. **팔리지 않거나, 팔리면 정서가 깨진다** |
| 확률 상향 팩 | 가보 칸(2026-10-13 ②), 같은 바코드 = 같은 유물 | 전설 1.5%의 무게가 "누구에게?"의 무게다(sim_heirloom: 귀함 이상의 80~88%가 진짜 결정). 돈 팩이 전설을 내면 **집 물건의 가치와 가보의 무게가 함께 무너진다** |
| 광고로 추가 스캔 | 아늑함(M10), 재스캔 감쇠 바닥 | 스캔을 다시 희소 자원으로 만든다. 광고 흐름이 "기다림" UX를 끊는다 |
| 시즌 한정 스킨 | FOMO 없음(라이브옵스 원칙) | 한정이면 Pocket Camp의 길이다. 상시 판매면 괜찮다(두 모델 공통) |

대안은 이 넷과 부딪치지 않는다. 대안의 약점은 따로 있다: **14일째 벽에서의 이탈**과 **웹 결제·등급 분류 같은 출시 절차**(§5).

## 4. 매출 추정 [추정] — 설치 1만 명, 90일

### 공통 가정
- **잔존**: D1 35% · D7 15% · D14 10% · D30 6%(교본 P4의 아늑·수집 장르 구간).
- **90일 동안 한 사람이 켠 날 수**: 약 7일(잔존 곡선 넓이).
- **수수료**: 웹 PWA 결제대행 약 3.5%. 앱 마켓이면 15~30%(국내 중소 개발사 감면 15% 가정 가능).
- 아래는 **결제대행 기준 순매출**이다.

### 기존안
| 수입원 | 가정 | 1인당 |
|---|---|---|
| 보상형 광고 | 켠 날마다 1.5회 시청, eCPM 약 20,000원(국내 보상형, 넓은 범위 10,000~30,000) | 7 × 1.5 × 20원 ≈ **210원** |
| 패스·팩 | 결제자 3%(아늑 무료 게임 2~5%), 결제자당 월 12,000원 × 평균 1.5개월 | 0.03 × 18,000 ≈ **540원** |
| 합 | | **≈ 750원 → 1만 설치 ≈ 750만 원** |

- **하방**: 결제자 1.5%, eCPM 10,000원 → 약 340원.
- **상방**: 4%, 30,000원 → 약 1,040원.

### 대안
| 수입원 | 가정 | 1인당 |
|---|---|---|
| 방주 열쇠 | 설치 대비 구매 4.5%(14일 도달 약 10~12% 중 40% 안팎이 산다), 11,000원 | 0.045 × 11,000 ≈ **495원** |
| 이야기 책 | 구매자의 40%가 90일 안에 한 권, 4,900원 | 0.045 × 0.4 × 4,900 ≈ **88원** |
| 표현·응원 | 구매자 10%, 1,900원 | ≈ **9원** |
| 합 | | **≈ 590원 → 1만 설치 ≈ 590만 원** |

- **하방**: 구매 2.5% → 약 330원.
- **상방**: 7%(사슬·가보가 잘 먹힐 때), 확장 50% → 약 950원.

### 읽는 법
- 90일 매출은 **기존안이 조금 많다**(중앙 750 대 590). 범위는 거의 겹친다.
- **90일 뒤는 갈린다.**
  - 대안: 6주마다 이야기 책이 나오고, 늦게 온 사람도 1장부터 산다(이야기 책은 사라지지 않는다).
  - 기존안: 패스가 매달 같은 사이클을 돌아 닳는다(TCG Pocket −41%).
- **대안의 매출은 리텐션에 크게 기대지 않는다.** 14일 체험이 좋으면 한 번에 들어온다. 기존안은 오래 머문 사람에게서 조금씩 나온다. 1인 개발에 **광고 SDK·운영 이벤트를 붙이지 않아도 된다**는 것도 대안의 몫이다.
- 리텐션 영향 [추정]: 기존안의 스캔 상한 판매와 확률 팩은 "찍기 = 선물" 정서를 깎아 D30을 0.5~1%p 낮출 수 있다. 대안의 14일 벽은 D14 직후 이탈을 만든다. 다만 산 사람은 남는다(매몰 비용보다 "결말까지"의 약속).

## 5. 대안의 위험과 대책

| 위험 | 대책 |
|---|---|
| 14일째 벽에서 이탈 | 이야기를 끊는 자리를 **2주째 끝 첫 큰 장면(두 번째 일지·벽 셋째 완성) 뒤**에 둔다. 장면 한가운데서 자르지 않는다. 무료 14일 안에도 첫 사슬 셋은 끝까지 간다 |
| 웹 PWA 결제 | 결제대행 연동, **디지털 콘텐츠 청약 철회 7일**(전자상거래법) 고지, 영수증 |
| 게임물 등급 분류 | 유료 판매 전 게임물관리위원회 등급 분류(웹도 대상). 자체 등급 분류 사업자 경유나 앱 마켓 출시를 함께 검토 |
| 서버 종료 시 | 저장 내보내기(복구 코드 + 파일), 집계 기능 없이도 본편이 돈다(Pocket Camp 교훈) |
| 바코드 = 구매 이력 | 수익 모델과 별개로 개인정보 처리 방침 필수(재검토 §5-4). 광고 SDK를 안 붙이면 이 위험이 줄어든다 |

## 6. 결정 항목 (사용자)

1. **대안 채택 여부**(권고: 채택). 채택하면 DECISIONS에 "기획서 수익화 절을 대체한다"를 적고, OPEN_GAPS의 「수익화 Phase 2까지 미정」을 닫는다.
2. **가격대**: 방주 열쇠 9,900원 / 12,900원 중. 첫 결말까지 30~45일 분량이면 9,900원을 권한다(지인 테스트 뒤 다시).
3. **무료 공개 순서**: 지인 테스트(무료) → 공개 무료 체험 + 위시리스트 → 유료 출시. 결제·등급 분류는 유료 출시 직전 과제다.
4. 공통으로 지킬 것(어느 모델이든): **스캔·확률·시간·정답을 팔지 않는다.**

## 7. 이 숫자를 확정하는 법 (B7)

- 실제 사람 7일·14일 테스트의 D7·D14.
- 설문 "이 게임에 돈을 낸다면 얼마?"(가격 민감도, Van Westendorp 네 문항).
- 공개 체험 뒤 14일 도달 대비 구매 전환. 4.5% 가정이 2%를 밑돌면 체험 길이(14일)와 끊는 자리를 다시 본다.
