# 실내복 시제품 — 요리사 · 체형 A (2026-10-17)

> 사용자: "밖에서 잠수복을 입는다는 건 알지만, 들어오면 옷이 바뀌어야 하지 않나?"
> 지금 P2 주민은 집 안에서도 투구 테와 두건을 쓰고 공기통을 메고 있어 잠수부처럼 보인다(DECISIONS 2026-10-01 「머리 갈래는 투구 테 아래, 투구 위는 역할 자리」).
> **한 역할만 먼저** 만들었다. 기존 시트는 건드리지 않았다. 생성 AI는 쓰지 않았다(손으로 찍은 도트). 커밋하지 않았다.

**비교 그림**: `docs/reports/char_indoor_proto.png`
- 위: idle · walk_side · work 세 행을 **지금 / 시제품 실내복 / 원정(잠수복 겹)** 순서로 나란히 놓았다.
- 아래: 방 ×3 합성(정찰병 · 실내복 요리사 · 농부 · 지금 요리사)과 70px 색·실루엣.

## 1. 무엇을 바꿨나

| | 지금 | 실내복 시제품 |
|---|---|---|
| 머리 | 놋쇠 투구 + 얼굴 창, 머리카락은 창 안 앞머리만 | **맨머리** — 머리카락 전체(뒷머리·귀·앞머리 술)와 얼굴이 다 보인다 |
| 머리 위(역할) | 번트오렌지 천 모자 | **흰 요리 모자(토크)** + 번트오렌지 머리띠 — 같은 「키 큰 천 모자」 실루엣, 역할 색이 이어진다 |
| 몸 | 잠수복 + 앞치마 색 겉옷 + 공기통 + 허리 랜턴 | **크림 셔츠(소매 걷음, 맨팔뚝)** + 번트오렌지 앞치마(가슴받이·주머니·뒤로 맨 끈) — 공기통·랜턴 없음 |
| 발 | 무게추 장화 | 갈색 바지 + 실내화 |
| 손 | 국자 | 국자(그대로) |
| 얼굴 | 얼굴 ① | 얼굴 ①과 **같은 자리·같은 모양**(눈 3×3 · 곧은 눈썹 · 넓은 미소 · 홍조) |

- 규약은 그대로다: 셀 64, 발 기준선 60, 맨머리 44px(머리카락 꼭대기 = 원화 y 16, 측정 확인), 어깨 폭 8.6(지금 몸과 같다 — 옷을 벗어도 사람 크기는 같다), 정수 배율.
- 행: `idle` 2 · `walk_side` 3(오른쪽 원본, 왼쪽은 반전, 앞치마 끈이 등 뒤로 보인다) · `work` 3(국자를 들고 f1에 김 한 줄).
- 파일: `static/art/chars/indoor_proto/cook_a.png`(x1, 3열 × 3행) · `cook_a_x4.png` · `meta.json`. 생성기는 `tools/gen_chars_indoor_proto.py`.

**본 것**
- 방 안에서 따뜻한 크림·주황이 등불 방과 어울리고, 투구 쓴 셋 사이에서 「집에 있는 사람」으로 바로 읽힌다.
- 70px 검은 실루엣: 키 큰 모자가 그대로라 요리사로 읽힌다. 다만 공기통이 빠져 실루엣이 지금보다 가늘다. 「잠수복을 벗었다」가 실루엣으로도 보이는 셈이지만, 역할 판독은 모자 하나에 더 기댄다.
- 1차 확인에서 고친 것:
  - 몸이 좁아(8.0) 아이처럼 보여 어깨를 지금과 같게(8.6) 했다.
  - 흰 모자만으로는 지금 주황 모자와 이어지지 않아, 머리띠를 역할 색으로 칠했다.
  - 머리 높이가 1px 모자라 머리카락을 1px 늘렸다.

## 2. 모든 역할에 넓힌다면 — 비용

생성기(`gen_chars_p2.py`)에 **옷차림 축 하나(`outfit = suit | indoor`)** 를 더하는 일이다. 몸 동작(팔·다리·설비·든 물건)은 그대로 쓰고, 머리와 겉옷만 갈아입힌다.

| 단계 | 할 일 | 크기 |
|---|---|---|
| ① 머리 | 투구·얼굴 창 대신 맨머리를 그린다 — 정면·옆모습·3/4·뒷모습·옆모습 작업(뒤집기) 다섯 시점 | 함수 1벌(이번 시제품이 정면·옆 두 시점의 견본) |
| ② 머리 위 역할 표식 8종 | 투구 없이 쓰는 판: 요리사 토크, 정찰병 천 후드(꼭지·꼬리 유지), 의무병 머릿수건(+이마 십자), 기술자 머리 위로 올린 고글(끈이 머리카락 위), 농부 밀짚 챙, 학자 납작 모자 + 깨진 안경, 교섭가 접은 챙 모자 + 목도리, 아이 우비 후드 → 노란 털모자 | 8 × 다섯 시점 |
| ③ 겉옷 8종 | 역할 색은 그대로, 잠수복 대신 일옷: 앞치마 · 조끼 · 가운+완장 · 작업복 멜빵 · 황토 작업복 · 긴 외투 · 코트 · 노란 우비. 공기통·허리 랜턴·무게추 장화·목 실링을 뺀다 | 8 |
| ④ 머리 6종 패치 | 지금은 얼굴 창 안 앞머리 띠 + 투구 테 아래 갈래뿐이다. 맨머리에서는 **머리통 전체**가 보이므로 여섯 종을 다시 그려야 한다(짧은·묶은·긴·땋은·곱슬·두건) × 다섯 시점. **가장 큰 일이다** | 6 × 5 시점 |
| ⑤ 얼굴 3종 | 눈·눈썹·입 자리가 지금과 같아(시제품에서 확인) 그대로 쓴다. 패치는 생성기가 다시 뽑는다(자동) | 0(자동) |
| ⑥ 각인 12종 | 목 실링·옷깃이 없어지므로 목덜미·옷깃·가슴·허리 앵커를 새 옷에 맞춰 옮긴다. 4체형 × 12종을 다시 뽑고, 역할 가림판 16장을 새로 낸다 | 앵커 표 1벌 + 자동 |
| ⑦ 검사 | 패치 복원 · 18조합 · 각인 겹침 · 몸 밖 · 가림판을 실내복에도 그대로 돌린다 | 자동(실행 시간 약 2배, 20~25분) |

## 3. 머리·얼굴 패치, 각인과의 관계
- **겹치는 순서는 같다**: 본체(실내복) → 머리 → 얼굴(조합 규칙) → 각인 → 가림판. 실내복에는 잠수복 겹이 없다. 잠수복은 원정 판의 일이다.
- 패치는 옷차림마다 **따로 한 벌**이다. 지금 패치는 투구 창 안 픽셀 기준의 차이라, 맨머리 위에 얹으면 맞지 않는다. 각인도 앵커가 바뀌어 옷차림마다 한 벌이다.
- 사람마다 고른 머리·얼굴 id(`pick_look`)는 그대로 쓴다. 같은 사람은 실내에서도 같은 머리·같은 얼굴이고, 투구를 쓰면 앞머리만 보인다. 그래서 옷을 갈아입어도 같은 사람으로 읽힌다.

## 4. 「투구 위는 역할 자리」 규칙은 어떻게 하나
제안: **「머리 위는 역할 자리」로 말을 바꾸고 원칙은 지킨다.**
- 실내에서도 역할 표식은 머리 꼭대기에 있다(토크·후드·머릿수건·고글·밀짚 챙·납작 모자·챙모자·털모자). 70px 판독은 지금처럼 머리 위 하나로 한다.
- 머리카락은 **모자 테 아래**에서만 갈래를 낸다. 이번 시제품도 머리카락이 토크 띠 아래에서 시작한다. 그래서 머리 변형이 머리 위 실루엣을 흐리지 않는다(2026-10-01의 뜻 그대로).
- 보조 판독축은 겉옷의 역할 색이다(앞치마 주황·조끼 올리브…). 공기통이 빠지는 만큼 옷 색 면적을 넓혔다(시제품 앞치마는 가슴받이 + 허리 아래 전체).
- DECISIONS 한 줄 제안: 「2026-10-xx 집 안에서는 투구를 벗는다. 역할은 여전히 머리 위(모자)와 겉옷 색으로 읽는다. 머리 갈래는 모자 테 아래에서만」.

## 5. 옷 바꾸는 규칙 — 제안

| 자리·상황 | 옷차림 | 시트 |
|---|---|---|
| 거점 방 안 · 홀 · 엘리베이터 · 일하는 동작 | **실내복** | `indoor/` |
| 인물 카드 · 주민 카드 · 초상 | 실내복(얼굴이 다 보인다) | `indoor/` idle |
| 에어락 방 · 해치 앞(나갈 준비) | 잠수복 + 투구(지금 몸) | `p2/` |
| 원정(바깥) · 해치 내려가기 · 해저 걸음 · 상자 나르기 | 잠수복 + 투구 + **잠수복 겹** | `p2/` + `suit/` |
| 돌아옴(`return_tired`) | 잠수복으로 에어락에서 「후」 → 다음 칸부터 실내복 | `p2/` → `indoor/` |
| 습격 중(경보) | **투구만 쓴다** = 지금 P2 몸 그대로(잠수복 겹 없이). 집 안에 물이 들 수 있으니 투구를 챙겨 쓰는 모습. 새 그림이 필요 없다 | `p2/` |
| 물 찬 칸 되찾기 · 금 간 방 수리 | 투구(습격과 같다) | `p2/` |

- 바꾸는 순간은 **에어락을 지날 때 한 번**뿐이다. 문간이 두 세계의 전환점이라는 결정(2026-09-23, EXPEDITION §3-6)과 맞는다.
- 갈아입는 1~2프레임 동작(투구를 벗어 팔에 끼는 칸)은 다음 단계 선택지다. 없어도 문 열림에 가려 어색하지 않다.
- 이렇게 하면 **지금 P2 시트는 버리지 않고 「경보·바깥 준비」 옷으로 남는다.** 새로 그리는 것은 실내복 한 벌뿐이다.

## 6. 결정할 것(PM → 사용자)
1. 이 방향(맨머리 + 머리 위 역할 모자 + 일옷)으로 갈지. 같은 방법으로 다른 역할 하나를 더 보고 싶으면 반나절 안이다. 예를 들어 투구와 가장 붙어 있던 기술자(고글)가 좋은 시험이다.
2. 습격 때 「투구만」 규칙을 쓸지(지금 시트 재사용).
3. 아이의 실내 머리 위 표식(우비 후드 → 노란 털모자 제안).
