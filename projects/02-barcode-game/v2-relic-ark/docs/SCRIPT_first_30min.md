# 대본 — 첫 30분 (WORLD_PRESENTATION §2 확장, 2026-09-20 / 시나리오)

> 이 문서는 `docs/WORLD_PRESENTATION.md` §2의 여덟 단계를 **개발·사운드가 그대로 구현할 수 있는 화면 지시**로 푼 것이다. 데모(Steam Next Fest 상당)와 쇼츠 소재가 이 시퀀스에서 나온다(교본 07 §5).
> 원칙: **설명 금지**(S1). 아래 표의 '대사·텍스트' 칸에 없는 문장은 화면에 띄우지 않는다. 튜토리얼 말풍선·화살표·가이드 텍스트를 쓰지 않는다. 배워야 할 것은 카메라와 소리가 가르친다.
> 대비(S2)는 단계마다 **하나씩만**. 아래 각 절의 제목 옆에 적어 두었다.

## 0. 전역 규칙
| 항목 | 규칙 |
|---|---|
| 화면 | 가로 고정(`docs/SCREEN_VISION.md`). 기준 해상도 1280×720, 폰 844×390에서 같은 프레이밍이 나와야 한다 |
| 카메라 | 아이소 45°/45°. **안**에서는 화각을 좁게(답답), **밖**에서는 넓게(열림). 전환은 1.5초 이즈아웃 |
| 색 | 안 = 어둡고 따뜻(랜턴 1 = 주색 1). 밖 = 밝고 차갑게 아름답다. 한 화면에 둘이 같이 보이는 구도를 기본값으로 |
| 소리 | 문턱 통과 시 안/밖 앰비언트 1.5초 크로스페이드. **발견 직전 0.8초 완전 무음**(`docs/AUDIO_CUES.md`) |
| 자막 | 두 AI만 자막을 쓴다. 리더 = 각진 흰 글자, 정원사 = 물 위에 비친 일렁이는 글자 |
| 말 | 주민 대사는 1~2문장(S9). 쪽지는 3~4문장. 그 이상은 서고의 낭독 같은 '의식'에만 |
| 스킵 | 어느 단계든 탭으로 넘길 수 있다. 단 5번(첫 발견)과 8번(첫 질문)은 **스킵 불가 8초** |
