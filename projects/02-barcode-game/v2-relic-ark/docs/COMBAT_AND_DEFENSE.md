# 방어 전투 설계 — 바깥에서 오는 것을 사람으로 막는다 (2026-10-01)

> 사용자 지시로 확정된 1막의 전투 구조. `DEVELOPMENT_GUIDE.md`·`PLAYER_JOURNEY.md`의 짝 문서.

## 1. 한 문장
**돔 바깥에서 크고 작은 물고기들이 무작위로 들이친다. 플레이어는 안의 사람들을 적절히 옮기고 배치해서 막는다.** 막기 위해 기지와 사람을 강화하고, 강화의 재료는 멸망한 현대 문명의 쓰레기 — 게임 안에서는 **유물**이라 부른다.

## 2. 이 구조가 해결하는 것
`PLAYER_JOURNEY.md` §1에서 진단한 구멍 중 둘이 여기서 닫힌다.
- **G1 분 단위 할 일이 없다** → 위협이 오면 즉시 사람을 옮긴다. 이것이 이 게임의 손가락 할 일이다.
- **거점 화면이 관찰용일 뿐이다** → 단면 화면이 **실제 플레이 판**이 된다. 개미집을 보는 쾌감과 조작이 같은 화면에서 일어난다.

## 3. 전투 흐름 (한 번의 습격)

```
  소리  →  실루엣  →  접촉  →  대응  →  결과  →  흔적
  (예고)   (어디로)   (어느 방)  (배치)   (막음/뚫림) (남는다)
```

1. **예고 — 소리가 먼저.** 물이 조용해지거나, 먼 울음이 가까워지거나, 유리를 두드리는 소리. `AUDIO_CUES.md`에 이미 있는 큐를 쓴다. **악의가 아니라 호기심이라 더 오래 머문다**는 성경 원칙 유지.
2. **실루엣 — 어디로 오는지 보인다.** 바깥 물에 그림자가 지나가고 **특정 방의 창 쪽으로 다가온다.** 플레이어는 어느 방이 위험한지 안다.
3. **대응 시간.** 압박을 주지 않는다. 느리게 다가오고, 그동안 사람을 옮긴다. 아늑함 보호(M10).
4. **배치.** 방에 있는 사람의 **역할·장비·각인**이 그 방의 방어력을 만든다. 빈 방은 못 막는다.
5. **결과.** 막으면 자원과 각인 기회. 뚫리면 유리 균열 → 침수 → **그 방을 잃는다**(이 게임의 죽음). 중간 결과로 부상·자원 손실.
6. **흔적.** 막아도 긁힌 자국이 남고, 뚫리면 물 찬 방이 영구히 보인다.

## 4. 바깥에서 오는 것들
성경(`WORLD_BIBLE_DEEP.md` §3)의 생물을 그대로 쓴다. **종마다 막는 방법이 다르다.** 같은 방식의 반복이 이 장르를 지루하게 만드는 주범이므로 여기서 갈라 놓는다.

| 생물 | 성격 | 막는 법 |
|---|---|---|
| **작은 떼** | 수가 많고 약하다. 이음매를 파고든다 | 사람 수로 막는다. 누구든 여럿 |
| **긴목** | 불빛에 끌려 창에 얼굴을 붙인다. 무게로 유리가 휜다 | **불을 끈다.** 조명 담당이 그 방에 있어야 한다. 끄면 우리도 못 본다 |
| **문지기** | 소리에 온다. 물이 조용해지면 온 것이다 | 소리를 죽인다. 전원을 내리고 모두 한 방에 모은다 |
| **손톱 무리** | 느리고 작고 수백. 잠수복 이음매를 정확히 찾는다 | 밖에 나간 사람을 즉시 들인다. 에어락 담당 |
| **동거 문어** | **위협이 아니라 식구.** 공격하지 않는다 | 해당 없음. 오히려 위협을 미리 알린다 |

> **설계 원칙**: 바다 생물은 악당이 아니다. 배고프거나 궁금할 뿐이다. 신뢰 역전(짐승 쪽이 사람보다 믿을 만하다)을 해치지 않기 위해, **죽이는 것이 주된 동사가 되지 않게 한다.** 쫓고, 숨고, 막고, 달랜다.

## 5. 강화 — 무엇을 왜 올리나

### 5-1. 방의 기능 (기지 강화)
| 방 | 생산 | 전투에서의 역할 |
|---|---|---|
| 발전실 | 전력 | 조명·음향 차단·격벽 작동의 전제 |
| 의무실 | 치료 | 부상자 복귀 속도 |
| 공방 | **대응 도구** | 방어 장비 제작 |
| 창고 | 보관 | 유물 적재량(E1의 선반) |
| 온실·양식 | 식량·산소 | 사기와 체력 |
| 정수 | 물 | 생존 기반 |

### 5-2. 사람 강화
- **역할** 8종이 각자 잘 막는 위협이 다르다(조명=긴목, 경비=작은 떼, 의무=부상).
- **각인**이 능력을 바꾼다. 「두드림을 들은 자」(긴목 조우 생환)는 긴목 대응에 강해진다. **계단식 성장이 전투와 직접 연결된다.**
- **장비**가 공방에서 나온다.

### 5-3. 강화의 재료 = 유물
**전부 멸망한 현대 문명의 쓰레기다.** 게임 안에서는 유물이라 부른다. 이것은 세계관과 이미 완전히 맞는다(`LORE_v3_바다가_보관한_것.md`: 바다가 200년간 보관했다).

재료가 들어오는 길은 셋이다.
1. **바코드 스캔** — 현실의 물건을 찍는다. 이 게임만의 훅.
2. **원정** — 동료를 바깥으로 정찰 보낸다. 공기 게이지가 시계.
3. **문어** — 매일 한 번 무언가를 물고 온다(E3).

## 6. 아늑함을 지키는 안전장치
이 구조는 압박 쪽으로 기운다. 다음을 규칙으로 못 박는다.
1. **습격은 드물다.** 하루 1회 이하. 조용한 날이 더 많아야 한다.
2. **예고가 길다.** 소리 → 실루엣 → 접촉까지 충분히 느리게. 놀래키지 않는다.
3. **실패가 즉사가 아니다.** 방 하나를 잃는 것이 최악이고, 그조차 되돌릴 수 없는 대신 **화면에 남아 이야기가 된다.**
4. **죽이는 것이 주된 동사가 아니다.** 쫓고 숨고 막고 달랜다.
5. **대응 도구의 이름을 무기로 부르지 않는다**(2026-10-01 사용자 승인으로 확정). 등불, 그물, 봉합 패치, 소리 가리개. 세계관과 정서를 함께 지킨다.

## 6.5 대응 도구 일곱 (공방 생산물) — 확정
무기가 아니다. **막고 가리고 꿰매고 부르는** 물건이다. 재료는 전부 유물(현대 문명의 쓰레기).

| 도구 | 하는 일 | 주로 막는 것 | 재료(유물 카테고리) | 종류 |
|---|---|---|---|---|
| **봉합 패치** | 유리 균열과 잠수복 이음매를 막는다 | 작은 떼, 유리 균열 | 의류·직물 + 의약 | 소모 |
| **차광 덧문** | 방을 즉시 어둡게 한다 | **긴목**(불빛에 끌린다) | 의류 + 부품 | 설치 |
| **유인 등불** | 돔에서 떨어진 곳에 불을 켜 둔다 | **긴목**(다른 데로 간다) | 전자 + 전력 | 설치 |
| **소리 가리개** | 방의 소리를 먹는다 | **문지기**(소리에 온다) | 의류·직물 + 부품 | 설치 |
| **귀환 신호기** | 밖에 있는 사람을 즉시 부른다 | **손톱 무리** | 전자 + 문구 | 소모 |
| **긴 장대 그물** | 밀어내고 떼어 낸다. 다치게 하지 않는다 | 전반 | 의류·직물 + 부품 | 내구 |
| **이음매 보강대** | 그 방의 기본 방어를 올린다 | 전반(상시) | 부품 + 청사진 | 영구 |

**설계 의도 둘**
- 도구 셋(차광 덧문·유인 등불·소리 가리개)이 **빛과 소리를 다룬다.** 이 게임의 위협은 빛과 소리에 반응하므로, 대응도 빛과 소리로 한다. 칼이 아니다.
- 재료 카테고리가 **여덟 스캔 카테고리에 흩어져 있다.** 스팟 해금과 같은 원리로, 한 종류만 찍어서는 도구를 다 못 만든다(지표 H2).

|---|---|
| 사건 카드 60장 | 그대로 쓴다. 바깥 생물 카드가 **배치 전투를 띄우는 방아쇠**가 된다 |
| 대항 카드(TCG) | 즉시 효과 아이템으로. `D3`의 "덱 구성까지만"과 `D11` 손패 상한이 그대로 유효 |

| 공기 게이지 | 원정의 시계 |
| 스팟 | 전투가 아니라 발견. **여기엔 싸움이 없다** |
