# 제목과 로고 (2026-10-01)

> 현재 제목 「잔해 방주 / RELIC ARK」는 **육상 쇼핑몰 폐허** 시절에 지은 것이다. 1막이 심해 유리돔으로 바뀌었으니 제목도 다시 본다.

## 1. 제목이 담아야 할 것
우선순위 순.
1. **따뜻한 빛 + 차가운 깊이.** 이 게임의 한 장면은 검은 물속에 불 켜진 집이다.
2. **아래로 자란다.** 위로 올라가는 게임이 아니다. 내려갈수록 좋아지고 위험해진다. 이만큼 독특한 구조가 없다.
3. **바다가 보관한 것 = 유물 = 현실의 바코드.** 이 게임만의 훅.
4. 짧을 것. 로고가 되어야 한다.
5. 검색해서 겹치지 않을 것.

## 2. 제목 후보 다섯

## 3. 로고 컨셉 넷
전부 **평면 민속화풍 + 도트**의 결을 따른다. 손으로 그은 선, 흙 팔레트, 2단 음영.

### L1. 성문이 수심선이 된다 ★
**바코드의 세로 막대가 아래로 내려갈수록 길어지고 흐려져 수심의 지층이 된다.** 맨 아래 막대들 사이에 아주 작은 등불 하나.
→ 이 게임의 두 축(현실의 바코드 / 깊은 바다)을 **한 그림**으로 묶는다. 설명이 필요 없다. **가장 강하다.**

### L2. 등불이 곧 돔
둥근 등불의 유리가 그대로 유리돔이고, 그 안에 아주 작은 방 두세 칸과 사람 점. 바깥은 검정.
→ 따뜻함과 거점을 직접 보여 준다. 아이콘으로 줄여도 읽힌다.

### L3. 아래로 뻗는 척추
위에 돔, 아래로 가늘어지는 기둥, 층마다 작은 불빛. 맨 아래는 검정에 삼켜진다.
→ **성장 방향이 아래**라는 구조를 그림이 말한다.

### L4. 물에 잠긴 글자
제목 글자의 아랫부분이 물에 잠겨 흔들린다. 잠긴 부분은 청록, 나온 부분은 황토.
→ 글자만으로 성립. 가장 싸고 가장 범용.
