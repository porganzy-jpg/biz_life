# 첫 주 해금 달력 — 1단계 마무리 (제안, 2026-10-13)

> 근거: 재검토 `design_next_level_20261013.md` §6 ①, §5-5(첫 주 과부하·권한 순서, M8). DECISIONS 2026-10-13 ③.
> 짝 데이터: `data/draft/unlock_calendar.json`. 비트는 `data/beats.json`(시나리오 소유)이 정본이고, 아래 **"비트 조정"** 칸은 시나리오 요청이다.

## 0. 원칙

- **1일째는 찍기와 「어디로」뿐이다.** 첫 3분에 기능을 하나씩만 보여 준다(M8). 재검토가 짚은 위험은 Wizards Unite식 과부하였다.
- **하루에 새 동사 하나.** 그날의 비트(새 사람·새 이야기)와 같은 날에 연다. 그러면 새 기능이 "설명"이 아니라 "사건"으로 들어온다.
- **열리기 전날, 떠날 때 카드로 예고한다**("내일부터 ○○"). 다음 세션의 이유가 된다.
- 잠긴 기능은 **안 보인다.** 회색 단추로 보이지도 않는다.

**옮기는 것**
- **습격 시작일**: 지금 `RAID_FIRST_DAY=2`라 2~3일째에도 습격이 올 수 있다 → **4일째부터**. 2일째 문어(넘김)는 비트로 따로 온다. `threats.first_week_guarantee.by_day 4`와 같은 날이다.
- **원정**: 1일째 → **5일째.** 첫 '모르는 쪽' 구조 보장은 그대로 둔다.
- **꾸밈 손님 첫 확정**(다음 세션 30분)은 2일째부터 자연히 따라온다.

## 2. 곡선 영향 (sim_expedition, 씨앗 20)

| | 방 7 / 14 / 30일 | 주민 7 / 14 / 30일 |
|---|---|---|
| 원정 1일째(지금) | 5.8 / 10.2 / 11.9 | 5.8 / 7.0 / 10.7 |
| **원정 5일째(달력)** | 5.6 / **9.9** / 11.9 | **5.1** / 6.5 / 10.1 |
| 목표 | 6 / 9 / 12 ±1 | 5 / 7 / 10 ±1 |

- 원정을 늦추면 14일째 방이 목표 9에 더 가까워진다. 원정을 켰을 때의 +1.1 편차가 +0.9로 준다.
- 주민 7일째는 5.1로 목표 5에 붙는다.
- 3일째 첫 손님(두드림)이 그대로라 첫 주의 사람 비트는 줄지 않는다.

## 3. 무엇을 재나 (라운드 5·실제 사람 7일)

- 첫 세션 길이, 첫 세션 안에서 창 닫기 비율, 1일째 복귀.
- 설문 "헷갈렸던 것".
- 하위 종류 고르기를 넘긴 비율. 50%를 넘으면 묻는 조건을 더 좁힌다.
- 3일째 기색 첫날의 맞힌 비율(전날 예고가 있을 때 / 없을 때).
