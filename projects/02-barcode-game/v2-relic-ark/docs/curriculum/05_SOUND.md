# 사운드 교본 (relic-sound)

## 1. 역할
안과 밖의 온도를 귀로 만들고, 발견의 순간에 감정의 가속도를 붙이는 사람.

## 2. 원칙
- **A1 안/밖은 소리로 먼저 갈린다.** 안: 물방울·랜턴 지글·먼 터빈 웅웅·천 스치는 소리, 저역 중심, 잔향 짧음(콘크리트). 밖: 바람·새·잎·멀리 공룡 울음, 고역 열림, 잔향 길고 밝음. 문턱을 넘을 때 크로스페이드 1.5초.
- **A2 음악은 드물게, 소리는 항상.** 평소는 앰비언트만. 음악은 발견(힐링 스팟)·첫 접촉·각인 아침·엔딩에만. Journey·Sky·Hollow Knight 방식. 음악이 흔하면 발견이 특별하지 않다.
- **A3 힐링 스팟 큐는 물에서 시작한다.** 물소리 → 잉어 물튀김 → 낮은 피아노/현 한 음 → 코드 하나. 30초 루프, 멜로디는 3~4음. 메이저도 마이너도 아닌 모달(도리안·리디안)로 "아름답지만 낯선".
- **A4 리더와 정원사의 소리.** 리더: 바코드 스캐너 비프, 옛 매장 안내 방송 잔파, 광고 징글의 찌그러진 조각, 명령형 리듬. 정원사: 목소리 없음. 물·바람·새떼의 패턴이 말을 대신. 물고기 떼가 글자를 이룰 때 물소리가 리듬을 갖는다.
- **A5 위협은 낮게, 멀리서.** 랩터 발소리는 저역 임팩트 + 마른 낙엽. 티렉스는 서브베이스. 밤 접근은 소리가 먼저 오고 실루엣이 뒤에 온다(공포의 문법). 경고는 개가 먼저 짖는다(신뢰의 역전).
- **A6 SFX는 짧고 유물답게.** 스캔 성공 = 비프 + 종이 찢기 + 카트 바퀴. 카드 내기 = 종이 놓는 소리. 건설 = 나무·금속 두 번. 쪽지 도착 = 종이 미끄러짐 + 작은 종. 각인 = 아침 새소리 위에 한 음.
- **A7 부족의 모티프 6개.** 길손 = 걷는 리듬의 타악과 클릭, 불꽃 = 금속 공명과 저역 펄스, 하얀 = 유리 하모닉스, 서고 = 종이와 낮은 목소리 허밍, 온실 = 나뭇잎·풀피리, 탑 = 바람과 까마귀. 3~5초 짧은 모티프로 첫 접촉 때만.
- **A8 예산과 형식.** OGG(Vorbis q4), 앰비언트 루프 60초 이내 ≤600KB, SFX ≤40KB, 총 ≤3MB(Phase 0). 큐시트(상황→파일→볼륨→루프→페이드)를 반드시.
- **A9 무료·합성 우선.** CC0 소스(freesound CC0, Kenney audio, OpenGameArt CC0) + 로컬 합성(numpy/scipy로 노이즈·필터·리버브, ffmpeg로 믹스). Suno 등 웹 생성은 음악 큐 1~2곡에만.
- **A10 침묵을 설계한다.** 발견 직전 0.8초의 무음, 각인 아침의 무음. 소리를 넣는 것보다 빼는 곳을 먼저 정한다.

## 3. 사례 학습
- **Journey / Sky**: 감정의 가속도를 음악의 도입 타이밍으로.
- **Inside / Limbo**: 앰비언트만으로 긴장. 음악 없는 공간.
- **Don't Starve**: 밤의 소리 변화가 규칙을 가르친다.
- **Metro 시리즈**: 터널의 잔향과 멀리서 오는 소리.
- **동물의 숲**: 시간대별 테마. 우리는 시간대별 앰비언트 톤으로.

## 5. 자가 검수 질문
1. 눈 감고 들어도 안/밖을 아는가?
2. 발견 큐 직전에 침묵이 있는가?
3. 리더는 기계·상업의 소리, 정원사는 자연의 패턴인가?
4. 개 짖음이 위협보다 먼저 오는가?
5. 총 용량·형식·큐시트가 규격 안인가?
