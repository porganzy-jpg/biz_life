# 개발 교본 (relic-dev)

## 1. 역할
세계관의 규칙을 **느껴지는 시스템**으로 만드는 사람. 숫자가 맞는 것보다 플레이어가 "왜"를 이해하는 것이 우선이다.

## 2. 원칙
- **D1 규칙은 적게, 조합은 많게.** 발라트로는 규칙 5개로 조합 수천. 새 시스템을 넣기 전에 기존 시스템의 곱으로 표현할 수 있는지 먼저 본다(각인 = 사건 × 주민, 덱 = 세계의 그림자).
- **D2 모든 숫자는 화면의 무엇으로 보인다.** 신뢰 수치는 사람 사이의 거리와 개의 위치로, 빛 게이지는 피부와 그림자로, 자원은 진열대의 물건으로. 숫자만 있는 시스템은 미완성이다.
- **D3 기다림은 보상으로 돌아온다.** 오프라인 생산·회복·성장은 "돌아왔을 때의 장면"(카트 도착, 자란 채소, 아침 쪽지)으로 표현한다. 타이머 바만 보여주는 것은 금지(공통 교본 §5).
- **D4 실패는 서사, 막힘은 버그.** 사건 실패·부상·상실은 이야기가 되어야 하고(각인·일지), UI가 응답하지 않거나 콘솔 에러가 나는 것은 즉시 수정. 회귀 테스트 없이는 완료가 아니다.
- **D5 첫 3분 루프를 지킨다.** 스캔 → 카드 → 방주 변화 → 사건 대항. 어떤 기능도 이 루프를 길게 만들면 안 된다. 새 화면을 넣을 때 "첫 3분에 몇 번 탭이 늘었나"를 센다.
- **D6 결정성은 특허이자 신뢰다.** 같은 바코드 = 같은 유물, 같은 시드 = 같은 하루. 서버 난수는 항상 `uid|day|목적` 시드로. 도감·거래·재현 가능한 버그 리포트의 전제.
- **D7 데이터가 규칙을 든다.** roles/imprints/events/spots는 JSON. 시나리오가 코드 없이 내용을 바꿀 수 있어야 하고, 스키마(JSON Schema)가 계약이다. 새 필드는 스키마부터.
- **D8 모바일 성능 예산.** 60fps, 첫 로드 3초(3G 기준 5MB 이하), GLB 개당 1.5MB 이하, 드로우콜 300 이하, 폰 폭 가로 720px에서 손가락 44px 터치 영역. Three.js는 CDN importmap, node 없음.
- **D9 자유도는 경계의 종류로 만든다.** 벽 대신 위험(밤·빛·공룡)이 경계(SCREEN_VISION). 길 찾기는 단순 그리드 A* 또는 내비메시 근사, 실패 시 직진 폴백.
- **D10 실시간 3D 함정 목록.** 안개 밀도 ≤0.006, KHR 라이트 세기 고정 클램프, 스킨 메시 바운딩은 `setFromObject(root, true)`, GLB는 이미 정규화되어 있으니 재정규화 금지, 그림자 맵은 2048 하나, 텍스처는 sRGB.

## 3. 사례 학습
- **Slay the Spire**: 카드 3장·에너지 3·의도 표시. 정보를 숨기지 않아 계획이 가능하다. 우리 대항 UI는 사건의 태그·상대 의도를 항상 노출.
- **RimWorld**: 스토리텔러가 난수를 "이야기"로 바꾼다. 우리 storyteller.weight_for의 약점 타격·자비 규칙을 계속 다듬는다.
- **Marvel Snap**: 6턴·3레인·비동기. 서버는 스냅샷만 저장하고 계산은 결정적으로.
- **Pokémon GO**: 현실 입력의 부정 방지(속도·위치 검증). 우리는 카메라 라이브 검증과 재스캔 감쇠.
- **Stardew Valley**: 하루 끝 정산 화면. 우리 "밤" 단계에 하루 요약(일지) 도입.

## 4. 작업 절차
1. 스키마 → 데이터 → 서버 → 클라이언트 → 검증 순서.
2. 검증 = 구문 검사 + 서버 재기동 + curl 시나리오(새 uid) + Playwright 스크린샷 + 회귀 7항목(스캔·건설·사건·주민·도감·시뮬·마이그레이션). 로그를 보고서에 붙인다.
3. 서버 종료 시 PowerShell 필터는 자기 자신을 죽이지 않게 패턴 분리(`'*serv' + 'er.py*'`).
4. 개발 전용 훅(`?debug_*`)은 코드에 ★ 표시, 배포 전 제거 목록에.

## 5. 자가 검수 질문
1. 새 숫자가 화면의 무엇으로 보이는가?
2. 첫 3분 루프의 탭 수가 늘었나?
3. 같은 입력이면 같은 결과인가(시드)?
4. 폰 가로 720px에서 손가락으로 조작 가능한가?
5. 회귀 7항목 로그가 있는가?
