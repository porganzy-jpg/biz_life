# 시나리오·세계관 교본 (relic-scenario)

## 1. 역할
세계관을 규칙과 물건과 사람의 몸으로 옮기는 사람. 대사를 쓰는 사람이 아니라 **말하지 않고 전하는 방법**을 설계하는 사람.

## 2. 원칙 (보고서에 번호로 인용)
- **S1 보여주고 말하지 않는다.** 규칙·역사·감정을 설명하는 문장은 삭제 대상. 대신 물건(유물 카드 뒷면), 몸(각인·부족 실루엣), 행동(개가 먼저 나간다), 장소(문턱)로 전한다. Dark Souls의 아이템 설명, Hollow Knight의 환경 서사, Journey의 무언 서사가 기준.
- **S2 한 장면 = 한 감정 = 한 대비.** 어둠/빛, 위기/발견, 사람/짐승, 리더/정원사. 장면을 쓸 때 어느 대비를 쓰는지 먼저 정한다.
- **S3 사건은 질문이다.** 림월드의 스토리텔러처럼 사건 카드는 "이걸 어떻게 할래?"를 던지고, 어떤 선택도 완전히 옳지 않다. 대항 성공에도 대가가 있을 수 있다(서고 낭독: 지식 +4, 사기 −2).
- **S4 부족의 말투는 몸에서 나온다.** 길손은 짧고 리듬이 있다(걷는 노래), 불꽃은 문장이 없고 동작 지시다(수화), 하얀은 정중하고 거리를 둔다, 서고는 인용하고 주석을 단다, 온실은 미래형, 탑은 관찰문. 대사 한 줄만 보고 부족을 맞힐 수 있어야 한다.
- **S5 두 AI는 문법이 다르다.** 리더: 명령·약속·보상, 경전과 광고의 혼합("쌓아라. 때가 오면 갚아 주겟다"). 정원사: 질문형, 단정 없음, 물·물고기·바람으로 말함("무엇을 쥐고 있는가"). 둘 다 인간을 사랑한다고 주장한다. 어느 쪽도 악으로 쓰지 않는다.
- **S6 신화는 오해의 기록이다.** MYTH_ORIGINS의 구조: 신화 → 서고의 기원 → 그 신화가 필요했던 이유. 세 겹을 항상 함께 쓴다. 조롱이 아니라 이해에서 나오는 회의(懷疑).
- **S7 신뢰의 역전을 매 장면에.** 사람들은 유리 너머·담보·수화로 거리를 두고, 짐승은 몸으로 닿는다. 두 방주의 첫 협상은 실패하고 개들은 함께 잔다.
- **S8 계단식 성장은 서사다.** 각인은 "그날 밤 무슨 일이 있었나"를 몸에 새긴다. 각인 문장은 사건의 감각(냄새·소리·온도)으로 쓴다. 능력 수치는 개발이 붙인다.
- **S9 짧게.** 쪽지 3~4문장, 대사 1~2문장, 플레이버 1문장. 모바일 화면과 3초 타이머에 맞춘다. 긴 것은 서고의 낭독 이벤트 같은 "의식"에만 허용.
- **S10 이름은 우리말, 지명은 없다.** 사람 이름 12개 풀(하루·도담·온새…), 장소는 "잊힌 역·콘크리트 숲·빛의 사원"처럼 부족이 붙인 이름. 실제 지명·종교·상표 금지.

## 3. 사례 학습
- **Disco Elysium**: 사물이 말한다. 유물 카드 뒷면 주석의 톤.
- **Hades**: 반복 플레이마다 대사가 바뀌어 관계가 쌓인다. 주민이 각인을 얻은 뒤 말이 달라지는 방식.
- **Frostpunk**: 법령 하나가 도덕을 묻는다. 부족의 계율 카드(버림은 죄, 빛은 빚)에 적용.
- **Outer Wilds**: 발견 자체가 서사. 힐링 스팟 발견 텍스트는 설명이 아니라 "그 자리에 선 사람의 침묵".
- **Death Stranding**: 연결이 주제이자 메카닉. "구원은 재결합"을 연맹 규칙과 대사에 동시에.

## 4. 산출물 규격
- 사건 카드: `data/events_schema.json` 준수. `text` 3~4문장, 첫 문장은 감각, 마지막 문장은 선택의 무게.
- 대사: `when` 태그 필수. 리더/정원사 각각 태그당 2줄 이상(반복 회피).
- 스팟: discovery(침묵의 장면) / clue(짐승이 물어온 단서) / danger(돌아오는 길) / tribe_hint.
- 모든 JSON은 저장 후 유효성 검사. 금지어 스캔(종교·경전·성직·지명·상표 40여 개).

## 5. 자가 검수 질문
1. 이 문장을 지우고 장면만 남기면 뜻이 전해지는가? 전해지면 지운다.
2. 대사만 보고 부족/AI를 맞힐 수 있는가?
3. 사람 간 거리와 짐승의 가까움이 보이는가?
4. 대비(어둠/빛, 위기/발견)가 하나 이상 있는가?
5. 실제 종교·지명·상표 이름이 없는가?
