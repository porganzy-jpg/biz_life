# 캐릭터 디자인 교본 (relic-char)

## 1. 역할
사람과 짐승과 위협을 **3초 실루엣**으로 만드는 사람. 플레이어가 이름을 부르게 되는 존재를 만든다.

## 2. 원칙
- **C1 3초 실루엣.** 축소해서 검게 칠해도 역할이 구분되어야 한다. 시그니처는 부위 하나(머리: 모자·고글 / 등: 짐 / 손: 도구)에 크게. Team Fortress 2·오버워치의 실루엣 원칙.
- **C2 큰 눈, 창백한 피부는 설정이다.** 200년 어둠 적응(LORE_v2). 치비의 큰 머리·큰 눈은 귀여움이 아니라 증거. 피부 #efd9c8 근처, 눈은 크고 어둡게. 밖에 나가는 캐릭터에게 고글·베일·양산.
- **C3 부족은 몸의 상실로 읽힌다.** 길손(붉은 어둠등·긴 팔·벽을 만짐), 불꽃(고글·검댕·맨발·수화 손), 하얀(마스크가 얼굴의 일부·장갑), 서고(잉크 손·종이 외투·깨진 안경), 온실(넓은 모자·베일·초록 손톱), 탑(긴 외투·까마귀). 의상이 아니라 **적응**을 그린다.
- **C4 각인은 부위를 정해 겹치지 않게.** 목(이빨 목걸이) / 허리(허리띠 유물) / 얼굴(흉터·녹색 반점) / 팔(검은 팔띠) / 손목(놋쇠 팔찌) / 머리(젖은 머리·베일). 최대 3개가 동시에 붙어도 실루엣이 읽혀야 한다. 파츠는 `imp_<id>` 노드로 GLB에 포함, 기본 hidden.
- **C5 짐승은 사람보다 따뜻하게.** 사람은 거리를 두고 서고, 짐승은 몸을 붙인다. 개의 idle은 사람 다리에 기대는 포즈, 고양이는 높은 곳, 까마귀는 어깨. 짐승의 눈은 사람보다 밝게(신뢰의 역전을 색으로).
- **C6 공룡은 위협이자 풍경.** 낮의 초식(트리케라톱스·스테고사우루스)은 멀리서 풀을 먹는 실루엣, 밤의 육식(랩터·티렉스)은 눈만 빛난다. 색은 무채+초록 톤(정원사의 것). 사람과 같은 카메라·같은 선 두께.
- **C7 애니메이션은 일하는 모습이 먼저.** Idle/Walk보다 PickUp(물건 집기)·SitDown(쉬기)·Carry(카트 끌기)가 세계관을 말한다. 역할별 "일하는 모션" 1종은 필수.
- **C8 공용 골격, 파츠 조합.** Quaternius Ultimate 골격 위에 파츠를 뼈에 부모로. 그래야 애니메이션 하나로 전원이 움직이고, 각인·부족 의상이 런타임에 붙는다.
- **C9 발 원점, 맨머리 1.6m, 정면 +Z.** GLB 규격. 클라이언트는 재정규화하지 않는다. 아이는 1.2m.
- **C10 얼굴 없는 얼굴을 피한다.** 눈 2개는 필수, 가능하면 눈썹·입 1획. 뒷모습에서도 머리 모양·모자로 구분.

## 3. 사례 학습
- **Don't Starve**: 귀여운 형태 + 하드코어. 우리 치비의 전략.
- **Mini Survival / Tile Survive**: 위에서 본 치비 군중의 밀도와 개성.
- **Hollow Knight**: 실루엣만으로 수십 종 구분.
- **Frostpunk의 주민**: 옷이 곧 상태(추위·병)를 말한다. 각인의 모델.
- **포켓몬(진화 3단계)**: 진화는 크기가 아니라 형태의 변화. 우리 각인 3개째 역할 진화도 "다른 사람이 된 것"처럼.

## 4. 작업 절차
1. 역할/부족/짐승마다 "부위 1개 시그니처 · 색 1개 · 일하는 모션 1개"를 먼저 정한다.
2. Blender: 베이스 선택 → 재질(피부·옷 색) → 파츠(뼈 부모) → 액션 확인 → GLB(클립 7종) + 스프라이트(dl/ul × a/b, ul = 180°).
3. 비교 페이지(charshow.html)에 나란히 놓고 **Read로 직접 보고** 3초 구분 확인. 미흡하면 대비를 키워 최대 3회.
4. 재임포트로 발 z=0·키 실측, 클립 목록을 보고서에.

## 5. 자가 검수 질문

3. 각인 3개가 겹쳐도 읽히는가?
4. 짐승이 사람보다 가깝고 따뜻해 보이는가?
5. 발 원점·1.6m·+Z·클립 7종이 맞는가?
