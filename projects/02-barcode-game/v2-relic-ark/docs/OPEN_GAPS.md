# 아직 정리 안 된 것 (2026-10-01)

> "지금 진행되는 것 말고 추가로 정리해야 할 것은 무엇인가"에 대한 PM의 답.
> 진행 중인 것(배치 전투 구현·체형·밸런스 수치·생물 명단)은 뺐다.
> **A → D 순으로 급하다.**

---

## A. 지금 당장 — 다른 작업을 막고 있다

### A1. 시간 구조 ✅ 확인 완료, 결정 등재
코드를 열어 보니 **이미 정해져 있었는데 문서에 없었다.**
- 게임 하루 = **실제 24시간**. 밤은 **플레이어의 실제 시계**(21~5시). 오프라인 생산이 이미 동작한다.
- 이 게임은 접속 시간이 아니라 **달력으로 흐른다.** "내일 또 켠다"가 비유가 아니라 사실이다.
- → 정식 결정으로 등재했고, 밸런스 담당에게 긴급 전달했다. **경제 곡선은 플레이 시간이 아니라 '며칠째'로 짜야 한다.**

### A2. 오프라인 진행 규칙 — 미정
`tick_production()`이 돌고는 있는데 **규칙이 설계된 적이 없다.**
- 오프라인 수입이 전체의 몇 %가 적정인가 (스캔이 주 수입이어야 한다)
- 상한이 있나. 일주일 안 켜면 일주일치가 다 들어오나
- **안 켠 동안 습격이 왔다면?** 지금은 아무 일도 안 일어난다. 이게 맞나
- 밸런스 담당에게 질문으로 넘겼다

## B. Phase 1을 막는다

### B1. 원정 시스템 — **설계 문서가 아예 없다** ★가장 큰 구멍
Phase 1 할 일 1번인데 사양서가 없다. 전투(방어)는 문서가 있는데 **나가는 쪽**은 장면 묘사뿐이다.
정해야 할 것: 어디로 가나(지도가 있나 목적지 선택인가) / 공기 게이지가 행동 몇 번인가 / 무엇을 줍나 / 돌아오지 못하면 / 누구를 보내나(스탯 숨·눈) / 스팟 발견과의 관계 / 2인 동행.
**PLAYER_JOURNEY J3·J4가 장면만 있고 규칙이 없다.**

### B2. 실패와 재시작 — 미정
- 방을 다 잃으면 어떻게 되나. 주민이 전부 죽으면?
- 아늑한 생존물이라 **게임 오버가 있으면 안 될 수도** 있다. 대신 "가장 깊은 층을 잃고 위로 물러난다" 같은 후퇴가 맞을지
- 지금은 방 상실만 있고 그 끝이 없다

### B3. 저장·이어하기 — 미정
- 현재 `localStorage` uid 하나. **기기를 바꾸면 전부 사라진다**
- D5에서 "6자리 복구 코드"를 추천했지만 설계도 구현도 없다
- 폰에서 하는 게임인데 브라우저 데이터 지우면 끝이다. **테스트 전에 반드시 해결**

### B4. 색으로 방을 구분하는 것의 위험 — 점검 필요
우리는 **방을 색으로 구분한다**(아트 원리 §1-4, 레퍼런스의 핵심). 그런데 남성의 약 8%가 적록색약이다.
- 황토·올리브·적갈이 서로 구분되는가
- 대비책: 방마다 **고유 무늬**를 이미 넣기로 했다(§1-5). 그게 색맹 대비책으로도 작동하는지 확인만 하면 된다
- 싸게 끝낼 수 있는데 지금 확인 안 하면 나중에 전부 다시 칠해야 한다

### B5. 튜토리얼 — 대본은 있고 설계가 없다
첫 10분 비트 표는 있지만 **배치를 어떻게 가르치나**가 없다. 전투가 배치로 바뀌었으니 새로 필요하다. 원칙은 "가르치지 않고 가르친다"(UI 0, 자막 0로 시작하는 J1~J2).

## C. 테스트 전에 필요하다

### C1. 지표를 실제로 어떻게 재나
H1~H5(하루 스캔 6회, 카테고리 4종, 첫 10분 완주, 스팟 자력 발견, 주민 이름 기억)를 **측정하는 코드가 없다.** `/api/stats`가 일부 있지만 가설과 연결돼 있지 않다. 지인 10명 테스트 설계도 없다.

### C2. 성능 예산
오디오만 1.92MB이고 이미지가 계속 는다. 폰에서 **첫 로딩 몇 초, 총 몇 MB, 몇 fps**를 목표로 할지 정한 적이 없다. 2.5D라 플레이트와 스프라이트가 계속 늘어난다.

### C3. 카메라 권한과 개인정보
바코드 스캔이 카메라를 쓴다. **권한 요청 전 고지 문구**, 사진을 저장하지 않는다는 명시, 개인정보 처리방침. 스토어에 올리지 않아도 웹에서 카메라를 쓰면 필요하다.

### C4. 알림
리텐션 장치인데 미설계. 웹 푸시는 제약이 많다. 문어가 뭘 물어 왔다는 알림이 이 게임에 가장 어울리지만, **압박이 되면 안 된다**(M10).
