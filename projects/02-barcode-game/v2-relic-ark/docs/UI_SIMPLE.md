# 거점 화면 단순화 — 폴아웃 셸터식 원칙 (2026-10-03)

> 사용자 지시: "폴아웃 셸터의 UI와 애니메이션을 참고해 달라. 지금은 너무 복잡하다."
> 가져오는 것은 **원리**다. 그림·아이콘·이름·배치를 베끼지 않는다.

## 1. 진단 — 지금 왜 복잡한가
| 지금 | 문제 |
|---|---|
| 습격이 열리면 오른쪽에 긴 패널(단계 3칸·서술·막는 법·반전·행동·대가·결과 예고·안내문) | 화면의 1/4을 글이 덮는다. 위협이 오는 심연을 가린다 |
| 방을 누르면 큰 패널(설명·불·선반·생산·붙은 것·사람 목록·숫자 칩) | 한 번에 다 보여 준다. 무엇을 눌러야 할지 모른다 |
| 자원 11종이 왼쪽 위에 글자 칩으로 두 줄 | 무엇이 중요한지 안 보인다 |
| 공기·깊이 막대 + 버튼 셋 + 찍기 + 줌 셋 | 모서리 네 곳이 다 차 있다 |

## 2. 원칙 다섯
1. **화면은 거의 전부 거점이다.** 고정 UI는 위 한 줄과 오른쪽 아래 버튼 둘(찍기·메뉴)뿐. 나머지는 눌렀을 때만 나온다.
2. **누를 것은 그림 위에 뜬다.** 생산이 다 되면 방 위에 **아이콘 방울**이 뜨고, 누르면 모인다. 패널을 열지 않는다.
3. **방을 누르면 그 방 위에 작은 카드**(이름·레벨·사람 수·유리한 능력치 한 글자·버튼 두 개 이하). 자세한 것은 카드의 「자세히」에서만.
4. **사람은 끌어다 놓는다.** 끄는 동안 방마다 **그 사람의 유리한 숫자 하나**만 방 위에 뜬다. 목록 UI가 아니다.
5. **사건은 방 안에서 일어난다.** 습격은 위 가운데의 **작은 띠 하나**(생물 실루엣 아이콘 + 한 줄 + 노려지는 방 표시). 노려지는 방이 깜빡이고 바깥에 실루엣이 다가온다. 막는 법·반전·대가는 띠를 누르면 펼쳐지는 작은 카드에.

## 3. 화면 구성 (가로)
```
┌──────────────────────────────────────────────────────────┐
│ ⚡3  🍞7  💧5  ⚙1     Day 1        [습격 띠: 거울눈 → 식량창고 ▸] │  ← 위 한 줄: 핵심 자원 4 + 날 + (있으면) 습격 띠
│                                                          │
│            (거점 — 방 위에 생산 방울, 끌기 숫자)              │
│                                                          │
│                                            [찍기] [≡]     │  ← 오른쪽 아래 둘
└──────────────────────────────────────────────────────────┘
```
- 위 한 줄 자원은 **4개만**(전력·식량·물·부품). 나머지(의약·사기·교역·지식·잔해·화학)는 ≡ 메뉴 안 「창고」에.
- 공기·깊이 막대는 위 한 줄 오른쪽 끝에 작은 아이콘 하나로(누르면 펼침).
- 전원·공방·열쇠는 ≡ 메뉴로. 줌 버튼은 PC에서만, 폰은 핀치.

## 4. 애니메이션 (작고 경쾌하게)
- 생산 방울: 방 위로 톡 튀어 올라 살짝 떠다님. 누르면 HUD 자원 쪽으로 날아가 숫자가 한 번 튐.
- 짓기/되찾기: 칸에 먼지 → 물이 빠지며 수면 내려감 → 불이 켜짐(1초 안팎).
- 사람: 엘리베이터 이동 + 방 안 작업(이미 있음). 가끔 둘이 마주 보고 이야기, 기지개.
- 습격: 노려지는 방 테두리가 천천히 깜빡, 바깥 실루엣이 다가옴. 결과는 방 위에 큰 글자 하나(「막았다」/「금이 갔다」)가 떴다 사라짐.
- 레벨업: 방이 한 번 밝게 번쩍 + 작은 반짝임.

## 5. 지키는 것
- 기능과 API는 그대로. 숨기는 것이지 지우는 것이 아니다.
- 이야기 문장(습격 서술·되찾기 문장·사건 카드)은 **눌렀을 때** 나온다. 아늑함의 맛은 글에 있으니 없애지 않는다.
