# 잔해 방주 — 주민(캐릭터) 설계 v1 (2026-09-19)

> 데이터: `data/roles.json` · 스프라이트: `tools/blender_chars.py` → `static/art/chars/<role>_<dl|ul>_<a|b>.png` · 서버 규칙: `server.py` `role_effects()`

## 1. 설계 원칙
- **역할이 곧 능력이다.** 주민은 가챠 카드가 아니라 "이 사람이 있어서 방주가 이렇게 굴러간다"가 눈에 보여야 한다. 모든 역할은 (a) 생산·건설 같은 **상시 효과**, (b) 사건 카드에 스스로 나서는 **자동 대항 태그**, (c) 방주 안에서 **눈에 띄는 행동**(말풍선·이동 패턴) 세 가지를 가진다.
- **3초 실루엣.** 치비 비율(머리 크게) + 역할 시그니처 소품 1~2개 + 몸 색 1개. 멀리서도 "저건 의무병"이 읽혀야 한다.
- **림월드식 특성 1개**로 개인차. 낙천적·야맹증·손재주·미식가·불면증·겁쟁이·강철 위장·수다쟁이.
- **이름은 지명 없는 우리말** (하루·도담·온새·가람·누리·다올·새벽·바람·여울·이슬·마루·소리).

## 3. 시스템 연결 (Phase 0에 구현됨)
- **시작 3인**: 요리사·기술자·정찰병 — "먹이고, 고치고, 살핀다". 아이·학자·교섭가·농부·의무병은 **표류자 사건**으로 합류한다(없는 역할 우선).
- **부상**: 사건 피해는 주민 개인에게 붙는다. 아이가 먼저 다친다(보호 못 하면). 8시간 틱마다 1명 회복, 의무병 있으면 2명.
- **자동 대항**: 카드도 방도 없을 때, 사건 태그와 맞는 역할이 확률로 나선다. 결과 화면에 "○○(의무병)이 나서서 막았습니다"로 표시 → 유저가 "저 사람 덕분"을 느낀다.
- **건설 할인**: 기술자 20% + 손재주 특성 10%, 최대 50%.
- **홀 시트 = 주민 명단**: 역 홀을 누르면 초상·이름·역할·능력·특성·부상 여부.

## 4. 스프라이트 규격
- Blender 원시 도형 치비(머리 r0.33m, 몸 0.5m, 다리 0.34m), 앞은 +X. 카메라 방위 45°·고도 32°(방보다 낮춰 얼굴이 보이게), 직교 2.4, 256px 투명.
- 4장/역할: `dl`(카메라 쪽 왼쪽 정면) · `ul`(뒷모습 왼쪽) × 걷기 `a`(다리 벌림) · `b`(모음). 오른쪽 방향은 CSS로 좌우 반전.
- 클라이언트 이동: 홀을 허브로 지어진 방 사이를 걷고, 승강기(페이드)로 지상 칸에 오른다. 정찰병·농부는 지상 선호, 아이는 빠르고 자주 말한다.
