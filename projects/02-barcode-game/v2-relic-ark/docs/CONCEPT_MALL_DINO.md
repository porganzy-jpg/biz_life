# 컨셉 추가: 거대한 쇼핑몰 거점 + 밖의 공룡 (2026-09-20, 사용자 제안)

> "밖에는 공룡들이 있고, 커다란 홈쇼핑 안에 텐트 치고 음식물 가져오고 이런 거 하고 싶다."

## 1. 왜 이게 좋은가
- **바코드와 무대가 하나가 된다.** 거점이 대형 쇼핑몰(홈쇼핑 물류센터·대형마트)이면, 진열대의 상품이 곧 유물이고 현실에서 스캔하는 물건과 같은 것이다. "매장 3층 식품관에서 라면을 가져온다" = 현실에서 라면을 스캔한다.
- **아늑한 생존의 정석.** 레퍼런스(편의점 진열대 사이의 텐트, Tile Survive 광고)와 정확히 같은 정서. 넓은 실내는 텐트·모닥불·빨래줄·채소밭을 자연스럽게 담는다.
- **공룡 = 가장 읽기 쉬운 위협.** 변이체·균류·기계 중 변이체를 "공룡화된 생물"로 시각화하면 3초 안에 위협이 읽히고, 아이도 어른도 좋아한다(포켓몬의 곤충채집처럼 공룡은 보편적 유년 원형이다). 깨진 유리창 밖으로 티렉스가 지나가는 장면 하나가 세계관을 설명한다.

## 2. 세계관 정리
- 대침묵 이후 유전자 실험실(하얀 산)에서 풀린 복원 생물이 213년 동안 번성했다. 도시는 **공룡의 초원**이 되었고, 인간은 두꺼운 벽이 있는 건물 안으로 들어갔다.
- 방주 = **잊힌 대형 쇼핑몰**. 지하(주차장·창고·옛 지하철 연결 통로)는 안전한 생활 공간, 지상 매장은 진열대에서 물자를 가져오는 탐색 구역, 옥상은 채소밭·빗물 저장·감시탑.
- 지하철 연결 통로는 그대로 남는다: 쇼핑몰 지하와 옛 역이 이어져 있어 노선 이동(다른 몰·다른 역)으로 확장된다.

## 3. 공간 구조 (현재 3×3 격자에 매핑)
| 층 | 현재 | 새 의미 |
|---|---|---|
| B1 격자 3×3 | 역 홀 + 방 8칸 | **지하 창고층**: 중앙 = 물류 승강기 홀(옛 역 통로 연결), 주변 = 창고 칸을 개조한 생활 방 |
| B0 지상 2칸 | 공터 | **매장층**: 진열대 사이에 텐트, 죽은 냉장고, 무너진 에스컬레이터. 유물(상품) 채집 구역 |
| 스카이라인 | 폐허 아파트 | **깨진 정면 유리 너머의 도시 초원**: 공룡 실루엣이 지나감. 밤에는 눈이 빛남 |
| 옥상 (Phase 1) | — | 채소밭·빗물통·감시탑. 농부·정찰병의 자리 |

## 4. 공룡의 게임 역할
- **일간 위협**: "밖의 위협" 사건 카드의 시각화. 낮에는 멀리서 풀을 먹고(초식: 트리케라톱스·스테고사우루스 = 자원 기회, 위험 낮음), 밤에는 육식(랩터 떼·티렉스)이 매장 가까이 온다.
- **대항**: 방어 시설(바리케이드·조명·소음), 정찰병 자동 대항, 미끼 유물(식품).
- **진화 생태계와 연결**: 서버 메타에 반응해 세대별 형질(장갑·야행·군집)이 바뀌는 종족이 공룡이다.
- **포획·사육**: 소형 초식(어린 파라사우롤로푸스)을 길들여 옥상 채소밭을 지키거나 운송에 쓴다(팰월드 요소).

## 5. 에셋 계획
- 공룡: Quaternius Animated Dinosaurs(CC0, 6종, 걷기·달리기·공격) → `tools/blender_charshow.py qd`로 아이소 렌더 확인 → 지상 배회 스프라이트(걷기 4프레임) + 위협 실루엣.
- 매장층 타일: 진열대 열·에스컬레이터·계산대·카트·죽은 냉장고 → `blender_iso.py`에 `mall_*` 타일 추가.
- 스카이라인: 깨진 유리 프레임 + 초원 위 공룡 실루엣 레이어(패럴랙스).
