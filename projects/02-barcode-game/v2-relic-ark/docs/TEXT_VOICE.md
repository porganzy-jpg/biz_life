# 글의 목소리 — 관리실 방송 (2026-10-03, S12-E)

> 사용자 지시: "한국어 문장이 너무 어색하다. 자연스럽게, **아파트 관리실 방송** 컨셉으로."
> 이 문서가 화면에 나오는 모든 한국어의 정본이다. 새 문장을 쓰는 사람(시나리오·개발·기획)은 쓰기 전에 읽고, 쓴 뒤에 §6 점검표로 소리 내어 읽어 본다.

---

## 1. 누가 말하나 — 관리실

이 집(기댄집)의 스피커에서 나오는 목소리가 **관리실**이다. 세계관에서는 **리더**다. 리더는 원래 이 건물의 재고 목소리였고, 200년째 같은 건물의 물건을 센다(`LORE_M5_기댄집.md` §1).

- 아파트 관리실 방송처럼 말한다. **친절하고, 조금 옛날식이고, 아주 평범하다.**
- 웃음은 거기서 나온다. 심해의 위험을 **승강기 점검 안내하듯 차분하게** 알린다. 긴목이 창에 얼굴을 붙여도 "관리실에서 알려 드립니다"로 시작한다.
- **절대 무섭게 하지 않는다.** 위협·경고·명령조·비꼬기 금지. 걱정은 하지만 놀라지 않는다.
- 리더의 버릇은 남겨 둔다(S5): 재고와 숫자를 좋아하고, 물건을 보면 값부터 떠올리고, 모르는 물건 앞에서 말을 더듬는다. 다만 광고 문구처럼 딱딱하게 쓰지 않고 **방송 아저씨의 말투로** 쓴다.
- **정원사는 관리실이 아니다.** 정원사는 지금처럼 질문으로, 짧게, 단정 없이 말한다(S5). 관리실 말투를 섞지 않는다.

## 2. 말투 — 진짜 관리실 방송처럼

합쇼체를 기본으로 하고, 사이사이 해요체를 섞는다. 실제 방송이 그렇다.

| 자리 | 쓰는 말 |
|---|---|
| 여는 말 | 「관리실에서 안내 말씀 드립니다.」 「관리실에서 알려 드립니다.」 「좋은 아침입니다, 관리실입니다.」 |
| 부르는 말 | 「주민 여러분」 「○○실 주민분들께서는」 |
| 부탁 | 「~해 주시기 바랍니다」 「~해 주세요」 「~하시면 됩니다」 「~주시고요,」 |
| 예정 | 「~있겠습니다」 「~하겠습니다」 「내일 공방에서 손보겠습니다」 |
| 안심 | 「다행입니다」 「다치신 분은 없습니다」 「급하게 안 하셔도 됩니다」 |
| 닫는 말 | 「수고 많으셨습니다」 「오늘도 무사한 하루 보내시기 바랍니다」 「이상, 관리실이었습니다」(가끔만) |

- 생물은 **「저 녀석」 「그 손님」 「넓적한 그림자」**처럼 동네 사람 부르듯 부른다. 「위협」「적」이라고 부르지 않는다.
- 숫자는 아라비아 숫자를 쓰고 단위를 붙인다(「식량 7, 물 5」「두 분」).
- 사람은 「분」으로 센다(「두 분」「다치신 분」).

### 기준 문장 (사용자에게 보인 것, 목소리의 닻)
- 습격 띠: 「관리실에서 알려 드립니다. 지금 식량창고 창가에 넓적한 그림자가 붙어 있습니다.」
- 막는 법: 「식량창고 불은 그대로 켜 두시고요, 다른 방에 불을 하나 더 켜 주세요. 저 녀석은 더 밝은 쪽으로 옮겨 갑니다.」
- 서두르지 않기: 「급하게 안 하셔도 됩니다. '맞서기'를 누르시기 전까지는 아무 일도 없으니, 천천히 자리 옮기시고 불도 정리해 주세요.」
- 막았을 때: 「다행입니다. 그림자가 그냥 지나갔습니다. 주민 여러분, 수고 많으셨습니다.」
- 금이 갔을 때: 「식량창고 유리에 금이 갔습니다. 다치신 분은 없습니다. 내일 공방에서 손보겠습니다.」
- 아침: 「좋은 아침입니다, 관리실입니다. 오늘 재고 확인 마쳤습니다. 식량 7, 물 5. 오늘도 무사한 하루 보내시기 바랍니다.」
- 스캔: 「새 물건이 들어왔습니다. '말없는 겨울 씨앗 주머니', 창고 선반 세 번째 칸에 두었습니다.」
- 잠긴 칸: 「이 칸은 물이 너무 깊게 차 있어서, 지금은 손을 댈 수 없습니다.」
- 승강기: 「승강기 정원은 두 분입니다. 다음 칸 이용해 주세요.」

> 막는 법 문장의 「반대편 방」은 「다른 방」으로 고쳤다. 「반대쪽」은 「먼 울음」 봉인 어휘다(`WORLD_BIBLE_DEEP` §9-5). 울음과 무관한 자리라 규칙 위반은 아니지만, 피할 수 있으면 피한다.

## 3. 어디에 어떤 목소리를 쓰나

| 자리 | 목소리 | 예 |
|---|---|---|
| 토스트·알림, 습격 띠·습격 카드, 결과, 아침 보고, 하루 마감, 층 되찾기, 스캔·선반 메시지, 잠긴 칸, 승강기 | **관리실 방송** | 위 기준 문장 |
| 버튼·탭·메뉴 이름 | **짧은 이름표.** 방송체를 쓰지 않는다. 명사나 「~기」 꼴 | 「맞선다」→「맞서기」, 「불을 끈다」→「불 끄기」, 「되찾는다」→「물 빼기」 |
| 칸 제목·라벨·수치 이름 | 짧은 명사 | 「식량」「사기」「정원 4명」 |
| 주민 대사 | **자연스러운 입말.** 무리마다 말투가 다르다(§4) | 「조금만 더 두면 돼요.」 |
| 사건 카드 본문 | **자연스러운 산문**(서술체 「~다」). 어울리면 관리실 한 줄로 열어도 된다 | 「관리실에서 알려 드립니다. 창고 쪽 유리에서 이상한 소리가 납니다.」 + 본문 |
| 유물 뒷면·가문 이야기·스팟 발견·각인 연출 | **자연스러운 산문**(서술체). 짧게 | 「입구만 남은 병이다. 귀에 대면 바깥 소리가 들린다.」 |
| 정원사 | 질문, 짧게, 단정 없음 | 「무엇을 쥐고 있는가.」 |
| 문어 | **말하지 않는다.** 행동 문장만 | 「문어가 먼저 들어가 본다.」 |

## 4. 주민 말투 — 무리마다 (S4)
모두 **진짜 사람이 하는 말**이어야 한다. 특징은 살리되 번역투로 만들지 않는다.

| 무리 | 말투 | 예 |
|---|---|---|
| 눈금 무리 | 숫자부터 말한다. 짧고 건조하다. 꾸밈말이 적다 | 「열둘이에요. 왼쪽에서 와요. 점점 커지고요.」 |
| 닻 무리 | 짧은 반말, 두세 마디 | 「막자. 셋이면 돼.」 |
| 그물 무리 | 부드러운 해요체, 권하는 말 | 「조금만 더 두면 돼요. 아직 덜 찼어요.」 |
| 손님 무리 | 안내 방송체 존댓말(관리실과 비슷하지만 **시간과 자리** 이야기를 한다) | 「곧 도착합니다. 두 분 자리는 있어요.」 |
| 아이 | 반말 질문 | 「옛날 사람들은 여기서 뭘 셌어?」 |

## 5. 하지 않는 것
- **번역투.** 「~하는 것이다」「~에 의해」「~를 가지다」「~하는 중이다」「그것은 ~이다」. 대명사 「그것」「그」를 줄인다.
- **줄표로 끊은 조각.** 「막는 법 — 불을 끄지 않는다」 같은 꼴. 문장으로 풀어 쓴다: 「불은 끄지 말고 그대로 두세요.」
- **명사만 줄줄이.** 「방 생산 ×0.5, 주민 사기 −0.3」은 수치 표 안에서만 쓴다. 화면 문장에서는 「그 방은 반만 일하고, 다들 조금 기운이 빠집니다.」
- **조사·어미 빼먹기.** 「한 층 더. 물 뺀다. 내일.」 같은 전보체는 닻 무리 대사에만 허용하고, 그것도 조사를 살린다(「한 층 더 빼자. 내일.」).
- **설명조 마무리.** 「~라는 뜻이다」「~이기 때문이다」로 끝나는 해설 문장. 장면에서 멈춘다(S1).
- **금지어**: 실제 상표·지명·인물·종교·경전 이름, 아파트 브랜드 이름. 1막 화면에서 건물을 「탑」이라고 부르지 않는다. 「먼 울음」 근처에 봉인 어휘를 쓰지 않는다.

## 6. 점검표 — 쓰고 나서
1. **소리 내어 읽었다.** 숨이 걸리는 곳이 없다.
2. 조사와 연결 어미가 다 있다(「~고」「~는데」「~니까」「~서」).
3. 줄표(—)가 화면 문장에 없다. 수치·명단 같은 표에서만 쓴다.
4. 「것이다」「그것」이 한 문장에 두 번 나오지 않는다.
5. 관리실 문장이면 여는 말이나 닫는 말 중 하나가 있고, 무섭지 않다.
6. 버튼이면 네 글자 안팎의 이름표다.
7. 실제 이름(상표·지명·인물·종교)이 없다.
