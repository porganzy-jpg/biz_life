# 사운드 출처 (audio/SOURCES.md)

## 결론: 이번 스프린트(S2-F)는 외부 CC0 음원을 쓰지 않았다

`docs/curriculum/05_SOUND.md` A9는 "CC0 소스 + 로컬 합성"을 함께 우선순위로 두지만, 앰비언트 3종·SFX 7종·힐링 스팟 큐 1곡 모두
`numpy`/`scipy`로 **100% 절차적 합성**이 가능했고(물방울·바람·새·귀뚜라미·공룡 울음·랜턴 지글·모닥불 크래클·비프·종·개 짖음 전부
노이즈 성형·필터·엔벨로프·글리산도·합성 리버브로 구현), 외부 CC0 파일을 다운로드해 붙일 필요가 없었다. 따라서 CC0 라이선스 표(원래
이 문서에 두려 했던)는 비어 있다 — **의도적 이탈이며 이유는 위와 같다.** 추후 부족 모티프(A7, 악기 음색이 필요한 경우)나 더 사실적인
동물 울음이 필요해지면 freesound.org(CC0 필터)·Kenney audio·OpenGameArt(CC0)에서 받아 이 표에 추가한다.

## "원본"의 정의: 결정론적 합성 스크립트 + 고정 시드

이 프로젝트의 사운드는 외부 원본 파일이 아니라 **재현 가능한 생성 스크립트**가 원본이다.
- `tools/gen_audio_common.py`: 공통 DSP(노이즈 성형, 필터, 리버브, 루프 크로스페이드).
- `tools/gen_audio_ambient.py`: 앰비언트 3종. 각 함수에 `seed` 고정(1/2/3).
- `tools/gen_audio_sfx.py`: SFX 7종. 각 함수에 `seed` 고정(10~16).
- `tools/gen_audio_cue.py`: 힐링 스팟 큐. `seed=42`.
- `tools/gen_audio_verify.py`: 검증(길이·크기·RMS·피크·스펙트럼 중심주파수).

동일 시드로 다시 실행하면 `static/audio/*.ogg`가 바이트 단위로 재현된다(단, ffmpeg 인코더 버전 차이로 OGG 압축 결과는
미세하게 달라질 수 있음 — PCM 단계는 결정론적). 중간 WAV(원시 파형)는 리포지토리 용량 절감을 위해 커밋하지 않고
`audio/_tmp/`에 생성 후 인코딩만 남긴다(각 스크립트가 자동 생성/재사용).

## 합성 방식 요약 (교본 05_SOUND A1~A10 대응)

- **안(amb_inside)**: 저역 터빈 웅웅(48/55Hz 비트) + 고역 랜턴 히스(3.2~8kHz, 랜덤 플리커) + 물방울(성긴 임의 이벤트,
  글리산도+클릭) + 천 스침(대역 노이즈 버스트) → 전체 로우패스 4.5kHz(저역 중심) → 짧고 어두운 합성 리버브(0.4s).
- **밖 낮(amb_outside_day)**: 광대역 핑크노이즈 바람(150~7kHz, 돌풍 LFO) + 잎 스침(2.2~8.5kHz) + 새 글리산도 칩(랜덤
  피치·타이밍) → 하이패스 70Hz(고역 열림) → 길고 밝은 리버브(2.0s).
- **밖 밤(amb_outside_night)**: 좁고 어두운 바람(90~1.8kHz) + 귀뚜라미 펄스(캐리어 4.2/6.1kHz × 트릴게이트 25Hz ×
  패킷 엔벨로프 2.5s) + 야간 대기 히스(옅게, 밖의 "열린 고역" 유지) + 저역 스윕 공룡 울음 1~2회(85~100Hz → 32~42Hz,
  가장자리 회피 배치) → 밝은 리버브지만 낮보다 낮은 웨트.
- **SFX 7종**: 클릭·붐·크래클·글리산도·비프·노이즈 버스트·저역 스윕의 조합. 상세는 `tools/gen_audio_sfx.py` 주석.
- **힐링 스팟 큐**: D 도리안(D-F-A-B, "Dm6") 코드 + 배음 합성 벨톤 멜로디(A4-G4-F4-D5) + 물소리/물튀김. 0.8초 무음
  선행(A10), 30초 루프(크로스페이드 1.5초).

## 루프 이음매 처리

모든 루프 파일은 `crossfade_loop()`로 처리했다: 루프 길이(L) + 여유(fade)만큼 신호를 생성한 뒤, 끝부분(L~L+fade)을
"진짜 연속된 다음 구간"으로 취급해 등파워 크로스페이드로 시작 지점에 섞는다. 저주파 변조(터빈 앰프 LFO, 바람 돌풍
LFO, 귀뚜라미 패킷)는 루프 길이의 정수 분의 1 주기로 맞춰 이음매에서 변조 자체가 끊기지 않게 했다.

## 추가: 스프린트 4-D(심해 1막, 2026-09-26) — 이번에도 CC0 미사용, 전부 로컬 합성

- `tools/gen_audio_deep_ambient.py`: 앰비언트 3종(`amb_dome_inside` seed=101, `amb_outside_deep` seed=102,
  `amb_trench` seed=103).
- `tools/gen_audio_deep_sfx.py`: SFX 6종(`sfx_airlock_cycle` seed=201 ~ `sfx_room_flood` seed=206).
- `tools/gen_audio_deep_cue.py`: `cue_vent_garden`(seed=52) · `amb_far_call`(seed=53).
- `tools/gen_audio_deep_verify.py`: 검증 + **돔 안 < 바깥 < 해구** 스펙트럼 중심주파수 순서 자동 판정.

합성 방식 요약(교본 05_SOUND A1·A3·A10 대응, 상세 근거는 `docs/reports/sound_S4.md`):

- **amb_dome_inside**(2026-09-26 PM 피드백 후 수정): 저역 기계 웅웅(45/52Hz) + 물방울 22회(밀도 상향) + 유리
  삐걱 2회(스틱-슬립 미세클릭) + 금속 딸깍 18회(1800~4200Hz 초단타) + 발소리 14회(120~220Hz 둔탁음) + 냄비 소리
  1회(620/930/1450/2100Hz 비화성 배음) + 웃음 1회(350~1100Hz 대역 노이즈 + 7Hz 트레몰로) + 먼 웅얼거림 2회
  (포먼트풍 350~1100Hz + 음절 엔벨로프) → 로우패스 3.5kHz → **더 짧고 좁은** 리버브(0.35s, wet 0.14, 원래
  0.4s/0.16에서 하향). 합쳐서 순간 사건 밀도 **1.18회/초**(원판 0.18회/초 대비 6.5배, `gen_audio_deep_verify.py`
  실측).
- **amb_outside_deep**(2026-09-26 PM 피드백 후 전면 재작업): 압력(34Hz+68Hz 배음, 근접한 두 기본음의 6Hz
  맥놀이를 피하려 배음 관계로 바꿈 — 맥놀이가 검증 스크립트의 순간사건 검출기를 오작동시켰다) + 먼 해류
  (핑크노이즈 90~3000Hz)를 **먼저 합쳐 하이패스 25Hz + 넓고 밝은 리버브(3.4s, wet 0.34)를 이 서브믹스에만
  적용**하고, 그 위에 **호흡을 리버브 없이 드라이하게** 더한다: 5초 주기, 들숨(0~45%, 150~900Hz, 완만한
  sin^1.8 상승)과 날숨(48~80%, 500~2500Hz, sin^1.6 — 첫 시도의 sin^0.7은 너무 날카로워 순간 사건으로
  오검출됐다) 사이에 무호흡 정지 구간(80~100%)을 두고, 헬멧 공명(320~520Hz 강조, 진폭을 낮게)만 살짝 얹었다.
  **사람 소리 요소는 코드 수준에서 아예 없다**(murmur/creak/footstep 함수 자체가 없음). 순간 사건 밀도
  **0.00회/초**(호흡의 완만한 스웰은 사건으로 검출되지 않도록 상승 곡선 자체를 늦춤).
- **amb_trench**: 광대역 '공백 히스'(500~6500Hz, 극히 낮은 레벨) + 서브베이스 바닥음(25~55Hz) + 아주 가끔(1회/루프)
  정체불명의 저역 신음(55~75→28~40Hz 글리산도, 구조물 삐걱임 — 「먼 울음」과는 다른 별개 요소) → 가장 긴 리버브
  (4.5s, wet 0.20). RMS가 셋 중 가장 낮아(-23.5dB) "더 비어 있음"을 소리 크기로도 뒷받침한다.
- **sfx_airlock_cycle**: 걸쇠 쿵(65Hz) + 금속 클랑크 → 라쳇 클릭 10회(가속-감속 곡선) → 물 차오름 노이즈 스웰(2.0s,
  거품 클릭 14회) → 정착 히스. 큐시트(§심해-2)의 크로스페이드 타이밍이 이 파형의 시간축에 맞춰져 있다.
- **sfx_glass_crack**: 손톱 긁기(불규칙 스타카토 9회, 대역이 조금씩 이동) → 날카로운 클릭 + 유리 공명 배음(2200/3300/
  4900/6600Hz, 비정수배 비율로 "유리스러움").
- **sfx_knock_glass**: 3회 노크, 간격 0.42s/0.51s로 **의도적으로 불균일**(등간격이면 기계처럼 들려 "생물의 흉내"라는
  설정이 깨진다).
- **sfx_air_low**: 비프 없음. 짧아지는 숨 3회(0.42/0.34/0.26초), 간격도 0.55→0.40초로 좁아짐 — 숫자가 아니라 호흡
  자체가 조급해지는 형태.
- **sfx_collect**: 물에 걸러진 먹먹한 클링크(로우패스 3200Hz) + 거품 3개.
- **sfx_room_flood**: 저역 임팩트(58Hz)+클랑 → 노이즈 로어(스웰 후 지수 2.2승으로 급격히 죽는 엔벨로프 — "그 방의
  소리가 사라진다"는 연출의 근거) → 거의 무음의 저역 잔향 꼬리.
- **cue_vent_garden**: A3 순서(물소리 → 거품 → 낮은 음 → 코드 → 멜로디) 그대로, 단 **G 리디안**(G B D + C#=#11)으로
  이전 스프린트의 D 도리안(cue_spot_found)과 색을 구분했다. 0.8초 무음 선행(A10), 30초 루프.
- **amb_far_call**: 42→27Hz 글리산도(살짝 어긋난 배음비로 이중 사인 겹침) + 아주 느린 트레몰로(1.3Hz). 로우패스
  140Hz로 형체를 지워 "생물도 기계도 아닌" 채로 남긴다(DECISIONS 2026-09-22 봉인 — 정체 비공개). 앞뒤에 0.4/0.6초
  여유를 둬 게임이 간격을 조절해 반복 재생해도 부자연스러운 절단이 없게 했다.
