# 사운드 출처 (audio/SOURCES.md)

## 결론: 이번 스프린트(S2-F)는 외부 CC0 음원을 쓰지 않았다

`docs/curriculum/05_SOUND.md` A9는 "CC0 소스 + 로컬 합성"을 함께 우선순위로 두지만, 앰비언트 3종·SFX 7종·힐링 스팟 큐 1곡 모두
`numpy`/`scipy`로 **100% 절차적 합성**이 가능했고(물방울·바람·새·귀뚜라미·공룡 울음·랜턴 지글·모닥불 크래클·비프·종·개 짖음 전부
노이즈 성형·필터·엔벨로프·글리산도·합성 리버브로 구현), 외부 CC0 파일을 다운로드해 붙일 필요가 없었다. 따라서 CC0 라이선스 표(원래
이 문서에 두려 했던)는 비어 있다 — **의도적 이탈이며 이유는 위와 같다.** 추후 부족 모티프(A7, 악기 음색이 필요한 경우)나 더 사실적인
동물 울음이 필요해지면 freesound.org(CC0 필터)·Kenney audio·OpenGameArt(CC0)에서 받아 이 표에 추가한다.

## "원본"의 정의: 결정론적 합성 스크립트 + 고정 시드

이 프로젝트의 사운드는 외부 원본 파일이 아니라 **재현 가능한 생성 스크립트**가 원본이다.
- `tools/gen_audio_common.py`: 공통 DSP(노이즈 성형, 필터, 리버브, 루프 크로스페이드).
- `tools/gen_audio_ambient.py`: 앰비언트 3종. 각 함수에 `seed` 고정(1/2/3).
- `tools/gen_audio_sfx.py`: SFX 7종. 각 함수에 `seed` 고정(10~16).
- `tools/gen_audio_cue.py`: 힐링 스팟 큐. `seed=42`.
- `tools/gen_audio_verify.py`: 검증(길이·크기·RMS·피크·스펙트럼 중심주파수).

동일 시드로 다시 실행하면 `static/audio/*.ogg`가 바이트 단위로 재현된다(단, ffmpeg 인코더 버전 차이로 OGG 압축 결과는
미세하게 달라질 수 있음 — PCM 단계는 결정론적). 중간 WAV(원시 파형)는 리포지토리 용량 절감을 위해 커밋하지 않고
`audio/_tmp/`에 생성 후 인코딩만 남긴다(각 스크립트가 자동 생성/재사용).

## 합성 방식 요약 (교본 05_SOUND A1~A10 대응)

- **안(amb_inside)**: 저역 터빈 웅웅(48/55Hz 비트) + 고역 랜턴 히스(3.2~8kHz, 랜덤 플리커) + 물방울(성긴 임의 이벤트,
  글리산도+클릭) + 천 스침(대역 노이즈 버스트) → 전체 로우패스 4.5kHz(저역 중심) → 짧고 어두운 합성 리버브(0.4s).
- **밖 낮(amb_outside_day)**: 광대역 핑크노이즈 바람(150~7kHz, 돌풍 LFO) + 잎 스침(2.2~8.5kHz) + 새 글리산도 칩(랜덤
  피치·타이밍) → 하이패스 70Hz(고역 열림) → 길고 밝은 리버브(2.0s).
- **밖 밤(amb_outside_night)**: 좁고 어두운 바람(90~1.8kHz) + 귀뚜라미 펄스(캐리어 4.2/6.1kHz × 트릴게이트 25Hz ×
  패킷 엔벨로프 2.5s) + 야간 대기 히스(옅게, 밖의 "열린 고역" 유지) + 저역 스윕 공룡 울음 1~2회(85~100Hz → 32~42Hz,
  가장자리 회피 배치) → 밝은 리버브지만 낮보다 낮은 웨트.
- **SFX 7종**: 클릭·붐·크래클·글리산도·비프·노이즈 버스트·저역 스윕의 조합. 상세는 `tools/gen_audio_sfx.py` 주석.
- **힐링 스팟 큐**: D 도리안(D-F-A-B, "Dm6") 코드 + 배음 합성 벨톤 멜로디(A4-G4-F4-D5) + 물소리/물튀김. 0.8초 무음
  선행(A10), 30초 루프(크로스페이드 1.5초).

## 루프 이음매 처리

모든 루프 파일은 `crossfade_loop()`로 처리했다: 루프 길이(L) + 여유(fade)만큼 신호를 생성한 뒤, 끝부분(L~L+fade)을
"진짜 연속된 다음 구간"으로 취급해 등파워 크로스페이드로 시작 지점에 섞는다. 저주파 변조(터빈 앰프 LFO, 바람 돌풍
LFO, 귀뚜라미 패킷)는 루프 길이의 정수 분의 1 주기로 맞춰 이음매에서 변조 자체가 끊기지 않게 했다.
