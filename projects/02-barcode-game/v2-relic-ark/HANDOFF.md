cd biz_life/projects/02-barcode-game/v2-relic-ark
pip install -r requirements.txt
python server.py            # http://localhost:8002

## 3.5 중단 지점 — 다음 세션이 여기서 이어받는다

배경 작업(평면 단면 거점 화면)을 **1차 렌더 상태에서 의도적으로 중단**했다. 이어받는 방법:

- **결과물**: `tools/blender_section.py`(구문 정상), `static/art/deep/section_hero.png`(1차, 미완성).
- **확정된 것**: 형상은 통과다. 맨 위 돔 → 아래로 유리 척추 → 층마다 좌우로 방. 방은 뒷벽·천장 보이는 얕은 디오라마, 방마다 다른 색, 안에 사람. **이 구조는 건드리지 말 것.**
- **남은 것은 전부 빛과 물이다.** PM이 마지막으로 보낸 지적 5건:
  1. 물이 너무 밝다. 답은 밝기가 아니라 **세로 그라데이션** — 화면 위는 청록, 아래 해구는 거의 검정. 이 하나가 "물속"과 "깊이 축"을 동시에 만든다.
  2. 떠 있는 각진 검은 사각형 제거(렌더 오류처럼 보인다).
  3. 화면을 가로지르는 검은 대각선(케이블) 수를 줄이고 물색에 잠기게.
  4. **방 둘레에 어두운 여백**을 줄 것(레퍼런스 §1-3의 핵심). 방이 밝은 물 위에 떠 있어 튀지 않는다.
  5. 부유물이 너무 크고 또렷하다. 절반 이하로, 반투명하게, 방 불빛보다 절대 밝지 않게. 척추 채도도 낮출 것.
- **원인은 이미 찾았다**: 배경 에이전트가 중단 직전에 확인하기를, **색 hex 값을 sRGB가 아니라 선형(linear) 값으로 넣고 있어서** 물이 밝게 나온다. 여기서부터 고치면 된다.
- 기준 한 줄: **화면에서 가장 밝은 것은 언제나 방 안의 등불이고, 물은 위에서 아래로 어두워진다.**
- 남은 산출물: 확대 컷 `section_zoom.png`, 보고서 `docs/reports/bg_S4.md`.

## 4. 바로 다음에 할 일 (스프린트 4 1순위)

## 6. 알려진 함정
- glTF에는 노드 가시성 필드가 없다 → 각인 파츠 `imp_*`는 클라이언트가 로드 직후 꺼야 한다.
- Blender에서 NLA 트랙을 푸시하면 GLB 기본 포즈가 망가진다 → `export_animation_mode='ACTIONS'`만 쓴다.
- Playwright는 `localhost` 연결을 거부한다 → `127.0.0.1` 사용.
- Pollinations 무료 이미지 API는 요청 제한이 심하다(429 시 5분 대기). 대량 생성은 Colab 노트북으로.
