# 2.5D 바코드 몬스터 — 신규 컨셉 샘플 (2026-09-19)

> 컨셉 유지: **상품 바코드를 스캔하면 몬스터가 태어난다.**
> 새 방향: 다크 판타지 대신 **2.5D 장난감 렌더** (치비 비율, 매끈한 3D 질감, 아이소메트릭 3/4 뷰, 스튜디오 조명).
> 귀여움과 멋을 한 화면에 둘 수 있도록 **"상품이 캐릭터가 된다"** 를 모든 테마의 공통 문법으로 삼았다.

## 게임 시스템 연결 아이디어
- **희귀도 = 바코드 자릿수 정보량**: 일반(식품·생활용품) → 고급(전자기기) → 전설(국가코드 고정 6종, 국가별 1종).
- **같은 상품 = 같은 몬스터** 원칙은 유지(특허 핵심). 테마는 상품 카테고리 코드로 결정, 개체 차이는 색 변형으로.
- **진화**는 "같은 브랜드 스캔", "같은 카테고리 N종" 등 **쇼핑 행동**과 연결(각 CONCEPTS.md 진화 항목 참고).
- 2.5D 렌더는 아이소메트릭 버스 내부(Heaven)에도 그대로 세울 수 있어 두 파트의 아트를 통일할 수 있음.

## 제작 방법과 배운 것
- 생성기: `gen_all_v2.py`(24종 순차), `regen_fix.py`(검수 후 재생성). Pollinations 무료 API, 키 없음.
- **Pollinations는 IP당 동시 1요청**. 에이전트 4개 병렬 실행은 3개가 429 대기만 하고 끝났다. 이미지 생성은 순차, 병렬 에이전트는 API를 안 쓰는 문서 작업에만.
- **저녁 시간대 무료 모델은 `sana`만** 제공(오후엔 flux). 긴 스타일 프리픽스를 주면 얼굴 없는 파란 덩어리가 나온다. `kawaii mascot character design, 3D render, chibi, isometric view, studio lighting, sharp focus` + **소재 하나 + 얼굴** 짧은 문장이 정답. `_style_test/`에 A/B 테스트 결과 보존.
- 복합 소재(김밥+슬라임, 드론+매)는 실패율이 높다. "X character with Y" 구조로 사물을 캐릭터화하는 문장이 잘 된다.
