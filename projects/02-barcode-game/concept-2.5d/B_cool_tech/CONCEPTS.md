# 2.5D 몬스터 컨셉 — 멋있는 계열 — 전자기기/기계 모티프

전자제품 바코드(EAN 880 + 전자·통신 제조사 코드)에서 태어나는 몬스터. 매끈한 패널, 발광 포인트, 살짝 건방진 표정이 공통 언어.

공통 스타일 프리픽스: `kawaii mascot character design, 3D render, chibi proportions, isometric three-quarter view, studio lighting, sharp focus, `

생성: `python ../gen_all_v2.py B_` (Pollinations, 순차 실행)


## 01. 배터골렘 (`01_battery_golem.png`)
- **모티프 상품 / 바코드**: 건전지·보조배터리 (880 / 전자)
- **속성**: 기계
- **성격**: 과묵하고 든든함. 충전 상태에 따라 기분이 변한다
- **진화 아이디어**: 충전량 100% 유지 3일 → 「파워뱅크 골렘」(팔에 USB 포트 4개)
- **시그니처 동작**: 가슴 충전바가 차오르며 스파크가 튄다
- **프롬프트**: `a battery golem robot character, body is a battery cell with glowing cyan charge bars, copper horns, cool eyes` / seed `41001`
- **이미지 평가**: 일치 — 청록색 발광 골렘, 가슴에 충전 표시등. 배터리 몸통은 약하지만 컨셉 전달됨
