## 추가 팁

### Midjourney 최적화
- `--style raw`로 MJ 자체 미화 줄이고 프롬프트에 충실하게
- `--s 750` (stylize) 값으로 예술성 높임
- `--v 6.1` 최신 버전 사용
- 결과가 마음에 들면 `U1`~`U4`로 업스케일

### DALL-E 3 최적화
- ChatGPT에서 "위 프롬프트 그대로 사용해주세요, 수정하지 마세요" 라고 추가
- 가로: "wide landscape format 16:9" / 세로: "tall portrait format 9:16" 명시
- 한 번에 2장씩 생성해서 비교 선택

### Stable Diffusion 최적화
- **추천 모델**: JuggernautXL, RealVisXL, SDXL base + refiner
- **LoRA**: oil painting LoRA, impasto LoRA 추가하면 퀄리티 대폭 상승
- **Sampler**: DPM++ 2M Karras 또는 Euler a
- **Hires fix**: 1.5x upscale with 0.3-0.4 denoising
- **ControlNet**: depth map으로 구도 잡으면 일관된 결과

### 게임 배경 적용 시
- 생성된 이미지를 약간 블러 처리하면 UI/캐릭터와 레이어 분리감 UP
- 상단/하단 그라데이션 오버레이로 텍스트 가독성 확보
- 같은 프롬프트에 시간대만 변경(dawn/noon/dusk/night)하면 시간 변화 연출 가능
