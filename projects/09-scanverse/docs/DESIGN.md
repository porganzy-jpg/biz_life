# ScanVerse (스캔버스) - Game Design Document

## 1. 게임 개요

**장르**: 바코드 스캔 카드 수집 + TCG (Trading Card Game)
**컨셉**: 바코드를 스캔하면 차원의 문이 열리고 카드팩을 획득. 수집한 카드로 전략적 덱을 구성하여 전투.
**타겟**: 캐주얼~미드코어 모바일 유저 (10대~30대)
**수익모델**: 프리미엄 카드팩, 코스메틱, 배틀패스

---

## 2. 핵심 게임 루프

```
SCAN (바코드 스캔) → COLLECT (카드 수집) → BUILD (덱 구성) → BATTLE (전투) → FUSE (합성)
     ↑                                                                          |
     └──────────────────────────────────────────────────────────────────────────┘
```

### 2.1 스캔 시스템
- 바코드 1개 스캔 = 카드팩 1개 (1~3장)
- 같은 바코드 = 같은 카드 (결정론적 생성)
- 하루 스캔 제한: 무료 20회, 프리미엄 무제한
- 특수 바코드: 팰린드롬, 연속번호 등 → 레어 확률 UP

### 2.2 팩 오프닝 연출
- 카드팩 등장 → 탭하여 개봉
- 카드 1장씩 뒤집기 (레어도에 따라 이펙트 상이)
- Mythic: 화면 전체 골드 파티클 + 진동

---

## 3. 카드 시스템

### 3.1 카드 등급 (6단계)
| 등급 | 색상 | 확률 | 테두리 효과 |
|------|------|------|-------------|
| Common | #9e9e9e 회색 | 40% | 없음 |
| Uncommon | #4caf50 초록 | 25% | 은은한 발광 |
| Rare | #2196f3 파랑 | 18% | 펄스 글로우 |
| Epic | #9c27b0 보라 | 10% | 강한 글로우 |
| Legendary | #ff9800 주황 | 5% | 레인보우 글로우 |
| Mythic | #e91e63 핑크 | 2% | 홀로그래픽 |

### 3.2 카드 타입 (4종)
1. **히어로 (Hero)** 🗡️ - 전투 유닛
   - 스탯: HP, ATK, DEF, SPD
   - 고유 스킬 1개
   - 코스트: 1~5 마나

2. **마법 (Spell)** ✨ - 즉발 효과
   - 공격 마법, 회복 마법, 버프/디버프
   - 코스트: 1~4 마나

3. **장비 (Equipment)** 🛡️ - 히어로 장착
   - 무기(ATK↑), 방어구(DEF↑), 악세서리(SPD↑)
   - 히어로 1체당 장비 1개

4. **유물 (Relic)** 💎 - 패시브 효과
   - 덱 전체에 적용
   - 유물 슬롯: 최대 2개

### 3.3 속성 (8속성)
| 속성 | 아이콘 | 컬러 | 강점 | 약점 |
|------|--------|------|------|------|
| Fire 🔥 | 불꽃 | #e74c3c | Nature, Wind | Water, Earth |
| Water 💧 | 물방울 | #3498db | Fire, Earth | Nature, Thunder |
| Nature 🌿 | 나뭇잎 | #27ae60 | Water, Thunder | Fire, Wind |
| Thunder ⚡ | 번개 | #f1c40f | Water, Wind | Nature, Earth |
| Dark 🌑 | 달 | #2c3e50 | Light, Wind | Light, Fire |
| Light ✨ | 별 | #f39c12 | Dark, Earth | Dark, Thunder |
| Wind 🌪️ | 바람 | #1abc9c | Nature, Earth | Fire, Thunder |
| Earth 🪨 | 바위 | #e67e22 | Fire, Thunder | Water, Wind |

### 3.4 바코드 → 카드 변환 알고리즘
```
EAN-13: [국가(3)] [제조사(4)] [상품(5)] [체크(1)]

1. SHA-256(barcode) → seed
2. 국가코드 → 속성 편향 (880=Fire, 490=Thunder, 690=Earth, ...)
3. 제조사코드 → 카드타입 편향 (0-2:Hero, 3-5:Spell, 6-7:Equipment, 8-9:Relic)
4. 상품코드 → 카드 ID 결정
5. 체크디짓 → 레어도 보너스 (7,0: +15%, 팰린드롬: +25%)
6. 팩 크기: seed[0] mod 3 + 1 (1~3장)
```

## 4. 전투 시스템

### 4.1 기본 규칙
- **4v4 턴제 배틀**
- 덱: 최소 8장, 최대 20장
- 시작 핸드: 4장
- 매 턴 1장 드로우
- 마나: 턴마다 +1 (최대 10)
- 승리 조건: 상대 히어로 전멸 또는 HP 0

### 4.2 턴 구조
1. **드로우 페이즈**: 카드 1장 뽑기
2. **마나 충전**: 최대 마나 +1, 현재 마나 = 최대 마나
3. **메인 페이즈**: 카드 사용 (히어로 소환, 마법 사용, 장비 장착)
4. **배틀 페이즈**: 필드 히어로 공격 지시
5. **엔드 페이즈**: 턴 종료 효과 처리

### 4.3 데미지 공식
```
기본 데미지 = ATK × (1 + 장비보너스) - DEF × 0.4
속성 보정 = 유리 1.5x / 불리 0.67x / 보통 1.0x
크리티컬 = 15% 확률, 1.5x 배율
최종 데미지 = 기본 데미지 × 속성 보정 × 크리티컬 × random(0.9~1.1)
```

### 4.4 전투 모드
- **스토리 모드**: 5개 챕터 × 10 스테이지 = 50 스테이지
- **일일 던전**: 속성별 특화 던전 (보상: 합성 재료)
- **PvP 아레나**: 실시간 매칭, ELO 레이팅
- **길드 보스**: 협동 레이드

## 5. 합성 시스템

### 5.1 등급 업 합성
- 동일 카드 3장 → 1등급 높은 같은 카드
- Common×3 → Uncommon, ..., Legendary×3 → Mythic

### 5.2 속성 합성
- 서로 다른 속성 히어로 2장 → 새로운 속성 히어로
- Fire + Water → Steam(특수), Nature + Thunder → Storm(특수)

### 5.3 레시피 합성
- 특정 카드 조합 → 히든 카드 (도감에서 힌트 제공)
- 예: "불꽃 검사" + "얼음 방패" + "바람의 망토" → "원소의 수호자" (Legendary)

---

## 6. 수집 시스템

### 6.1 카드 도감
- 전체 카드: 100종 (프로토타입)
  - 히어로 50종, 마법 25종, 장비 15종, 유물 10종
- 속성별 / 타입별 / 등급별 필터
- 미발견 카드: 실루엣으로 표시

### 6.2 세트 보너스
- 같은 속성 히어로 4종 수집 → 해당 속성 ATK +10% (전투 패시브)
- 전체 Common 수집 → 스캔 시 Uncommon 확률 +5%
- 전체 도감 완성 → 특별 Mythic 카드 "ScanVerse 마스터" 해금

### 6.3 업적
- 첫 스캔, 100번 스캔, 첫 Legendary 등
- 업적 보상: 골드, 보석, 특수 카드팩

---

## 7. 화면 구성

1. **홈** - 메인 허브, 퀵 액션, 일일 퀘스트
2. **스캔** - 바코드 스캔 + 팩 오프닝 연출
3. **컬렉션** - 카드 도감, 필터, 상세보기
4. **덱 빌더** - 덱 편집, 카드 배치
5. **배틀** - 스토리/던전/아레나 선택 → 전투
6. **합성** - 카드 합성 UI
7. **상점** - 카드팩, 코스메틱, 골드
8. **프로필** - 업적, 통계, 설정

---

## 8. 기술 스택 (프로토타입)
- **프론트**: Single HTML + Vanilla JS (모바일 퍼스트 430px)
- **백엔드** (Phase 2): FastAPI + SQLite
- **바코드**: SHA-256 결정론적 생성 (기존 알고리즘 활용)
- **이미지**: pollinations.ai AI 아트
- **저장**: localStorage (프로토타입) → SQLite (프로덕션)
