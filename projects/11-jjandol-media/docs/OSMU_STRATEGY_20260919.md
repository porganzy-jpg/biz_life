## 0. 한 줄 결론

**얼굴은 "짠한 독거 아저씨"(A), 뼈대는 "월 30만원 가계부"(B).** 둘 중 하나를 고르는 게 아니라 겹친다.

그리고 지금 당장 병목은 컨셉도 편집도 아니다. **핸드폰에 이미 있는 밥 사진을 `photos/`에 옮기고 가계부에 붙이는 것.** README의 미완료 항목 첫 줄이 그대로 이 문제다.

## 2. 컨셉 분석 — 짠함(A)과 짠테크(B)는 적이 아니다

### 2.1 두 컨셉의 정직한 비교

| 항목 | A · 짠한 독거 아저씨 (지금 채널 톤) | B · 월 30만원 아저씨 (기존 계획) |
|------|------|------|
| 첫 1초 훅 | **강함** — 지저분한 밥상은 스크롤을 멈춘다 | 약함 — 숫자만으로는 안 멈춘다 |
| 댓글·공유 | **강함** — "힘내세요", "저도 그래요" 감정 참여 | 보통 — 정보 공유형 |
| 알고리즘 확산 | 높음 (감정 콘텐츠는 완주율이 높다) | 중간 |
| 검색 유입 | **없음** — 아무도 "짠한 아저씨"를 검색하지 않는다 | **높음** — "1인가구 식비", "라면 원가"는 매일 검색된다 |
| 광고주 인식 | **기피** — 브랜드는 궁핍 옆에 로고를 안 둔다 | 선호 — 절약·핀테크·생필품 광고주의 핵심 타겟 |
| 애드센스 단가 | 낮음 | 높음 (구매 의도 시청자) |
| 쿠팡파트너스 전환 | 낮음 (동정은 구매로 안 이어진다) | **높음** ("이 라면 1,100원" → 링크) |
| 후원(슈퍼땡스) | 나올 수 있으나 **동정형 후원은 플랫폼·광고주 리스크** | 거의 없음 |
| 지속 가능성 | 위험 — 컨셉이 삶을 더 망가뜨리도록 압박한다 | 안전 — 기록은 삶을 개선하는 쪽으로 밀어준다 |
| 원조와의 차별성 | **낮음** — 독거아조씨 아류로 읽힐 위험 | 높음 — 숫자 기록형 1인가구 채널은 드물다 |

### 2.2 결론: 레이어링

```
[화면]   지저분한 밥상 사진 그대로            ← A. 손대지 않는다
[자막]   "오늘, 3,200원이었습니다."            ← B. 노랑 132px, 썸네일도 이것
[목소리] 저음·느림, 무심한 톤                 ← A
[구조]   웃음 → 숫자 → 위로                    ← 이미 확정된 시그니처가 정확히 이것
```

이미 `publisher/README.md`의 8컷 구성이 이 레이어링을 구현하고 있다. **새로 만들 게 없다.** 다만 운용 원칙을 한 줄로 못 박는다:

> **"불쌍해 보여도 되지만, 불쌍해 달라고 하지 않는다."**
> 시청자가 "안됐다"가 아니라 "저 사람은 저렇게 사는데 숫자는 나보다 낫네"로 끝나야 한다.

### 2.3 원조 독거아조씨와 갈라서는 세 가지

1. **숫자** — 독거아조씨는 감정을 주고, 이 채널은 감정 + 영수증을 준다.
2. **반복 가능한 포맷** — 원조는 한 편 한 편이 창작이다. 이 채널은 가계부 한 줄이 곧 대본이라 매일 나온다. 양이 곧 차별점.
3. **시청자 참여 CTA** — 매 편 끝 고정 댓글: "오늘 얼마 쓰셨어요?" 동정을 커뮤니티로 바꾸는 가장 싼 장치. 댓글 수는 쇼츠 노출의 핵심 신호다.

## 3. 당위성과 가능성 — 솔직한 판정

### 3.1 될 것 (확률 높음)

- **쇼츠 조회수 확보.** 사진 슬라이드 + TTS + 숫자 자막은 양산이 되고, 감정 훅이 있어 완주율이 나온다. 하루 1편 × 90일이면 알고리즘이 채널을 분류하기에 충분하다.
- **티스토리 애드센스 승인.** 30편 제목이 이미 있고 니치가 좁다. 정보형으로만 쓰면 D+60 승인은 현실적이다.
- **쿠팡파트너스 수익.** 이 채널의 소재가 라면·쌀·계란·두부·다이소다. 링크와 콘텐츠가 100% 일치하는 드문 경우.

### 3.2 안 될 것 (착각하면 안 되는 것)

- **쇼츠 광고 수익으로 먹고 살기.** 쇼츠 RPM은 출처마다 편차가 크지만 롱폼의 1/10~1/50 수준으로 보고된다. 100만 뷰가 몇만 원일 수 있다. 쇼츠는 **관객을 모으는 기계**지 돈 기계가 아니다.
- **인스타 릴스 조회수 보너스.** 2026년 검색 결과 기준 릴스 조회수 보상은 종료되고 사진·캐러셀 게시물에만 초대제 보너스가 남았다는 정보가 있다(미검증, §9). 다만 이게 사실이면 **밥 사진 아카이브가 캐러셀 그 자체**라 오히려 유리하다.
- **네이버 애드포스트.** 애드센스 대비 3~4배 낮다는 게 공통 평가. 네이버는 돈이 아니라 협찬 창구다.
- **YPP 빠른 승인.** 2026년 8월 보도에 쇼츠 기준 상향(90일 2,000만 뷰 설)이 있었다. 원문 확인 실패. **기존 계획의 "쇼츠 1,000만 뷰" 기준은 낡았을 수 있으니 YPP는 D+180이 아니라 "될 때 되는 것"으로 격하한다.**

### 3.3 수익 시나리오 (기존 계획 재확인, 수정 없음)

| 구간 | 보수 | 기본 | 상승 | 주 수입원 |
|------|------|------|------|----------|
| 1~3개월 | 0 | 0~3만 | 5만 | 쿠팡 |
| 4~6개월 | 2만 | 5~15만 | 30만 | 애드센스 + 쿠팡 |
| 7~9개월 | 5만 | 20~40만 | 80만 | + 첫 협찬 |
| 10~12개월 | 10만 | 40~90만 | 150만+ | + 브랜디드 · 전자책 |

세 시나리오를 가르는 변수는 재능이 아니라 **연속 발행 일수** 하나. 이 판정은 바뀌지 않았다.

## 4. 원소스 멀티유즈 설계 — 5채널을 3+1로 줄인다

### 4.1 원소스 정의

```
원소스 = 가계부 한 줄 (date, spend, meal, meal_cost, note) + 사진 3~5장
```

이게 없으면 아무 채널도 안 돌아가고, 이게 있으면 아래가 전부 자동/반자동으로 나온다.

### 4.2 채널 배치 (수정안)

기존 계획은 5채널 동시 운영이었다. 계획서 §6이 스스로 경고한 "5채널 완벽주의" 함정을 피하기 위해 **핵심 3 + 조건부 1 + 보류 1**로 재배치한다.

| 우선 | 채널 | 역할 | 원소스 변형 방식 | 소요/일 |
|------|------|------|-----------------|--------|
| **핵심** | 유튜브 쇼츠 | 관객 확보 · 허브 | 사진 켄번스 + TTS (자동) | 5분 |
| **핵심** | 인스타그램 | 배포 + 사진 캐러셀 | 릴스 = 쇼츠 재업 / **캐러셀 = 원본 사진 5장 + 캡션** | 5분 |
| **핵심** | 티스토리 | **현금** | 같은 소재 **정보형 재작성** (표·숫자·원가) | 25분 (주 3회) |
| 조건부 | 네이버 블로그 | 협찬 창구 | 일기형, 감성 톤 | D+90 이후 착수 |
| 보류 | 네이버 웹툰 | IP | — | 6개월 뒤 재검토 |

**왜 인스타가 핵심으로 올라왔나** — 사진이 원소스인 채널에서 인스타 캐러셀은 편집이 0이다. 폰 사진 5장 + 캡션 4줄(이미 `out/*/instagram.txt`로 자동 생성됨). 게다가 사진 게시물 보너스 정보가 사실이라면 유일하게 "사진 그대로"가 돈이 되는 곳이다.

**왜 웹툰을 보류하나** — 5채널 중 유일하게 원소스에서 자동으로 안 나온다(그림을 그려야 함). 지금 시점의 시간 대비 기대값이 가장 낮다.

### 4.3 복붙 금지 규칙 (수익의 생명선)

| 채널 쌍 | 규칙 |
|--------|------|
| 유튜브 ↔ 인스타 릴스 | 영상 동일 OK. 캡션·해시태그만 다르게 |
| 네이버 ↔ 티스토리 | **글 본문 절대 공유 금지.** 구글 중복 판정 = 애드센스 탈락 |
| 쇼츠 나레이션 ↔ 블로그 | 나레이션 문장을 그대로 글에 넣지 않는다 (`tistory.md` 주석이 이미 경고) |
| 5채널 공통 | 마지막 문장 "이렇게 살아도, 삽니다."는 **반드시 동일** |

## 5. 콘텐츠 포맷 — 일일 1종 + 주간 2종

일일 포맷만으로는 조회수 편차가 크다. 숫자가 커지는 편이 터지므로 **결산 편**을 따로 둔다.

| 포맷 | 주기 | 훅 (썸네일 숫자) | 원재료 | 예상 반응 |
|------|------|-----------------|--------|----------|
| ① 오늘의 밥상 | 매일 | `3,200원` | 가계부 1줄 + 사진 | 완주율·댓글 |
| ② 주간/월간 결산 | 주 1회 · 월 1회 | `이번 주 21,400원` / `이번 달 314,000원` | 가계부 7~30줄 집계 | **조회수 최상.** 큰 숫자 + 누적 스토리 |
| ③ 원가 실험 | 주 1회 | `계란 한 알 187원` | 이미 note 칸에 있는 문장들 | 검색·저장·쿠팡 전환 |

②와 ③은 티스토리 30편 제목과 1:1로 겹친다. **쇼츠 한 편이 곧 티스토리 글의 요약본**이 되도록 같은 날 소재를 맞춘다.

## 7. 실행 — 하루 30분, 이번 주 7개

### 7.1 주간 리듬

```
월~금  쇼츠 1편 (자동) + 인스타 릴스 재업 + 캐러셀 1개     ← 10분
수·토  티스토리 정보형 1편                                ← 25분
일     주간 결산 쇼츠 + 다음 주 사진 정리                  ← 20분
```

버거우면 **유튜브 + 티스토리만** 사수. 인스타는 쉬어도 계획이 안 무너진다.

### 7.2 이번 주 체크리스트

- [ ] **폰 사진 전부 PC로 덤프 → `photos/`에 넣기.** 이게 안 되면 아래 전부 안 된다

- [ ] 유튜브 OAuth `client_secret.json` 발급 → 비공개 업로드 → 매일 1편씩 공개 전환 (20일치 예약 완성)
