# 티스토리 첫 30개 글 — 제목 리스트

> 목적: **구글 애드센스 심사 통과** + 검색 유입 기반 확보
> 대상 블로그: 티스토리 (네이버 블로그와 절대 내용 공유 금지)
> 예상 소요: 주 3~4편 발행 시 약 8~10주

---

## 이 30개를 이렇게 설계했다

애드센스 심사는 글 개수보다 **"이 블로그가 무엇에 대한 곳인지 3초 안에 보이는가"** 를 본다.
그래서 30개 전부를 `1인가구 · 짠테크 · 실지출 기록` 하나의 니치로 묶었다.

네 가지 규칙을 모든 제목에 적용했다.

1. **숫자를 넣는다** — 구체성이 곧 원본성의 증거다. `31만원`, `100g당`, `7일`
2. **직접 해본 것만 쓴다** — 심사 탈락 1순위는 "어디서 본 듯한 글"이다
3. **검색어를 제목 앞쪽에 둔다** — 뒤에 있으면 노출에서 밀린다
4. **일기가 아니라 정보로 쓴다** — 감성 톤은 네이버 블로그 담당이다

## 발행 규칙 (제목보다 중요함)

### 반드시 지킬 것

- **네이버 블로그와 내용을 절대 공유하지 않는다.**
  같은 날 같은 소재를 써도 글은 새로 쓴다. 구글이 중복으로 판단하면 한쪽이 색인에서 빠지고,
  이건 애드센스 탈락 사유이기도 하다.
  - 네이버 = 그날의 일기 · 감성 톤 · 사진 위주
  - 티스토리 = 같은 소재의 **정보형 재구성** · 표와 숫자 위주

- **쿠팡 링크를 넣은 글에는 고지 문구를 반드시 넣는다.**
  `이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다.`
  누락은 계정 문제가 아니라 표시광고법 문제다. 위 표의 `쿠팡 O` 표시가 링크를 넣을 글이다.

- **애드센스 심사 기간에는 쿠팡 링크를 최소화한다.**
  제휴 링크가 많은 글은 "가치 없는 콘텐츠"로 분류될 수 있다. 승인 후에 늘린다.

### 글마다 넣을 고정 구성

1. 첫 문단에 **결론 숫자 하나** — 검색으로 들어온 사람이 3초 안에 답을 봐야 이탈하지 않는다
2. 본문 중간에 **표 1개 이상** — 체류시간이 오르고, 구글이 좋아한다
3. 마지막에 **직접 찍은 사진 1장** — 원본성의 가장 확실한 증거
4. 관련 글 2~3개 내부 링크 — 30편이 서로 연결될수록 전체 지수가 오른다

### 카테고리 구조 (블로그 개설 시 이대로)

```
├─ 실지출 기록      (1, 17, 21, 22, 29, 30)
├─ 식비와 장보기    (2, 5, 8, 16, 18, 23, 24, 25)
├─ 고정비 줄이기    (4, 7, 11, 12, 15, 19, 27)
├─ 살림과 물건      (3, 9, 10, 13, 28)
└─ 제도와 계약      (14, 20, 26)
```

카테고리를 5개 이상 만들지 않는다. 니치가 흐려지면 심사에 불리하다.
