# 11 · 짠돌이 미디어 (Jjandol Media)

1인가구 절약 기록 콘텐츠를 5개 채널로 운영해 수익화하는 프로젝트.

## 컨셉

**월 30만원 아저씨** — 지저분한 방, 대충 만든 음식, 아무렇게나 입은 옷.
사진은 그대로 쓰되 프레임을 뒤집는다.

> 방 사진 하나만 있으면 = 불쌍함
> 방 사진 + "이번 달 생활비 31만 4천원" = 정보

"못 사는 게 아니라 안 쓰는 것." 시청자가 안타까워하는 대신 배우게 만드는 게 이 컨셉의 전부다.

## 시그니처 (확정)

모든 콘텐츠는 이 2단 구조로 끝난다. **앞은 매 편 바뀌고, 뒤는 절대 바뀌지 않는다.**

```
[오프닝]  "오늘도 안 치웠습니다."          ← 유머
[변수]    "오늘, 3,200원이었습니다."       ← 숫자만 교체
          ( 0.4초 쉼 )
[상수]    "이렇게 살아도, 삽니다."         ← 절대 불변
```

한 편 안에서 **웃음 → 정보 → 위로**로 떨어지는 낙차가 생긴다.
이게 "불쌍한 아저씨"와 "짠돌이 아저씨"를 가르는 지점이다.

**운용 규칙**

- 5개 채널 전부 같은 문장으로 끝낸다 — 유튜브 나레이션, 인스타 캡션 마지막 줄,
  블로그 맺음말, **웹툰 마지막 컷 말풍선**까지. 5개 계정이 같은 사람이라는 걸 알리는 가장 싼 방법.
- **최소 1년은 바꾸지 않는다.** 3개월쯤 질리는데, 시청자는 그때 겨우 외우기 시작한다.
- TTS: `ko-KR-InJoonNeural` -35Hz/-12%로 약 2.3초. edge-tts는 쉼표를 거의 안 쉬므로
  `"이렇게 살아도"` / `"삽니다"`를 따로 생성해 **0.4초 무음을 끼워 붙인다.** 이 문장은 쉼이 전부다.

## 채널 배치

| 채널 | 역할 | 수익 방식 |
|------|------|----------|
| 유튜브 | 허브 · 원본 제작 | 애드센스(YPP), 멤버십, 브랜디드 |
| 티스토리 | **수익 창고** | 애드센스 ← 초반 현금은 여기서 나온다 |
| 네이버 블로그 | 협찬 창구 | 애드포스트, 체험단 |
| 인스타그램 | 배포 | 직접 수익 거의 0, 공동구매·협찬 DM |
| 네이버 웹툰 | IP 자산 | 도전 단계는 0원, 캐릭터를 만드는 곳 |

**핵심 판단 3가지**

1. 네이버 블로그에는 애드센스를 붙일 수 없다 (구조적으로 불가). 애드포스트만 가능.
2. 애드센스는 유튜브가 아니라 **티스토리에서 먼저 나온다.** YPP는 6개월+, 티스토리는 2개월.
3. 지금 당장 가능한 수익 수단은 **쿠팡파트너스 하나뿐이다.**

## 관련 프로젝트

강아지 클립 대신 사진 슬라이드를 넣으면 그대로 재사용된다.
내레이션은 이미 튜닝된 `ko-KR-InJoonNeural` -35Hz/-12% (저음·느림)이 이 컨셉에 맞는다.
