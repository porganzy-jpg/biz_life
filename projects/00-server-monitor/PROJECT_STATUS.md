# Server Monitor v2.0 - 프로젝트 현황

**최종 업데이트**: 2026-02-18

## 개요
노트북을 홈서버로 운영하기 위한 **통합 모니터링 + 제어 + 자동복구 시스템**.
FastAPI 웹 대시보드(포트 9000) + 텔레그램 봇(11개 명령) + 백그라운드 모니터링(헬스체크/리소스 알림)을 **단일 프로세스로 통합 관리**.

## 기술 스택
- **Backend**: Python 3.13, FastAPI + Uvicorn (포트 9000)
- **텔레그램 봇**: python-telegram-bot 22.5 (11개 명령)
- **모니터링**: psutil (CPU, RAM, Disk) + httpx (비동기 헬스체크)
- **프로세스 관리**: subprocess + psutil (Windows)
- **통합 런처**: multiprocessing (대시보드 + 봇 + 모니터링 3-in-1)

## 실행 방법
```bash
cd projects/00-server-monitor

# 통합 실행 (대시보드 + 텔레그램 봇 + 모니터링)
python main.py

# 대시보드 + 모니터링만 (봇 없이)
python main.py --no-bot

# 대시보드 + 봇만 (모니터링 없이)
python main.py --no-monitor

# 개별 실행
python app.py     # 웹 대시보드만
python bot.py     # 텔레그램 봇만
```

## 핵심 기능

### 1. 통합 런처 (main.py)
- 대시보드 + 텔레그램 봇 + 모니터링을 **단일 프로세스로 관리**
- 서브프로세스 크래시 자동 감지 + 재시작 (5초 간격 감시)
- Ctrl+C 우아한 종료 (SIGINT/SIGTERM 처리)
- `--no-bot`, `--no-monitor` 플래그로 개별 비활성화

### 2. 백그라운드 헬스체크 (monitor.py)
- **30초마다** 모든 프로젝트 포트 응답 확인
- 응답 없으면 **자동 재시작** (좀비 프로세스 정리 포함)
- 재시작 이벤트 텔레그램 알림 (5분 쿨다운)

### 3. 리소스 임계치 알림 (monitor.py)
- **60초마다** CPU, RAM, Disk 사용률 체크
- 임계치 초과 시 텔레그램 경고:
  - CPU > 85%
  - RAM > 80%
  - Disk > 90%
- 동일 알림 5분 쿨다운 (스팸 방지)

### 4. 텔레그램 봇 (bot.py, 11개 명령)

| 명령 | 설명 |
|------|------|
| `/start` | 봇 도움말 |
| `/status` | 전체 프로젝트 상태 |
| `/system` | CPU, RAM, Disk 리소스 |
| `/report` | 서버 일일 리포트 (프로젝트 + 리소스 + 업타임) |
| `/begin <이름>` | 프로젝트 시작 |
| `/stop <이름>` | 프로젝트 중지 |
| `/restart <이름>` | 프로젝트 재시작 |
| `/logs <이름>` | 최근 10줄 로그 |
| `/startall` | 전체 프로젝트 시작 |
| `/stopall` | 전체 프로젝트 중지 |
| `/panel` | 인라인 버튼 제어 패널 |

### 5. 웹 대시보드 (app.py, 포트 9000)
- 시스템 리소스 게이지 (CPU/RAM/Disk)
- 프로젝트별 상태 카드 (실행/중지 + 제어 버튼)
- 전체 시작/중지/재시작
- 로그 뷰어 (최근 15줄)
- 30초 자동 새로고침

### 6. Windows 자동 시작
- `install_autostart.bat`: 시작 프로그램 폴더에 바로가기 자동 등록
- `startup_all.bat`: 전체 프로젝트 일괄 시작 (모니터 포함)
