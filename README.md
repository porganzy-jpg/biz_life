# BIZ LIFE - 퇴직 후 5대 사업 프로젝트

> 기술 기반 5개 사업 프로젝트의 통합 개발 레포지토리

## 프로젝트 목록

| # | 이름 | 설명 | 상태 |
|---|------|------|------|
| 01 | **PromoMap** | 위치 기반 임직원 할인 프로모션 앱 | 기획 중 |
| 02 | **BarcodeQuest** | 바코드 스캔 기반 모험 게임 | 기획 중 |
| 03 | **VoiceMemory** | AI 음성 보존 서비스 | 기획 중 |
| 04 | **CryptoBot** | 코인 자동매매 프로그램 | 개발 중 |
| 05 | **StockBot** | 주식 자동매매 프로그램 | 기획 중 |

## 기술 스택
- **Backend**: Python 3.13, FastAPI
- **Frontend**: React Native / Web
- **Database**: PostgreSQL, Redis
- **AI/ML**: OpenAI API, TensorFlow
- **Trading**: ccxt, TA-Lib

## 시작하기

```bash
# 레포지토리 클론
git clone git@github.com:porganzy-jpg/biz_life.git

# 각 프로젝트 폴더로 이동하여 개별 README 참조
cd projects/04-crypto-trader/  # 예시
```
